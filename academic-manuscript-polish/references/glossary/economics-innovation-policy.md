# 经济、创新、会计与政策

共 32 条。条目包括阅读用释义、论文用法及易混边界。文献用例提供相关研究入口，具体操作定义和公式须按原文判断；不能把每个用例都当作规范定义的首次来源。

<a id="term-01"></a>

## 01 Nash 均衡

英文：Nash equilibrium。

其他参与者策略给定时，无人能靠单方面改策略提高收益。

- 论文用法：描述策略互动的一种均衡。
- 易混边界：不保证唯一、稳定、容易达到或社会最优。
- 依据与用例：[文献用例](../sources.md#s042)


<a id="term-02"></a>

## 02 收益

英文：Payoff。

模型用来评价参与者结果的数值。

- 论文用法：表达策略偏好与目标。
- 易混边界：可代表效用而非金钱，含义由模型定义。
- 依据与用例：[文献用例](../sources.md#s042)


<a id="term-03"></a>

## 03 混合策略

英文：Mixed strategy。

在纯策略集合上的概率分布。

- 论文用法：描述随机化选择并研究均衡存在。
- 易混边界：群体中不同人的选择比例与个体随机化需区分。
- 依据与用例：[文献用例](../sources.md#s042)


<a id="term-04"></a>

## 04 信号传递

英文：Signaling。

有信息的一方通过可观察行为影响另一方判断。

- 论文用法：分析学历等可见特征与雇佣决策。
- 易混边界：信号有效性取决于成本与激励，观察到相关性不足以证明。
- 依据与用例：[文献用例](../sources.md#s059)


<a id="term-05"></a>

## 05 信息不对称

英文：Information asymmetry。

不同参与者掌握的信息不相同。

- 论文用法：分析市场决策与制度安排。
- 易混边界：信息差不自动意味着欺骗或某项政策必然有效。
- 依据与用例：[文献用例](../sources.md#s059)


<a id="term-06"></a>

## 06 外部性

英文：Externality。

某行动对第三方产生、未被该交易充分计价的影响。

- 论文用法：讨论政策干预的理由及福利核算。
- 易混边界：外溢是更宽的传播描述，未必都符合外部性定义。
- 依据与用例：[文献用例](../sources.md#s004)


<a id="term-07"></a>

## 07 政策外溢

英文：Policy spillover。

政策影响扩展到直接目标以外的主体或地区。

- 论文用法：研究跨市场或跨国影响。
- 易混边界：需要区分共同冲击、贸易调整和真正传播路径。
- 依据与用例：[文献用例](../sources.md#s004)


<a id="term-08"></a>

## 08 产品属性传播

英文：Attribute propagation。

政策诱导的产品属性变化随跨市场销售传播。

- 论文用法：Ito 等用于解释境外燃油经济性变化。
- 易混边界：属于该研究明确的机制，不能涵盖所有政策外溢。
- 依据与用例：[文献用例](../sources.md#s004)


<a id="term-09"></a>

## 09 局部均衡

英文：Partial equilibrium。

分析某市场时将部分其他市场条件视为给定。

- 论文用法：隔离特定渠道。
- 易混边界：适用范围取决于被忽略的反馈是否重要。
- 依据与用例：[文献用例](../sources.md#s004)


<a id="term-10"></a>

## 10 一般均衡

英文：General equilibrium。

把多个相互关联市场的同时调整纳入模型。

- 论文用法：分析价格、需求和资源配置反馈。
- 易混边界：结果依赖行为假设、市场结构和校准。
- 依据与用例：[文献用例](../sources.md#s004)


<a id="term-11"></a>

## 11 技术范式

英文：Technological paradigm。

技术共同体用来界定问题及研究路径的认知和实践框架。

- 论文用法：Dosi 用于解释技术变化的方向。
- 易混边界：范式边界需具体识别，不能把任意热门技术都这样命名。
- 依据与用例：[文献用例](../sources.md#s019)


<a id="term-12"></a>

## 12 技术轨迹

英文：Technological trajectory。

在给定技术范式内持续发展的改进方向。

- 论文用法：组织技术性能与经济取舍的历史。
- 易混边界：轨迹不表示每一步预先确定，也允许分支与改变。
- 依据与用例：[文献用例](../sources.md#s019)


<a id="term-13"></a>

## 13 知识重组

英文：Knowledge recombination。

把已有知识或技术组件按新方式组合。

- 论文用法：研究创新来源。
- 易混边界：组件分类、组合单位和新旧参照决定测量。
- 依据与用例：[文献用例](../sources.md#s024)


<a id="term-14"></a>

## 14 新颖性

英文：Novelty。

相对规定历史或知识参照的差异程度。

- 论文用法：评价新组件或新组合。
- 易混边界：新颖不直接等于有用、高影响或高商业价值。
- 依据与用例：[文献用例](../sources.md#s024)


<a id="term-15"></a>

## 15 突破性发明

英文：Breakthrough invention。

按指定标准具有极高技术或后续影响的发明。

- 论文用法：研究结果分布的高端部分。
- 易混边界：引用分位数、奖项与专家判断会选出不同集合。
- 依据与用例：[文献用例](../sources.md#s024)


<a id="term-16"></a>

## 16 专利前向引用

英文：Forward patent citation。

某专利被后续专利引用的记录。

- 论文用法：作为部分技术影响的代理。
- 易混边界：受年龄、领域和审查实践影响，不能直接等同经济价值。
- 依据与用例：[文献用例](../sources.md#s024)


<a id="term-17"></a>

## 17 搜索广度

英文：Search breadth。

搜索涉及知识或技术类别的跨度与数量。

- 论文用法：分析创新输入来源。
- 易混边界：类别多、距离远和组合新颖是不同属性。
- 依据与用例：[文献用例](../sources.md#s024)


<a id="term-18"></a>

## 18 探索与利用

英文：Exploration and exploitation。

探索尝试新路径，利用扩展或改进已知知识。

- 论文用法：解释资源在创新活动间的分配。
- 易混边界：两者取决于分析层级，组织层与单个发明层不能直接混用。
- 依据与用例：[文献用例](../sources.md#s024)


<a id="term-19"></a>

## 19 技术转移

英文：Technology transfer。

知识、技术或使用能力在组织之间转移。

- 论文用法：分析大学与产业联系。
- 易混边界：专利、许可、合同研究和衍生企业是不同渠道。
- 依据与用例：[文献用例](../sources.md#s009)


<a id="term-20"></a>

## 20 技术转移办公室

英文：Technology transfer office（TTO）。

组织内管理技术转移活动的机构。

- 论文用法：比较人员、经验和制度安排。
- 易混边界：办公室规模与绩效的关联可能受大学资源共同影响。
- 依据与用例：[文献用例](../sources.md#s009)


<a id="term-21"></a>

## 21 技术许可

英文：Licensing。

按约定授权另一主体使用特定知识产权或技术。

- 论文用法：衡量商业化渠道。
- 易混边界：许可数量、收入及技术实际采用各自反映不同结果。
- 依据与用例：[文献用例](../sources.md#s009)


<a id="term-22"></a>

## 22 衍生企业

英文：Spin-off。

从已有组织的知识、人员或技术基础上形成的企业。

- 论文用法：分析大学研究成果的企业化。
- 易混边界：不同研究对大学关联程度和成立条件的定义不同。
- 依据与用例：[文献用例](../sources.md#s009)


<a id="term-23"></a>

## 23 预期信用损失

英文：Expected credit loss（ECL）。

考虑未来可能违约及现金回收的信用损失估计。

- 论文用法：分析论文中的前瞻损失确认。
- 易混边界：预测期间、情景权重和折现决定结果，不能与已实现损失等同。
- 依据与用例：[文献用例](../sources.md#s033)


<a id="term-24"></a>

## 24 贷款损失拨备

英文：Loan-loss provision。

为预期或确认的贷款损失作出的会计计提。

- 论文用法：研究损失确认时点与银行行为。
- 易混边界：当期计提费用、累计准备余额及实际核销应区分。
- 依据与用例：[文献用例](../sources.md#s033)


<a id="term-25"></a>

## 25 违约概率

英文：Probability of default（PD）。

在规定期间和定义下发生违约的概率。

- 论文用法：作为信用风险模型输入。
- 易混边界：期间和违约事件定义改变时，数值不可直接比较。
- 依据与用例：[文献用例](../sources.md#s033)


<a id="term-26"></a>

## 26 违约损失率

英文：Loss given default（LGD）。

条件于违约发生时，损失占相应风险敞口的比例。

- 论文用法：连接回收情景与损失估计。
- 易混边界：担保、回收时点和折现均可能影响估计。
- 依据与用例：[文献用例](../sources.md#s033)


<a id="term-27"></a>

## 27 违约风险敞口

英文：Exposure at default（EAD）。

违约时面临损失风险的债权敞口金额。

- 论文用法：与 PD 和 LGD 共同组织风险核算。
- 易混边界：简单乘积只是一种简化表达，完整 ECL 还含时间和情景结构。
- 依据与用例：[文献用例](../sources.md#s033)


<a id="term-28"></a>

## 28 资本比率

英文：Capital ratio。

指定资本量相对于指定资产或风险加权资产的比例。

- 论文用法：比较银行资本状态。
- 易混边界：必须写清分子分母，资本比率与高于要求的余量不同。
- 依据与用例：[文献用例](../sources.md#s033)


<a id="term-29"></a>

## 29 会计裁量

英文：Accounting discretion。

会计估计和分类中允许的判断空间。

- 论文用法：研究激励与报告行为。
- 易混边界：存在裁量或报告差异不能直接判定操纵或违规。
- 依据与用例：[文献用例](../sources.md#s033)


<a id="term-30"></a>

## 30 政策反事实

英文：Policy counterfactual。

在另一政策状态下可能出现的结果。

- 论文用法：评估政策净作用。
- 易混边界：它由设计或模型推断，不能当作额外观察样本。
- 依据与用例：[文献用例](../sources.md#s004)


<a id="term-31"></a>

## 31 社区情绪

英文：Community sentiment。

社区成员对某项目或议题的态度分布及表达。

- 论文用法：分析能源设施接受与反对。
- 易混边界：个体调查、公开发言和媒体材料覆盖不同集合。
- 依据与用例：[文献用例](../sources.md#s043)


<a id="term-32"></a>

## 32 公共叙事

英文：Public narrative。

公共空间中流通并组织事件意义的讲述。

- 论文用法：研究政策议题如何被理解和传播。
- 易混边界：出现频率不等于总体支持比例。
- 依据与用例：[文献用例](../sources.md#s043)
