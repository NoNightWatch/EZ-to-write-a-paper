# 心理、组织、传播与人文

共 28 条。条目包括阅读用释义、论文用法及易混边界。文献用例提供相关研究入口，具体操作定义和公式须按原文判断；不能把每个用例都当作规范定义的首次来源。

## 01 主观幸福感

英文：Subjective well-being（SWB）。

人对生活及情感体验的主观评价。

- 论文用法：研究幸福感与行为或环境的联系。
- 易混边界：即时情绪、生活满意度和总体幸福感需按量表区分。
- 依据与用例：[文献用例](../sources.md#s020)


<a id="term-02"></a>

## 02 亲社会支出

英文：Prosocial spending。

把金钱用于他人或公益的支出。

- 论文用法：比较支出对象与幸福感变化。
- 易混边界：支出动机、金额及观察窗口限制结论范围。
- 依据与用例：[文献用例](../sources.md#s020)


<a id="term-03"></a>

## 03 自我报告

英文：Self-report。

由研究对象直接报告自身体验或行为的数据。

- 论文用法：测量主观感受及部分经历。
- 易混边界：回忆、措辞和社会期许会影响读数；并非因此完全无效。
- 依据与用例：[文献用例](../sources.md#s020)


<a id="term-04"></a>

## 04 情绪效价

英文：Affective valence。

体验或评价的正负性质。

- 论文用法：组织愉悦与不愉悦的关系。
- 易混边界：正负与强弱不同，效价也不等于唤醒程度。
- 依据与用例：[文献用例](../sources.md#s045)


<a id="term-05"></a>

## 05 愉悦

英文：Pleasure。

具有正性享乐性质的心理体验。

- 论文用法：分析体验的性质及对立关系。
- 易混边界：Massin 的哲学用法比特定实验量表更宽。
- 依据与用例：[文献用例](../sources.md#s045)


<a id="term-06"></a>

## 06 不愉悦

英文：Unpleasure。

负性享乐体验的统称。

- 论文用法：区分快乐的极性对立项。
- 易混边界：疼痛只是相关体验的一部分，不能覆盖全部不愉悦。
- 依据与用例：[文献用例](../sources.md#s045)


<a id="term-07"></a>

## 07 享乐中性

英文：Hedonic indifference。

既无愉悦也无不愉悦的体验状态。

- 论文用法：Massin 以 indolence 指此中性状态。
- 易混边界：该作者用语不可直接译成日常意义的懒惰。
- 依据与用例：[文献用例](../sources.md#s045)


<a id="term-08"></a>

## 08 相反关系

英文：Contrariety。

按指定承载对象与条件不能同时成立的性质关系。

- 论文用法：进行哲学概念区分。
- 易混边界：两个相反项可以同时不成立，需检查定义范围。
- 依据与用例：[文献用例](../sources.md#s045)


<a id="term-09"></a>

## 09 矛盾关系

英文：Contradiction。

命题与其否定之间的关系，在经典逻辑中不能同真或同假。

- 论文用法：区分“愉悦”与“非愉悦”。
- 易混边界：非愉悦还可包含中性，不能直接等于不愉悦。
- 依据与用例：[文献用例](../sources.md#s045)


<a id="term-10"></a>

## 10 构念

英文：Construct。

为解释现象而界定的理论概念。

- 论文用法：组织幸福感、身份或图式等研究对象。
- 易混边界：一个测量分数只体现构念的一种操作化。
- 依据与用例：[文献用例](../sources.md#s060)


<a id="term-11"></a>

## 11 框架化

英文：Framing。

突出某些问题面向并组织其解释的过程。

- 论文用法：分析同一设施如何被描述为不同公共议题。
- 易混边界：框架内容及传播强度与总体态度比例分开。
- 依据与用例：[文献用例](../sources.md#s043)


<a id="term-12"></a>

## 12 社会规范

英文：Social norm。

群体对行为的共享期待及相应认可或制裁。

- 论文用法：解释工作和表达中的约束。
- 易混边界：正式制度、实际行为频率与规范性期待可不同。
- 依据与用例：[文献用例](../sources.md#s060)


<a id="term-13"></a>

## 13 认知图式

英文：Schema。

组织经验、解释和行动的认知结构。

- 论文用法：分析人如何理解好工作和工作边界。
- 易混边界：图式可由行动推断，不能当作已直接观测的脑结构。
- 依据与用例：[文献用例](../sources.md#s060)


<a id="term-14"></a>

## 14 理想员工规范

英文：Ideal worker norm。

把高度投入、持续可用等作为好员工标准的期待。

- 论文用法：研究工作生活关系。
- 易混边界：具体表现随组织和职业变化。
- 依据与用例：[文献用例](../sources.md#s060)


<a id="term-15"></a>

## 15 可持续员工图式

英文：Sustainable worker schema。

Heaphy 与 Trefalt 描述的兼顾工作成果和工作过程的图式。

- 论文用法：解释案例中绩效与生活边界的共同安排。
- 易混边界：属于研究归纳的概念，不能默认适用于所有行业。
- 依据与用例：[文献用例](../sources.md#s060)


<a id="term-16"></a>

## 16 共同演绎

英文：Co-enactment。

多人通过互动把某套图式落实并维持在实践中。

- 论文用法：解释边界安排为何依赖同事网络。
- 易混边界：与个人独立信念或正式政策的存在分别判断。
- 依据与用例：[文献用例](../sources.md#s060)


<a id="term-17"></a>

## 17 边界工作

英文：Boundary work。

建立、协商和维护某类区分的实践。

- 论文用法：本文涉及工作及工作生活边界。
- 易混边界：不同学科可能指专业边界、知识边界等，需说明对象。
- 依据与用例：[文献用例](../sources.md#s060)


<a id="term-18"></a>

## 18 弹性污名

英文：Flexibility stigma。

利用灵活工作安排可能遭到负面评价的现象。

- 论文用法：解释为何边界实践被隐藏。
- 易混边界：有弹性制度不保证实际使用者免于负面后果。
- 依据与用例：[文献用例](../sources.md#s060)


<a id="term-19"></a>

## 19 社会归因

英文：Social attribution。

社会互动中把事件、贡献或创新与行动者联系起来的过程。

- 论文用法：分析谁被持续认作创新者。
- 易混边界：被承认的贡献与技术贡献总量可能不同。
- 依据与用例：[文献用例](../sources.md#s056)


<a id="term-20"></a>

## 20 功劳分配

英文：Credit allocation。

把贡献的认可分配给不同参与者。

- 论文用法：研究创新和知识生产的认可。
- 易混边界：credit 在这里指功劳，与会计中的信用风险不同。
- 依据与用例：[文献用例](../sources.md#s056)


<a id="term-21"></a>

## 21 微观史

英文：Microhistory。

深入研究特定小尺度历史案例以解释更广过程的取向。

- 论文用法：重建人物、事件和制度联系。
- 易混边界：细节丰富不能单独保证总体代表性。
- 依据与用例：[文献用例](../sources.md#s056)


<a id="term-22"></a>

## 22 质性编码

英文：Qualitative coding。

给材料片段标注分析概念并组织比较。

- 论文用法：从访谈或档案建立类别和关系。
- 易混边界：编码规则、研究者解释和材料语境需保留。
- 依据与用例：[文献用例](../sources.md#s010)


<a id="term-23"></a>

## 23 主题

英文：Theme。

由分析形成的具有意义联系的模式。

- 论文用法：综合不同材料中的共同问题。
- 易混边界：高频词与主题不同；各质性传统的判定标准也不同。
- 依据与用例：[文献用例](../sources.md#s010)


<a id="term-24"></a>

## 24 编码饱和

英文：Code saturation。

继续收集材料时，新议题或编码出现趋少的状态。

- 论文用法：判断已识别的问题范围。
- 易混边界：主题种类大致齐全不代表已理解其全部内涵。
- 依据与用例：[文献用例](../sources.md#s010)


<a id="term-25"></a>

## 25 意义饱和

英文：Meaning saturation。

对已知议题的差异、条件和细节获得充分理解。

- 论文用法：评价解释深度。
- 易混边界：达到时间依目标与样本而变，文中访谈数不能作为通用阈值。
- 依据与用例：[文献用例](../sources.md#s010)


<a id="term-26"></a>

## 26 三角互证

英文：Triangulation。

把不同材料、方法或观察角度用于交叉核对。

- 论文用法：检验历史过程与解释的一致性。
- 易混边界：来源共享偏差时，一致结果仍非独立确认。
- 依据与用例：[文献用例](../sources.md#s056)


<a id="term-27"></a>

## 27 虚拟展开

英文：Virtual unwrapping。

从体积成像中重建卷曲材料表面并计算展开。

- 论文用法：读取无法直接展开的古代卷轴。
- 易混边界：几何展开、墨迹识别和文字解读是不同证据环节。
- 依据与用例：[文献用例](../sources.md#s029)


<a id="term-28"></a>

## 28 图像分割

英文：Image segmentation。

把图像或体积中的不同对象区域分开标识。

- 论文用法：在卷轴中定位纸草层与表面。
- 易混边界：分割误差会传递到展开与阅读，图像清楚也不保证释读正确。
- 依据与用例：[文献用例](../sources.md#s029)
