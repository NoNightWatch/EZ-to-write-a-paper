# 土壤与微生物生态

共 50 条。条目包括阅读用释义、论文用法及易混边界。文献用例提供相关研究入口，具体操作定义和公式须按原文判断；不能把每个用例都当作规范定义的首次来源。

<a id="term-01"></a>

## 01 土壤有机碳

英文：Soil organic carbon（SOC）。

土壤有机物所含的碳。

- 论文用法：讨论土壤碳库大小与变化。
- 易混边界：浓度和单位面积储量不同；比较需说明深度与土壤质量。
- 依据与用例：[文献用例](../sources.md#s028)


<a id="term-02"></a>

## 02 土壤有机质

英文：Soil organic matter（SOM）。

土壤中来自生物的有机组分整体。

- 论文用法：连接分解、养分与结构。
- 易混边界：SOM 质量不等于 SOC 质量，固定换算比例需验证。
- 依据与用例：[文献用例](../sources.md#s054)


<a id="term-03"></a>

## 03 微生物生物量碳

英文：Microbial biomass carbon（MBC）。

研究定义及方法覆盖的微生物生物量中的碳。

- 论文用法：作为碳库或生物量归一化分母。
- 易混边界：提取与换算系数会改变估计，不能直接当作活跃生物量。
- 依据与用例：[文献用例](../sources.md#s047)


<a id="term-04"></a>

## 04 摄取

英文：Uptake。

物质进入细胞的过程或数量。

- 论文用法：构造微生物碳收支。
- 易混边界：培养液中底物消失也可能来自吸附等过程。
- 依据与用例：[文献用例](../sources.md#s028)


<a id="term-05"></a>

## 05 同化

英文：Assimilation。

底物进入生物合成相关代谢的过程，具体记账依作者定义。

- 论文用法：说明底物碳如何进入前体与产物。
- 易混边界：Geyer 框架计入相关合成呼吸，须查其原表。
- 依据与用例：[文献用例](../sources.md#s028)


<a id="term-06"></a>

## 06 总生物量生产

英文：Gross biomass production。

观测期内新形成的生物量，尚未扣除死亡等损失。

- 论文用法：估计合成投入。
- 易混边界：生物量库存差是净变化，不能直接替代总生产。
- 依据与用例：[文献用例](../sources.md#s028)


<a id="term-07"></a>

## 07 净生物量增加

英文：Net biomass growth。

生物量形成与损失相抵后的增加。

- 论文用法：解释一段时间后库存改变。
- 易混边界：若存在迁入迁出，库存变化还需计入输运。
- 依据与用例：[文献用例](../sources.md#s028)


<a id="term-08"></a>

## 08 比生长速率

英文：Specific growth rate（µ）。

按生物量或细胞数归一化的增长速率，单位为时间的倒数。

- 论文用法：比较不同大小种群的增长快慢。
- 易混边界：需标明总生产还是净增殖、分母及估计窗口。
- 依据与用例：[文献用例](../sources.md#s047)


<a id="term-09"></a>

## 09 碳利用效率

英文：Carbon use efficiency（CUE）。

摄入碳中进入指定生物合成产物的比例。

- 论文用法：比较碳在生物合成与其他去向间的分配。
- 易混边界：先说明分子含不含分泌物、是否扣死亡及时间窗。
- 依据与用例：[文献用例](../sources.md#s028)


<a id="term-10"></a>

## 10 细菌生长效率

英文：Bacterial growth efficiency（BGE）。

常用细菌生产除以生产与呼吸之和。

- 论文用法：联系细菌碳生产和呼吸。
- 易混边界：缺少的分泌、周转或其他碳去向决定其与 CUE 的关系。
- 依据与用例：[文献用例](../sources.md#s028)


<a id="term-11"></a>

## 11 呼吸

英文：Respiration。

代谢中的能量转化过程；土壤研究常用 CO₂ 产生作读数。

- 论文用法：表征碳矿化及代谢。
- 易混边界：CO₂ 信号的来源与碳酸盐等非生物贡献需区分。
- 依据与用例：[文献用例](../sources.md#s054)


<a id="term-12"></a>

## 12 维持代谢

英文：Maintenance metabolism。

维持细胞功能所需的物质与能量消耗。

- 论文用法：解释无明显增长时仍有呼吸。
- 易混边界：不能把全部非增长呼吸无条件归为同一机制。
- 依据与用例：[文献用例](../sources.md#s028)


<a id="term-13"></a>

## 13 代谢商

英文：Metabolic quotient（qCO₂）。

常以单位 MBC 的呼吸速率表示。

- 论文用法：比较生物量归一化的碳释放。
- 易混边界：缺少生产项，单凭 qCO₂ 不能推出 CUE。
- 依据与用例：[文献用例](../sources.md#s028)


<a id="term-14"></a>

## 14 矿化

英文：Mineralisation。

有机元素转成无机形态的过程。

- 论文用法：如有机碳形成 CO₂。
- 易混边界：分解可先生成小分子有机物，尚未完成矿化。
- 依据与用例：[文献用例](../sources.md#s054)


<a id="term-15"></a>

## 15 解聚

英文：Depolymerisation。

大分子裂解成较小分子。

- 论文用法：连接胞外酶与可摄取底物。
- 易混边界：解聚产物可仍是有机碳，不能等同 CO₂ 排放。
- 依据与用例：[文献用例](../sources.md#s054)


<a id="term-16"></a>

## 16 胞外酶

英文：Extracellular enzyme。

在细胞外发挥催化功能的酶。

- 论文用法：连接资源获取与有机质分解。
- 易混边界：潜在酶活测定和原位真实通量需分别解释。
- 依据与用例：[文献用例](../sources.md#s054)


<a id="term-17"></a>

## 17 微生物残体

英文：Microbial necromass。

微生物死亡后留下的有机物。

- 论文用法：讨论微生物来源的土壤碳。
- 易混边界：形成量与保存量不同，标志物换算也含假设。
- 依据与用例：[文献用例](../sources.md#s028)


<a id="term-18"></a>

## 18 激发效应

英文：Priming effect（PE）。

新物质输入改变原有有机碳分解的现象。

- 论文用法：比较原有碳矿化相对对照的变化。
- 易混边界：总 CO₂ 增加也可由新加入底物产生。
- 依据与用例：[文献用例](../sources.md#s007)


<a id="term-19"></a>

## 19 表观激发效应

英文：Apparent priming effect。

额外 CO₂ 主要来自微生物自身碳周转等的情形。

- 论文用法：与原有 SOM 矿化改变作区分。
- 易混边界：命名依碳库边界；需要来源分离，不能凭呼吸曲线判定。
- 依据与用例：[文献用例](../sources.md#s007)


<a id="term-20"></a>

## 20 周转

英文：Turnover。

组分被产生、损失或替换的动态过程。

- 论文用法：估计碳库或分子的更新。
- 易混边界：周转量、周转率和周转时间分别有不同单位。
- 依据与用例：[文献用例](../sources.md#s028)


<a id="term-21"></a>

## 21 停留时间

英文：Residence time。

物质在指定系统内停留的时间尺度。

- 论文用法：比较碳的滞留。
- 易混边界：库存除以通量需稳态等条件；与年龄及半衰期不同。
- 依据与用例：[文献用例](../sources.md#s028)


<a id="term-22"></a>

## 22 稳定同位素探针

英文：Stable isotope probing（SIP）。

根据标记同位素进入生物分子的情况联系类群与物质利用。

- 论文用法：追踪某底物进入哪些生物群体。
- 易混边界：二次利用、分子类型和观察窗口影响解释。
- 依据与用例：[文献用例](../sources.md#s032)


<a id="term-23"></a>

## 23 定量稳定同位素探针

英文：Quantitative stable isotope probing（qSIP）。

估计各类群生物分子同位素富集程度的框架。

- 论文用法：利用密度变化推算类群特异的掺入。
- 易混边界：¹⁸O-DNA 掺入支持窗口内 DNA 合成，不能直接读作净增殖。
- 依据与用例：[文献用例](../sources.md#s032)


<a id="term-24"></a>

## 24 原子分数过量

英文：Atom fraction excess（AFE）。

标记样本的重同位素原子分数减去基线。

- 论文用法：表达相对天然丰度的富集。
- 易混边界：与 atom% 的数值尺度不同；0.1 分数等于 10 个百分点。
- 依据与用例：[文献用例](../sources.md#s032)


<a id="term-25"></a>

## 25 检出限

英文：Limit of detection（LOD）。

给定误报和漏检条件下可检出的信号或含量界限。

- 论文用法：解释未检出或低富集类群。
- 易混边界：未检出不证明过程为零，检出也不保证准确定量。
- 依据与用例：[文献用例](../sources.md#s049)


<a id="term-26"></a>

## 26 生物量与 DNA 换算系数

英文：Biomass carbon to DNA conversion factor。

把 DNA 量转成估计生物量碳的比例。

- 论文用法：用于部分 ¹⁸O 生长和 CUE 计算。
- 易混边界：全群落比例可能不代表实际发生 DNA 合成的子群体。
- 依据与用例：[文献用例](../sources.md#s047)


<a id="term-27"></a>

## 27 磷脂脂肪酸

英文：Phospholipid fatty acids（PLFA）。

细胞膜磷脂的脂肪酸组分。

- 论文用法：表征生物量代理及群落脂质剖面。
- 易混边界：标志物专一性有限，生理调节也会改变脂质比例。
- 依据与用例：[文献用例](../sources.md#s046)


<a id="term-28"></a>

## 28 群落组成

英文：Community composition。

群落中有哪些类群及其数量或比例。

- 论文用法：比较处理前后的类群格局。
- 易混边界：组成变化与功能变化可分离，需另测功能。
- 依据与用例：[文献用例](../sources.md#s057)


<a id="term-29"></a>

## 29 相对丰度

英文：Relative abundance。

某类群在选定总量中的比例。

- 论文用法：描述测序或群落组成。
- 易混边界：比例升高可由其他类群减少造成，不能单独证明绝对增长。
- 依据与用例：[文献用例](../sources.md#s051)


<a id="term-30"></a>

## 30 绝对丰度

英文：Absolute abundance。

每个规定样本单位中的数量。

- 论文用法：把类群比例转到数量尺度。
- 易混边界：基因拷贝、细胞数与生物量各有不同含义。
- 依据与用例：[文献用例](../sources.md#s008)


<a id="term-31"></a>

## 31 物种丰富度

英文：Species richness。

群落的物种数或分析单元数。

- 论文用法：描述多样性的种类维度。
- 易混边界：观测丰富度受取样完整度和分类分辨率影响。
- 依据与用例：[文献用例](../sources.md#s051)


<a id="term-32"></a>

## 32 均匀度

英文：Evenness。

各类群丰度分配的均等程度。

- 论文用法：区分优势种集中与较均匀分布。
- 易混边界：丰富度相同的群落可有不同均匀度。
- 依据与用例：[文献用例](../sources.md#s051)


<a id="term-33"></a>

## 33 Hill 数

英文：Hill numbers。

把多样性表达为有效物种数的一族指标。

- 论文用法：常比较阶数 q 为 0、1、2 的多样性谱。
- 易混边界：q 越大越侧重常见类群，需说明阶数和取样覆盖度。
- 依据与用例：[文献用例](../sources.md#s051)


<a id="term-34"></a>

## 34 取样覆盖度

英文：Sample coverage。

总体个体中属于样本已检出物种的比例。

- 论文用法：把不同群落比较到相近完整度。
- 易混边界：它与已检出物种占全部物种的比例不同。
- 依据与用例：[文献用例](../sources.md#s051)


<a id="term-35"></a>

## 35 稀释

英文：Rarefaction。

估计较小取样规模或特定覆盖度下的多样性。

- 论文用法：标准化多样性比较。
- 易混边界：不能补回全部未检出类群；外推需另列假设。
- 依据与用例：[文献用例](../sources.md#s051)


<a id="term-36"></a>

## 36 群落聚合

英文：Community coalescence。

原先分别存在的群落发生混合。

- 论文用法：研究成员及其既有互作如何共同进入新体系。
- 易混边界：与单一成员进入已有群落的情形区分。
- 依据与用例：[文献用例](../sources.md#s057)


<a id="term-37"></a>

## 37 群落层级选择

英文：Community-level selection。

群落整体差异与成员共同保留或淘汰相关的选择描述。

- 论文用法：Song 研究按亲本群落来源分析成员命运关联。
- 易混边界：该操作性证据不自动涵盖全部群体选择理论条件。
- 依据与用例：[文献用例](../sources.md#s057)


<a id="term-38"></a>

## 38 明确定义的群落

英文：Defined microbial community。

成员组成经明确界定的微生物群落。

- 论文用法：提高组成描述和重复研究的清晰度。
- 易混边界：成员已知不保证互作、功能及长期组成均已知。
- 依据与用例：[文献用例](../sources.md#s015)


<a id="term-39"></a>

## 39 合成菌群

英文：Synthetic microbial community（SynCom）。

常指研究者组装、成员已知的群落。

- 论文用法：作为可控生态研究体系。
- 易混边界：Koch 等建议使用 defined；领域仍并存多种命名。
- 依据与用例：[文献用例](../sources.md#s015)


<a id="term-40"></a>

## 40 交叉喂养

英文：Cross-feeding。

一个成员释放的代谢产物被另一个成员利用。

- 论文用法：解释资源传递与成员依赖。
- 易混边界：资源传递可单向，不能直接等同互利。
- 依据与用例：[文献用例](../sources.md#s054)


<a id="term-41"></a>

## 41 生物膜

英文：Biofilm。

具有群聚及基质关联等特征的微生物生活形式。

- 论文用法：讨论聚集、空间结构与群落生理。
- 易混边界：Sauer 综述纳入非表面附着聚集体，经典五阶段并非通式。
- 依据与用例：[文献用例](../sources.md#s053)


<a id="term-42"></a>

## 42 胞外聚合物

英文：Extracellular polymeric substances（EPS）。

胞外的多糖、蛋白、核酸等聚合物集合。

- 论文用法：描述生物膜基质与微环境。
- 易混边界：提取所得 EPS 依方法而变，不能视为单一化学物。
- 依据与用例：[文献用例](../sources.md#s053)


<a id="term-43"></a>

## 43 微生物活性

英文：Microbial activity。

微生物发生某种代谢、合成或行为过程的程度。

- 论文用法：以呼吸、RNA 或分子合成等代理描述不同侧面。
- 易混边界：需命名实际过程；一个阳性或阴性信号不能确定全部生理状态。
- 依据与用例：[文献用例](../sources.md#s052)


<a id="term-44"></a>

## 44 α 多样性

英文：Alpha diversity（α）。

指定局地样本或群落内部的多样性。

- 论文用法：比较局部群落。
- 易混边界：需同时说明空间尺度、分类单元和具体多样性指标。
- 依据与用例：[文献用例](../sources.md#s051)


<a id="term-45"></a>

## 45 β 多样性

英文：Beta diversity（β）。

群落之间组成差异或区域多样性的分解量。

- 论文用法：研究地点间替换和群落分化。
- 易混边界：距离指标、周转分量与 Hill 分解不是同一个数。
- 依据与用例：[文献用例](../sources.md#s051)


<a id="term-46"></a>

## 46 γ 多样性

英文：Gamma diversity（γ）。

多个局地群落合成的区域总体多样性。

- 论文用法：连接局地与区域尺度。
- 易混边界：区域边界和取样完整度会影响估计。
- 依据与用例：[文献用例](../sources.md#s051)


<a id="term-47"></a>

## 47 时间稳定性

英文：Temporal stability。

系统变量随时间保持少波动的程度。

- 论文用法：生态研究常用时间均值与标准差之比。
- 易混边界：趋势、采样长度及变量尺度影响结果，不能直接代替恢复能力。
- 依据与用例：[文献用例](../sources.md#s061)


<a id="term-48"></a>

## 48 生态抵抗力

英文：Ecological resistance。

扰动发生时系统偏离参照状态的程度所对应的抵抗能力。

- 论文用法：比较受扰时的即时响应。
- 易混边界：参照值和指标方向需定义，与宿主抗性不同。
- 依据与用例：[文献用例](../sources.md#s061)


<a id="term-49"></a>

## 49 恢复

英文：Recovery。

扰动后系统向参照状态返回的过程。

- 论文用法：比较恢复速率、程度或时间。
- 易混边界：几个指标不能互换，短期恢复也不保证长期轨迹一致。
- 依据与用例：[文献用例](../sources.md#s061)


<a id="term-50"></a>

## 50 韧性

英文：Resilience。

描述系统受扰后的保持或恢复能力，具体定义随理论而异。

- 论文用法：Isbell 等用受扰后给定时点接近未受扰水平的程度。
- 易混边界：其他文献可指返回速度或保持吸引域，须先核对定义。
- 依据与用例：[文献用例](../sources.md#s061)
