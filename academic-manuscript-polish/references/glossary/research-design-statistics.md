# 研究设计与统计

共 36 条。条目包括阅读用释义、论文用法及易混边界。文献用例提供相关研究入口，具体操作定义和公式须按原文判断；不能把每个用例都当作规范定义的首次来源。

<a id="term-01"></a>

## 01 目标估计量

英文：Estimand。

研究希望量化的总体特征或效应，即先说清要算什么。

- 论文用法：写明人群、处理、结局及时间窗。
- 易混边界：同一数据可服务不同目标；估计量与估计结果分开。
- 依据与用例：[文献用例](../sources.md#s004)


<a id="term-02"></a>

## 02 估计值

英文：Estimate。

把样本代入指定方法得到的数值。

- 论文用法：报告点估计及不确定性。
- 易混边界：数值依赖样本和方法；小标准误不能消除系统偏差。
- 依据与用例：[文献用例](../sources.md#s037)


<a id="term-03"></a>

## 03 操作化

英文：Operationalization。

把抽象概念转成可观测指标和判定规则。

- 论文用法：将活性落实为呼吸、RNA 或同位素掺入。
- 易混边界：换指标可能改变问题含义，须说明与概念的对应。
- 依据与用例：[文献用例](../sources.md#s028)


<a id="term-04"></a>

## 04 代理指标

英文：Proxy。

用可测变量间接代表目标，如专利引用代表部分技术影响。

- 论文用法：在直接测量困难时建立映射。
- 易混边界：代理可同时受其他机制影响，相关性不能保证等价。
- 依据与用例：[文献用例](../sources.md#s024)


<a id="term-05"></a>

## 05 实验单位

英文：Experimental unit。

被独立分配处理的最小单位。

- 论文用法：盆栽研究常以盆为单位。
- 易混边界：一盆取多个土样不会自动增加独立处理重复数。
- 依据与用例：[文献用例](../sources.md#s014)


<a id="term-06"></a>

## 06 生物学重复

英文：Biological replicate。

来自不同生物个体或独立生物样本的重复。

- 论文用法：估计生物层面的差异。
- 易混边界：是否独立还取决于采样、共同环境与层级设计。
- 依据与用例：[文献用例](../sources.md#s014)


<a id="term-07"></a>

## 07 技术重复

英文：Technical replicate。

对同一生物样本重复检测或处理。

- 论文用法：评估检测的随机波动。
- 易混边界：不能替代生物学重复；应区分误差所在层级。
- 依据与用例：[文献用例](../sources.md#s008)


<a id="term-08"></a>

## 08 随机分配

英文：Random assignment。

借助随机机制决定实验单位接受何种处理。

- 论文用法：支持组间处理效应比较。
- 易混边界：随机分配与随机抽样不同，前者不保证人群代表性。
- 依据与用例：[文献用例](../sources.md#s020)


<a id="term-09"></a>

## 09 对照组

英文：Control group。

为目标比较提供参照的组。

- 论文用法：区分处理效应和背景变化。
- 易混边界：空白、载体、未处理和阳性对照各自回答不同问题。
- 依据与用例：[文献用例](../sources.md#s037)


<a id="term-10"></a>

## 10 混杂变量

英文：Confounder。

同时影响处理或暴露与结局的共同原因。

- 论文用法：解释暴露与结局关联中的替代路径。
- 易混边界：并非所有相关协变量都该调整；控制碰撞变量可能引入偏差。
- 依据与用例：[文献用例](../sources.md#s004)


<a id="term-11"></a>

## 11 中介变量

英文：Mediator。

位于假设的处理到结局因果路径中的变量。

- 论文用法：分解效应可能经过的机制。
- 易混边界：统计中介分析依赖额外因果假设，路径图本身不证实机制。
- 依据与用例：[文献用例](../sources.md#s004)


<a id="term-12"></a>

## 12 调节变量

英文：Moderator。

使效应随背景而改变的变量。

- 论文用法：分析不同条件下效应大小或方向。
- 易混边界：交互依赖加法、乘法等尺度，应说明所用模型。
- 依据与用例：[文献用例](../sources.md#s037)


<a id="term-13"></a>

## 13 平均处理效应

英文：Average treatment effect（ATE）。

目标总体中个体处理效应的平均值。

- 论文用法：比较处理与未处理潜在结局的总体均值。
- 易混边界：样本效应、处理者效应和总体效应的目标群体可不同。
- 依据与用例：[文献用例](../sources.md#s004)


<a id="term-14"></a>

## 14 双重差分

英文：Difference-in-differences（DID）。

比较处理组前后变化与对照组前后变化的差。

- 论文用法：利用政策时点与受影响程度识别效应。
- 易混边界：公式可算不代表因果成立；平行趋势及同期冲击需审查。
- 依据与用例：[文献用例](../sources.md#s004)


<a id="term-15"></a>

## 15 平行趋势

英文：Parallel trends。

若处理未发生，两组平均结局变化应可比的假设。

- 论文用法：为 DID 提供反事实变化参照。
- 易混边界：处理前趋势相似有助判断，却不能证明处理后的反事实。
- 依据与用例：[文献用例](../sources.md#s004)


<a id="term-16"></a>

## 16 因果识别

英文：Causal identification。

在给定设计和假设下，观测信息能确定目标因果量。

- 论文用法：说明为何某比较可解释为干预效应。
- 易混边界：与变量筛选、分类识别及模型拟合分开。
- 依据与用例：[文献用例](../sources.md#s004)


<a id="term-17"></a>

## 17 相关

英文：Correlation。

变量共同变化的程度，Pearson 相关衡量线性关系。

- 论文用法：描述变量间模式。
- 易混边界：零线性相关仍可有非线性依赖；相关不能单独定因果方向。
- 依据与用例：[文献用例](../sources.md#s034)


<a id="term-18"></a>

## 18 回归

英文：Regression。

用协变量描述或估计结局的条件分布或条件均值。

- 论文用法：估计关联、预测或在设计支持下估计因果效应。
- 易混边界：回归系数含义依赖调整集、尺度与模型形式。
- 依据与用例：[文献用例](../sources.md#s034)


<a id="term-19"></a>

## 19 效应量

英文：Effect size。

差异或关联的大小，如均值差与标准化均值差。

- 论文用法：让结果回答影响有多大。
- 易混边界：应连同单位和区间报告；显著性不能替代效应大小。
- 依据与用例：[文献用例](../sources.md#s037)


<a id="term-20"></a>

## 20 p 值

英文：p-value。

在零假设及检验模型下，出现当前或更极端统计量的概率。

- 论文用法：衡量数据与指定零假设的不相容程度。
- 易混边界：不能读作零假设为真的概率，也不能读作效应重要性。
- 依据与用例：[NIST p 值定义](https://csrc.nist.gov/glossary/term/p_value)


<a id="term-21"></a>

## 21 置信区间

英文：Confidence interval（CI）。

按指定规则反复抽样时，以名义比例覆盖真参数的区间程序。

- 论文用法：描述估计精度。
- 易混边界：已算出的频率学区间不能直接赋予参数落入其中的概率。
- 依据与用例：[NIST 置信区间](https://www.itl.nist.gov/div898/handbook/prc/section1/prc14.htm)


<a id="term-22"></a>

## 22 标准误

英文：Standard error（SE）。

估计量在重复抽样中的标准差，通常由样本估计。

- 论文用法：表示均值或系数估计的精度。
- 易混边界：与观测值的离散程度 SD 分开，独立性假设影响计算。
- 依据与用例：[文献用例](../sources.md#s037)


<a id="term-23"></a>

## 23 标准差

英文：Standard deviation（SD）。

变量取值围绕均值的离散尺度。

- 论文用法：描述样本或总体的变异。
- 易混边界：扩大样本通常提高均值精度，不会让总体 SD 必然下降。
- 依据与用例：[文献用例](../sources.md#s037)


<a id="term-24"></a>

## 24 统计功效

英文：Statistical power。

指定真实效应与设计下，检验拒绝零假设的概率。

- 论文用法：设计样本量并评估可检测效应。
- 易混边界：功效属于效应、方差、样本量和检验规则的组合。
- 依据与用例：[文献用例](../sources.md#s037)


<a id="term-25"></a>

## 25 错误发现率

英文：False discovery rate（FDR）。

被判为阳性的结果中，错误阳性比例的期望值。

- 论文用法：管理多重检验的错误发现。
- 易混边界：与单次假阳性概率、至少一次误报概率不同。
- 依据与用例：[文献用例](../sources.md#s034)


<a id="term-26"></a>

## 26 自助法

英文：Bootstrap。

按某种重采样方案近似统计量抽样分布。

- 论文用法：构造效应量区间。
- 易混边界：配对、层级和时间数据需要匹配依赖结构的重采样。
- 依据与用例：[文献用例](../sources.md#s037)


<a id="term-27"></a>

## 27 元分析

英文：Meta-analysis。

按统计模型汇总多个研究或重复实验的效应估计。

- 论文用法：综合效应及不确定性。
- 易混边界：固定效应与随机效应假设不同，研究质量和可比性仍重要。
- 依据与用例：[文献用例](../sources.md#s037)


<a id="term-28"></a>

## 28 异质性

英文：Heterogeneity。

效应或结构在研究、群体、地点间存在差别。

- 论文用法：分析平均效应背后的差异。
- 易混边界：观测差异包含抽样误差；需区分真实效应变异。
- 依据与用例：[文献用例](../sources.md#s037)


<a id="term-29"></a>

## 29 参数可辨识性

英文：Parameter identifiability。

不同参数能否由可观测数据区分。

- 论文用法：判断曲线可否唯一约束参数组合。
- 易混边界：拟合良好仍可能有多套参数；结构与实际可辨识性分开。
- 依据与用例：[文献用例](../sources.md#s012)


<a id="term-30"></a>

## 30 敏感性分析

英文：Sensitivity analysis。

改变假设、参数或分析选择，查看结论如何变化。

- 论文用法：定位结果依赖的关键条件。
- 易混边界：只试少数替代设定不能覆盖全部可能偏差。
- 依据与用例：[文献用例](../sources.md#s047)


<a id="term-31"></a>

## 31 交叉验证

英文：Cross-validation（CV）。

轮换保留部分数据，用其评价其余数据训练的模型。

- 论文用法：估计样本外预测表现。
- 易混边界：分组、时间与空间边界须匹配未来应用场景。
- 依据与用例：[文献用例](../sources.md#s034)


<a id="term-32"></a>

## 32 过拟合

英文：Overfitting。

模型学入训练样本的偶然细节，降低样本外表现。

- 论文用法：解释训练误差低而新数据误差高。
- 易混边界：复杂度、样本量与验证设计需一起检查。
- 依据与用例：[文献用例](../sources.md#s034)


<a id="term-33"></a>

## 33 数据泄漏

英文：Data leakage。

验证或测试信息进入训练、特征选择或调参环节。

- 论文用法：审查预测评估是否独立。
- 易混边界：先全数据筛特征再交叉验证也会泄漏。
- 依据与用例：[文献用例](../sources.md#s034)


<a id="term-34"></a>

## 34 共线性

英文：Collinearity。

解释变量之间存在强线性依赖。

- 论文用法：解释系数不确定、变量可互相替代。
- 易混边界：预测可仍然良好，单变量效应解释却可能困难。
- 依据与用例：[文献用例](../sources.md#s034)


<a id="term-35"></a>

## 35 决定系数

英文：Coefficient of determination（R²）。

常见形式为相对指定基线减少的平方误差比例。

- 论文用法：量化拟合或预测表现。
- 易混边界：训练集高 R² 不保证外推；测试集 R² 可以为负。
- 依据与用例：[文献用例](../sources.md#s034)


<a id="term-36"></a>

## 36 外部效度

英文：External validity。

研究结论在目标之外人群、环境或时间中的适用程度。

- 论文用法：限定实验向自然系统或政策场景的推广。
- 易混边界：内部因果识别成立仍需要额外证据支持外推。
- 依据与用例：[文献用例](../sources.md#s020)
