# 植物、进化与生命史

共 32 条。条目包括阅读用释义、论文用法及易混边界。文献用例提供相关研究入口，具体操作定义和公式须按原文判断；不能把每个用例都当作规范定义的首次来源。

<a id="term-01"></a>

## 01 根际

英文：Rhizosphere。

受根系活动影响的土壤区域。

- 论文用法：研究根系与微生物及养分的联系。
- 易混边界：根际范围依采样定义，不能与全部根周土统一替换。
- 依据与用例：[文献用例](../sources.md#s014)


<a id="term-02"></a>

## 02 根鞘

英文：Rhizosheath。

紧密黏附根表的土壤结构。

- 论文用法：测定根黏土量及相关化学组分。
- 易混边界：根鞘是结构性对象，根际是影响范围。
- 依据与用例：[文献用例](../sources.md#s014)


<a id="term-03"></a>

## 03 根系分泌物

英文：Root exudates。

由根系释放到周围环境的物质。

- 论文用法：连接植物碳投入与养分动员。
- 易混边界：与脱落细胞、死亡根等广义根际沉积区分。
- 依据与用例：[文献用例](../sources.md#s014)


<a id="term-04"></a>

## 04 羧酸根

英文：Carboxylates。

含去质子化羧基的化合物或离子。

- 论文用法：解释根系相关的矿物元素动员。
- 易混边界：检测到积累量不能直接推出释放通量或单一因果机制。
- 依据与用例：[文献用例](../sources.md#s014)


<a id="term-05"></a>

## 05 间作

英文：Intercropping。

同一地块或容器内在重叠时段种植多种作物。

- 论文用法：研究物种间资源互补与竞争。
- 易混边界：混种效应要与密度、配置和单作参照一起解释。
- 依据与用例：[文献用例](../sources.md#s014)


<a id="term-06"></a>

## 06 促进作用

英文：Facilitation。

一个生物改善另一个生物表现的作用。

- 论文用法：研究邻体改变资源或微环境。
- 易混边界：效应可单向，也可随环境改变方向。
- 依据与用例：[文献用例](../sources.md#s014)


<a id="term-07"></a>

## 07 功能性状

英文：Functional trait。

与生物表现或生态过程相关的可测特征。

- 论文用法：用根、叶或生理特征解释策略差异。
- 易混边界：性状与功能的关系需在给定环境中验证。
- 依据与用例：[文献用例](../sources.md#s014)


<a id="term-08"></a>

## 08 表型可塑性

英文：Phenotypic plasticity。

同一基因型在不同环境下形成不同表型的能力。

- 论文用法：解释环境诱导的生理或形态变化。
- 易混边界：群体均值改变也可来自基因型组成变化。
- 依据与用例：[文献用例](../sources.md#s014)


<a id="term-09"></a>

## 09 系统发育

英文：Phylogeny。

谱系之间的演化关系。

- 论文用法：用分支结构组织亲缘和性状比较。
- 易混边界：基因树、物种树及网状基因交流可能不同。
- 依据与用例：[文献用例](../sources.md#s002)


<a id="term-10"></a>

## 10 演化支

英文：Clade。

共同祖先及其全部后代构成的群体。

- 论文用法：界定系统分类单元。
- 易混边界：形态相似或名称相近不足以判定同属一支。
- 依据与用例：[文献用例](../sources.md#s002)


<a id="term-11"></a>

## 11 单系性

英文：Monophyly。

一个类群包含其共同祖先及全部后代的性质。

- 论文用法：评价分类范围与树结构是否一致。
- 易混边界：排除某些后代会形成并系情形。
- 依据与用例：[文献用例](../sources.md#s002)


<a id="term-12"></a>

## 12 祖先状态重建

英文：Ancestral state reconstruction。

借树及现生或化石信息推断祖先性状。

- 论文用法：讨论性状何时获得或丢失。
- 易混边界：结论受树、模型与取样限制，属于推断。
- 依据与用例：[文献用例](../sources.md#s002)


<a id="term-13"></a>

## 13 分子钟

英文：Molecular clock。

把序列演化量与时间联系起来的模型。

- 论文用法：估计谱系分化年代。
- 易混边界：速率可变化，日期依赖校准与替换模型。
- 依据与用例：[文献用例](../sources.md#s021)


<a id="term-14"></a>

## 14 化石校准

英文：Fossil calibration。

利用化石及地层证据约束分化时间。

- 论文用法：给分子钟加入时间信息。
- 易混边界：最早发现化石与真实起源时间不同，缺失证据需考虑保存。
- 依据与用例：[文献用例](../sources.md#s021)


<a id="term-15"></a>

## 15 分化时间

英文：Divergence time。

两个谱系从共同祖先分开的估计时间。

- 论文用法：组织演化事件顺序。
- 易混边界：基因分歧时间可早于物种分化；现代特征也可能后来出现。
- 依据与用例：[文献用例](../sources.md#s021)


<a id="term-16"></a>

## 16 驯化

英文：Domestication。

长期人类关联下，种群出现遗传和表型变化的过程。

- 论文用法：追踪作物或动物与野生亲缘的分离及交流。
- 易混边界：栽培、驯养与完整驯化过程不能简单等同。
- 依据与用例：[文献用例](../sources.md#s011)


<a id="term-17"></a>

## 17 基因流

英文：Gene flow。

遗传变异经繁殖进入另一种群。

- 论文用法：解释群体间遗传联系。
- 易混边界：个体移动后未贡献后代时，不一定形成基因流。
- 依据与用例：[文献用例](../sources.md#s011)


<a id="term-18"></a>

## 18 基因渐渗

英文：Introgression。

经杂交及后续回交，遗传成分进入另一谱系。

- 论文用法：解释栽培与野生类群的遗传混合。
- 易混边界：一次杂交与持续遗传渗入要分开。
- 依据与用例：[文献用例](../sources.md#s011)


<a id="term-19"></a>

## 19 种群瓶颈

英文：Population bottleneck。

种群有效大小在一段时期内显著降低。

- 论文用法：解释遗传多样性和频率谱。
- 易混边界：驯化不必经历同样强度的瓶颈，需用数据判断。
- 依据与用例：[文献用例](../sources.md#s011)


<a id="term-20"></a>

## 20 遗传漂变

英文：Genetic drift。

有限种群中由随机传递造成的等位基因频率变化。

- 论文用法：与选择共同解释变异分布。
- 易混边界：频率改变并不自动说明适应。
- 依据与用例：[文献用例](../sources.md#s023)


<a id="term-21"></a>

## 21 有效种群大小

英文：Effective population size（Ne）。

与指定遗传过程等效的理想种群大小。

- 论文用法：表达漂变、近交等过程的强度。
- 易混边界：与实际个体数不同，不同估计方式对应不同时间尺度。
- 依据与用例：[文献用例](../sources.md#s023)


<a id="term-22"></a>

## 22 适合度

英文：Fitness。

在指定环境和比较框架下对后代的贡献。

- 论文用法：连接遗传变异与繁殖成功。
- 易混边界：生长速率、存活或产种量常是代理，需说明完整生命史。
- 依据与用例：[文献用例](../sources.md#s023)


<a id="term-23"></a>

## 23 选择系数

英文：Selection coefficient（s）。

相对于参考基因型的适合度差异参数。

- 论文用法：估计变异受选择的方向和强度。
- 易混边界：符号约定不同；环境、显性及频率依赖会改变含义。
- 依据与用例：[文献用例](../sources.md#s023)


<a id="term-24"></a>

## 24 显性系数

英文：Dominance coefficient（h）。

描述杂合子效应相对于两个纯合子的程度。

- 论文用法：把等位基因效应映射到基因型适合度。
- 易混边界：常用 $1$、$1-hs$、$1-s$ 的记法须先定义参照。
- 依据与用例：[文献用例](../sources.md#s023)


<a id="term-25"></a>

## 25 突变负荷

英文：Mutation load。

有害突变导致的平均适合度降低。

- 论文用法：讨论有害变异与群体历史。
- 易混边界：预测有害位点数量不等于真实适合度损失。
- 依据与用例：[文献用例](../sources.md#s023)


<a id="term-26"></a>

## 26 生活史

英文：Life history。

生物生长、维持、繁殖及存活在生命过程中的安排。

- 论文用法：比较不同资源分配与状态转换。
- 易混边界：需指定物种及环境，不能由一个快慢指标代表全部策略。
- 依据与用例：[文献用例](../sources.md#s040)


<a id="term-27"></a>

## 27 权衡

英文：Trade-off。

改进一项表现伴随另一项代价的约束关系。

- 论文用法：解释生长、存活和繁殖的共同分配。
- 易混边界：负相关可有其他来源，权衡需机制或设计支持。
- 依据与用例：[文献用例](../sources.md#s040)


<a id="term-28"></a>

## 28 休眠

英文：Dormancy。

可逆的低活动或停止增长状态。

- 论文用法：解释暂时不贡献明显增长的存活储备。
- 易混边界：低信号、死亡与休眠不能只凭一个指标互相替换。
- 依据与用例：[文献用例](../sources.md#s040)


<a id="term-29"></a>

## 29 复苏

英文：Resuscitation。

休眠个体恢复较高活动或增长的过程。

- 论文用法：描述种子库重新参与群落动态。
- 易混边界：检测到某类群增加需区分原有细胞复苏与其他成员增长。
- 依据与用例：[文献用例](../sources.md#s040)


<a id="term-30"></a>

## 30 核糖体休眠

英文：Ribosome hibernation。

核糖体进入低翻译活性并受保护的状态。

- 论文用法：解释有 rRNA 储备却无强翻译信号。
- 易混边界：核糖体状态与整个细胞休眠并非一一对应。
- 依据与用例：[文献用例](../sources.md#s003)


<a id="term-31"></a>

## 31 扩散

英文：Dispersal。

个体或传播单元在地点之间移动。

- 论文用法：连接局地群落与区域物种库。
- 易混边界：移动、存活、建立和繁殖是不同环节。
- 依据与用例：[文献用例](../sources.md#s040)


<a id="term-32"></a>

## 32 微生物种子库

英文：Microbial seed bank。

有条件复苏的低活动或休眠个体储备。

- 论文用法：解释群落的时间延续性。
- 易混边界：DNA 检出集合还可包含死亡及胞外遗留信号。
- 依据与用例：[文献用例](../sources.md#s040)
