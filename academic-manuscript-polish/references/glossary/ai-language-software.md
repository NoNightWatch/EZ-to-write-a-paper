# AI、语言与软件工程

共 32 条。条目包括阅读用释义、论文用法及易混边界。文献用例提供相关研究入口，具体操作定义和公式须按原文判断；不能把每个用例都当作规范定义的首次来源。

## 01 词元

英文：Token。

文本经过分词规则得到的处理单位，可为词、子词或其他片段。

- 论文用法：描述序列长度和模型输入输出。
- 易混边界：token 数与字数、词数不同，依分词器而变。
- 依据与用例：[文献用例](../sources.md#s063)


<a id="term-02"></a>

## 02 语料库

英文：Corpus。

按特定目的收集的文本集合。

- 论文用法：提供语言统计或训练材料。
- 易混边界：来源、时期和筛选规则决定覆盖与偏差。
- 依据与用例：[文献用例](../sources.md#s062)


<a id="term-03"></a>

## 03 共现

英文：Co-occurrence。

语言单位在规定窗口或上下文中共同出现。

- 论文用法：构造分布式语义特征。
- 易混边界：窗口定义改变关系类型，不能直接读作同义。
- 依据与用例：[文献用例](../sources.md#s062)


<a id="term-04"></a>

## 04 分布假说

英文：Distributional hypothesis。

相近使用语境往往对应某些语义相似性。

- 论文用法：从语言使用统计构造意义表示。
- 易混边界：统计相似可含反义或主题相关，不能覆盖全部意义。
- 依据与用例：[文献用例](../sources.md#s062)


<a id="term-05"></a>

## 05 向量空间模型

英文：Vector space model（VSM）。

用向量表示词、文档或关系的模型。

- 论文用法：以空间关系组织语言信息。
- 易混边界：距离含义由特征、权重和训练目标决定。
- 依据与用例：[文献用例](../sources.md#s062)


<a id="term-06"></a>

## 06 嵌入

英文：Embedding。

把对象映射为向量等表示。

- 论文用法：支持语义比较与后续模型。
- 易混边界：向量邻近不必对应因果、同义或事实一致。
- 依据与用例：[文献用例](../sources.md#s063)


<a id="term-07"></a>

## 07 余弦相似度

英文：Cosine similarity。

以两向量夹角的余弦衡量方向相似。

- 论文用法：比较文本或词向量。
- 易混边界：不反映向量模长，零向量需特殊处理。
- 依据与用例：[文献用例](../sources.md#s062)


<a id="term-08"></a>

## 08 语义相似性

英文：Semantic similarity。

两个表达在意义上相近的程度。

- 论文用法：评价语义表征。
- 易混边界：与主题相关性不同；医生与医院相关却非同义。
- 依据与用例：[文献用例](../sources.md#s062)


<a id="term-09"></a>

## 09 语义相关性

英文：Semantic relatedness。

表达之间存在较广的意义联系。

- 论文用法：评估联想、主题或关系检索。
- 易混边界：相似性通常只是其中一类，基准标签需区分。
- 依据与用例：[文献用例](../sources.md#s062)


<a id="term-10"></a>

## 10 注意力

英文：Attention。

根据查询与键的关系，对值向量进行加权汇总的机制。

- 论文用法：建立序列位置间的信息交互。
- 易混边界：注意力权重不能直接当成因果解释或人类注意。
- 依据与用例：[文献用例](../sources.md#s063)


<a id="term-11"></a>

## 11 自注意力

英文：Self-attention。

查询、键和值来自同一序列表示的注意力。

- 论文用法：整合序列内部关系。
- 易混边界：是否能看未来位置还取决于遮罩。
- 依据与用例：[文献用例](../sources.md#s063)


<a id="term-12"></a>

## 12 多头注意力

英文：Multi-head attention。

并行在多个投影空间计算注意力后合并。

- 论文用法：表达多种关系。
- 易混边界：头数增加不保证收益，单头维度及计算预算也会变化。
- 依据与用例：[文献用例](../sources.md#s063)


<a id="term-13"></a>

## 13 位置编码

英文：Positional encoding。

向模型提供位置或顺序信息的表示。

- 论文用法：让序列模型利用顺序。
- 易混边界：训练长度内有效不自动保证长序列外推。
- 依据与用例：[文献用例](../sources.md#s063)


<a id="term-14"></a>

## 14 自回归

英文：Autoregressive modelling。

把联合序列概率分解为依赖先前部分的条件概率。

- 论文用法：逐步生成后续词元。
- 易混边界：训练时某些计算可并行，生成时仍可能逐步依赖。
- 依据与用例：[文献用例](../sources.md#s063)


<a id="term-15"></a>

## 15 因果遮罩

英文：Causal mask。

限制当前位置访问未来位置的计算规则。

- 论文用法：实现自回归预测所需信息边界。
- 易混边界：这里的 causal 表示序列可见性，不能等同因果识别。
- 依据与用例：[文献用例](../sources.md#s063)


<a id="term-16"></a>

## 16 预训练

英文：Pretraining。

在目标任务适配之前进行的模型训练阶段。

- 论文用法：提供可复用的参数起点。
- 易混边界：训练数据与目标会影响迁移能力及偏差。
- 依据与用例：[文献用例](../sources.md#s058)


<a id="term-17"></a>

## 17 微调

英文：Fine-tuning。

在已有模型基础上继续更新部分或全部可训练参数。

- 论文用法：适配任务或数据分布。
- 易混边界：与只改变输入提示的优化分别核算。
- 依据与用例：[文献用例](../sources.md#s058)


<a id="term-18"></a>

## 18 提示优化

英文：Prompt optimization。

调整指令、示例等输入组织以提高目标表现。

- 论文用法：改进固定模型或多阶段程序。
- 易混边界：反复用测试集挑提示会使评估失去独立性。
- 依据与用例：[文献用例](../sources.md#s058)


<a id="term-19"></a>

## 19 损失函数

英文：Loss function。

训练或评估时衡量预测与目标差异的量。

- 论文用法：定义优化方向。
- 易混边界：损失降低不保证每项用户关心的能力都提高。
- 依据与用例：[文献用例](../sources.md#s063)


<a id="term-20"></a>

## 20 模型参数

英文：Model parameter。

模型中由训练学习或估计的内部数值。

- 论文用法：报告模型大小与训练更新范围。
- 易混边界：参数量不等于实际推理算量或功能质量。
- 依据与用例：[文献用例](../sources.md#s063)


<a id="term-21"></a>

## 21 超参数

英文：Hyperparameter。

控制模型结构或训练过程、通常在外层选择的设置。

- 论文用法：如学习率、层数和批量大小。
- 易混边界：调参需要验证数据，不能把测试集作为持续选择依据。
- 依据与用例：[文献用例](../sources.md#s063)


<a id="term-22"></a>

## 22 基准评测

英文：Benchmark。

由任务、数据、评分与运行约定组成的比较框架。

- 论文用法：比较模型在规定条件下的表现。
- 易混边界：单个分数只能代表所覆盖任务及评分规则。
- 依据与用例：[文献用例](../sources.md#s048)


<a id="term-23"></a>

## 23 测试集

英文：Test set。

留作最终或独立评价的数据。

- 论文用法：估计未参与开发数据上的表现。
- 易混边界：重复按测试结果修改模型后，其独立性会减弱。
- 依据与用例：[文献用例](../sources.md#s034)


<a id="term-24"></a>

## 24 泛化

英文：Generalization。

从已见数据获得的能力适用于新数据。

- 论文用法：讨论模型迁移范围。
- 易混边界：同分布新样本与跨任务、跨环境推广难度不同。
- 依据与用例：[文献用例](../sources.md#s034)


<a id="term-25"></a>

## 25 分布漂移

英文：Distribution shift。

训练与应用中的数据或关系分布发生改变。

- 论文用法：解释性能变化。
- 易混边界：输入分布、标签比例及条件关系变化需分别定位。
- 依据与用例：[文献用例](../sources.md#s048)


<a id="term-26"></a>

## 26 项目反应理论

英文：Item response theory（IRT）。

用潜在能力与题目参数描述作答概率的模型族。

- 论文用法：tinyBenchmarks 用于估计完整基准分数。
- 易混边界：潜在能力取决于测量模型，题目代表性仍需验证。
- 依据与用例：[文献用例](../sources.md#s048)


<a id="term-27"></a>

## 27 智能体

英文：Agent。

在环境中根据观测选择行动的系统角色。

- 论文用法：描述模型、工具和反馈的闭环。
- 易混边界：“智能体”名称本身不说明自主程度或可靠性。
- 依据与用例：[文献用例](../sources.md#s066)


<a id="term-28"></a>

## 28 多智能体系统

英文：Multi-agent system（MAS）。

多个可交互智能体构成的系统。

- 论文用法：研究分工、通信和协调。
- 易混边界：多个模型调用并不自动产生有效协作。
- 依据与用例：[文献用例](../sources.md#s039)


<a id="term-29"></a>

## 29 工具调用

英文：Tool use。

通过外部工具执行查询、计算或动作。

- 论文用法：扩展模型与环境的交互。
- 易混边界：生成调用文本、实际执行和验证成功是不同状态。
- 依据与用例：[文献用例](../sources.md#s066)


<a id="term-30"></a>

## 30 编排

英文：Orchestration。

决定参与者、调用顺序、信息交接和停止条件的组织逻辑。

- 论文用法：比较工作流和团队结构。
- 易混边界：更多环节也带来成本与失效路径，须用对照评估。
- 依据与用例：[文献用例](../sources.md#s066)


<a id="term-31"></a>

## 31 通信协议

英文：Communication protocol。

规定参与者交换信息的格式、顺序及约束。

- 论文用法：支持多系统协作。
- 易混边界：格式兼容不保证语义一致或任务目标一致。
- 依据与用例：[文献用例](../sources.md#s039)


<a id="term-32"></a>

## 32 架构模式

英文：Architectural pattern。

对反复出现的系统组织问题提炼的结构安排。

- 论文用法：分析组件职责、依赖与交互。
- 易混边界：采用模式名称不能替代对实际约束和代价的说明。
- 依据与用例：[文献用例](../sources.md#s039)
