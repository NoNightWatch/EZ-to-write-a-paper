# 地球、气候与化学

共 30 条。条目包括阅读用释义、论文用法及易混边界。文献用例提供相关研究入口，具体操作定义和公式须按原文判断；不能把每个用例都当作规范定义的首次来源。

<a id="term-01"></a>

## 01 碳库

英文：Carbon reservoir。

给定边界内储存碳的集合及其数量。

- 论文用法：比较土壤、海洋或地质储库。
- 易混边界：库存大小与交换速度分别描述，须标明边界。
- 依据与用例：[文献用例](../sources.md#s005)


<a id="term-02"></a>

## 02 通量

英文：Flux。

单位时间穿过边界或发生转化的数量。

- 论文用法：描述海气 CO₂ 交换。
- 易混边界：总通量、净通量与单位面积通量的单位不同。
- 依据与用例：[文献用例](../sources.md#s005)


<a id="term-03"></a>

## 03 碳汇

英文：Carbon sink。

在给定时段净吸收碳的过程或系统。

- 论文用法：核算净吸收贡献。
- 易混边界：碳库存大不保证当前仍为净汇。
- 依据与用例：[文献用例](../sources.md#s005)


<a id="term-04"></a>

## 04 二氧化碳移除

英文：Carbon dioxide removal（CDR）。

人为从大气移除 CO₂ 并持久储存的活动。

- 论文用法：评价大气碳减少。
- 易混边界：海水中碳减少尚需海气交换补充证据；减排与移除分开记账。
- 依据与用例：[IPCC 二氧化碳移除](https://www.ipcc.ch/report/ar6/wg3/chapter/chapter-12/)


<a id="term-05"></a>

## 05 额外性

英文：Additionality。

相对无干预反事实新增的效果。

- 论文用法：判断碳移除中可归于干预的部分。
- 易混边界：总吸收量需扣除本来会发生的过程及相关排放。
- 依据与用例：[文献用例](../sources.md#s005)


<a id="term-06"></a>

## 06 储存持久性

英文：Storage durability。

被储存碳在指定时间跨度内保持隔离的程度。

- 论文用法：评价再释放风险。
- 易混边界：高初始吸收与长久储存各需独立证据。
- 依据与用例：[IPCC 二氧化碳移除](https://www.ipcc.ch/report/ar6/wg3/chapter/chapter-12/)


<a id="term-07"></a>

## 07 海气再平衡

英文：Air-sea CO₂ equilibration。

海水与大气之间 CO₂ 差异经交换逐步调整的过程。

- 论文用法：估算海洋干预向大气移除的传递。
- 易混边界：混合和输运可改变路径，不能直接假设即时平衡。
- 依据与用例：[文献用例](../sources.md#s005)


<a id="term-08"></a>

## 08 气候反馈

英文：Climate feedback。

初始气候变化引起的过程反过来改变该变化。

- 论文用法：分析放大或削弱作用。
- 易混边界：正负反馈指对变化方向的作用，不表示价值好坏。
- 依据与用例：[文献用例](../sources.md#s065)


<a id="term-09"></a>

## 09 辐射强迫

英文：Radiative forcing（RF）。

外部驱动变化造成的地球净辐射收支改变。

- 论文用法：比较不同驱动的能量影响，常用 W/m²。
- 易混边界：RF 与有效辐射强迫 ERF 的调整范围不同。
- 依据与用例：[IPCC 气候敏感度与反馈](https://www.ipcc.ch/report/ar6/wg1/chapter/chapter-7/)


<a id="term-10"></a>

## 10 平衡气候敏感度

英文：Equilibrium climate sensitivity（ECS）。

相对工业化前 CO₂ 持续加倍后的长期平衡全球增温。

- 论文用法：汇总气候反馈强度，通常以 K 或 °C 表示温差。
- 易混边界：与每单位强迫的敏感度参数、瞬态响应不同。
- 依据与用例：[IPCC 气候敏感度与反馈](https://www.ipcc.ch/report/ar6/wg1/chapter/chapter-7/)


<a id="term-11"></a>

## 11 反照率

英文：Albedo。

入射辐射被反射的比例。

- 论文用法：解释冰雪、云和地表的能量反馈。
- 易混边界：必须说明波段、空间尺度及晴空或全天条件。
- 依据与用例：[文献用例](../sources.md#s065)


<a id="term-12"></a>

## 12 稳定同位素

英文：Stable isotope。

同一元素中不发生可观测放射性衰变的同位素。

- 论文用法：作物质来源或过程示踪。
- 易混边界：稳定不等于高富集条件下对生物过程完全无影响。
- 依据与用例：[文献用例](../sources.md#s049)


<a id="term-13"></a>

## 13 同位素 δ 值

英文：Isotope delta value（δ）。

同位素比值相对指定标准的差异表示。

- 论文用法：用千分数比较天然同位素组成。
- 易混边界：写作 $\delta=(R_{\mathrm{sample}}/R_{\mathrm{standard}}-1)\times1000\,\text{‰}$，须注明标准和比值方向。
- 依据与用例：[文献用例](../sources.md#s044)


<a id="term-14"></a>

## 14 同位素分馏

英文：Isotope fractionation。

过程中不同同位素分配比例发生差异。

- 论文用法：解释来源与反应历史。
- 易混边界：分馏和多来源混合都能改变同位素组成。
- 依据与用例：[文献用例](../sources.md#s044)


<a id="term-15"></a>

## 15 地球化学代理

英文：Geochemical proxy。

用保存下来的化学信号间接推断历史状态。

- 论文用法：重建来源、温度或环境。
- 易混边界：校准、后期改变与多机制作用影响反演。
- 依据与用例：[文献用例](../sources.md#s044)


<a id="term-16"></a>

## 16 风化

英文：Weathering。

岩石矿物在环境中发生物理破碎及化学改变的过程。

- 论文用法：联系元素释放与物质循环。
- 易混边界：具体矿物、反应路径和后续碳命运决定净效应。
- 依据与用例：[文献用例](../sources.md#s044)


<a id="term-17"></a>

## 17 地幔

英文：Mantle。

地壳与地核之间以硅酸盐为主的地球层圈。

- 论文用法：研究水、熔融与地球深部循环。
- 易混边界：地幔存在空间异质性，局部样本不代表整体平均。
- 依据与用例：[文献用例](../sources.md#s044)


<a id="term-18"></a>

## 18 俯冲

英文：Subduction。

板块的一部分进入另一板块之下并向地球内部运动。

- 论文用法：研究表层物质进入深部。
- 易混边界：输入量和真正保留在深部的量需分开。
- 依据与用例：[文献用例](../sources.md#s044)


<a id="term-19"></a>

## 19 部分熔融

英文：Partial melting。

岩石只一部分转为熔体的过程。

- 论文用法：解释熔体与残余矿物的元素分配。
- 易混边界：熔体组成不能直接当作原始整体岩石组成。
- 依据与用例：[文献用例](../sources.md#s044)


<a id="term-20"></a>

## 20 名义无水矿物

英文：Nominally anhydrous minerals（NAMs）。

理想化学式不含水，却可在缺陷中容纳氢的矿物。

- 论文用法：估计地幔中的含氢储量。
- 易混边界：所谓矿物中的水常指结构性氢，不必是液态水。
- 依据与用例：[文献用例](../sources.md#s044)


<a id="term-21"></a>

## 21 催化剂

英文：Catalyst。

改变反应速率并在总体循环中再生的物质。

- 论文用法：解释可达反应路径。
- 易混边界：催化剂不改变给定温度下同一反应的热力学平衡常数。
- 依据与用例：[文献用例](../sources.md#s036)


<a id="term-22"></a>

## 22 配体

英文：Ligand。

与中心原子配位结合的物种。

- 论文用法：解释金属催化体系的反应性。
- 易混边界：同名 ligand 在受体生物学中另有结合对象。
- 依据与用例：[文献用例](../sources.md#s036)


<a id="term-23"></a>

## 23 交叉偶联

英文：Cross-coupling。

把不同反应组分的片段连接起来的一类反应。

- 论文用法：组织成键方法研究。
- 易混边界：名称只给出反应类别，具体机制与适用范围需独立证实。
- 依据与用例：[文献用例](../sources.md#s036)


<a id="term-24"></a>

## 24 底物适用范围

英文：Substrate scope。

方法在一组不同底物上的表现范围。

- 论文用法：展示官能团和结构兼容性。
- 易混边界：被测试成功的集合不能代表所有未测结构。
- 依据与用例：[文献用例](../sources.md#s036)


<a id="term-25"></a>

## 25 产率

英文：Yield。

得到的目标产物量相对理论量的比例。

- 论文用法：比较反应产出。
- 易混边界：分离产率、分析产率及校正方法需注明。
- 依据与用例：[文献用例](../sources.md#s036)


<a id="term-26"></a>

## 26 转化率

英文：Conversion。

起始反应物发生消耗的比例。

- 论文用法：描述反应物利用程度。
- 易混边界：转化率高仍可能生成很多副产物。
- 依据与用例：[文献用例](../sources.md#s036)


<a id="term-27"></a>

## 27 选择性

英文：Selectivity。

反应在竞争路径或产物间的偏向程度。

- 论文用法：比较区域、立体或化学选择性。
- 易混边界：须说明所选分母；选择性与产率不能互换。
- 依据与用例：[文献用例](../sources.md#s036)


<a id="term-28"></a>

## 28 核磁共振

英文：Nuclear magnetic resonance（NMR）。

利用原子核在磁场中的共振性质表征化学环境。

- 论文用法：辅助结构鉴定与部分定量。
- 易混边界：峰数、位移、积分和纯度需综合解释。
- 依据与用例：[文献用例](../sources.md#s036)


<a id="term-29"></a>

## 29 质谱

英文：Mass spectrometry（MS）。

按离子的质荷比检测并分析的技术。

- 论文用法：支持分子质量及碎片结构判断。
- 易混边界：信号强度受响应和离子化影响，未经校准不能等同浓度。
- 依据与用例：[文献用例](../sources.md#s036)


<a id="term-30"></a>

## 30 色谱

英文：Chromatography。

利用组分在固定相和流动相间行为差异进行分离的方法。

- 论文用法：分离产物或辅助含量测定。
- 易混边界：保留时间相同不单独证明化学身份。
- 依据与用例：[文献用例](../sources.md#s036)
