# 数学、物理与理论计算

共 32 条。条目包括阅读用释义、论文用法及易混边界。文献用例提供相关研究入口，具体操作定义和公式须按原文判断；不能把每个用例都当作规范定义的首次来源。

<a id="term-01"></a>

## 01 定义

英文：Definition。

明确一个对象或术语在讨论中如何使用。

- 论文用法：确定证明和模型的研究对象。
- 易混边界：定义本身不提供对象存在或结论成立的证明。
- 依据与用例：[文献用例](../sources.md#s064)


<a id="term-02"></a>

## 02 假设

英文：Assumption。

论证或模型预先要求成立的条件。

- 论文用法：限定定理与推导范围。
- 易混边界：数学模型假设和经验待检验假说需区分。
- 依据与用例：[文献用例](../sources.md#s016)


<a id="term-03"></a>

## 03 定理

英文：Theorem。

在明确假设和形式体系中已被证明的命题。

- 论文用法：报告严格结论。
- 易混边界：引用时应连同条件、量词与适用区间。
- 依据与用例：[文献用例](../sources.md#s064)


<a id="term-04"></a>

## 04 引理

英文：Lemma。

主要用于支持其他证明的已证命题。

- 论文用法：拆分复杂推导。
- 易混边界：名称不说明难度或重要性，有些引理承担核心工作。
- 依据与用例：[文献用例](../sources.md#s026)


<a id="term-05"></a>

## 05 证明

英文：Proof。

从给定前提按有效推理建立结论的过程。

- 论文用法：说明为何结论必然成立。
- 易混边界：数值例证和广泛测试不能替代一般性证明。
- 依据与用例：[文献用例](../sources.md#s064)


<a id="term-06"></a>

## 06 反例

英文：Counterexample。

满足命题前提却违反结论的实例。

- 论文用法：否定全称断言。
- 易混边界：落在定理假设之外的例子只能说明外推边界。
- 依据与用例：[文献用例](../sources.md#s016)


<a id="term-07"></a>

## 07 必要条件

英文：Necessary condition。

结论成立时必须满足的条件。

- 论文用法：排除不可能情形。
- 易混边界：满足必要条件仍未保证结论成立。
- 依据与用例：[文献用例](../sources.md#s064)


<a id="term-08"></a>

## 08 充分条件

英文：Sufficient condition。

满足后足以推出结论的条件。

- 论文用法：给出可保证结果的范围。
- 易混边界：条件不满足时，结论仍可能通过其他路径成立。
- 依据与用例：[文献用例](../sources.md#s064)


<a id="term-09"></a>

## 09 极限

英文：Limit。

对象在参数趋向指定状态时接近某一对象的关系。

- 论文用法：连接不同尺度的描述。
- 易混边界：双参数的迭代顺序、联合路径和拓扑都要说明。
- 依据与用例：[文献用例](../sources.md#s016)


<a id="term-10"></a>

## 10 渐近估计

英文：Asymptotic estimate。

描述参数趋于极限时量的增长或衰减。

- 论文用法：比较主阶与误差。
- 易混边界：渐近优势不保证有限样本或实际规模下领先。
- 依据与用例：[文献用例](../sources.md#s026)


<a id="term-11"></a>

## 11 大 O 记号

英文：Big-O notation（O）。

存在常数使目标量最终被某参照量的常数倍界住。

- 论文用法：报告时间复杂度或误差上界。
- 易混边界：隐藏常数可依赖哪些参数必须明确。
- 依据与用例：[文献用例](../sources.md#s026)


<a id="term-12"></a>

## 12 一致收敛

英文：Uniform convergence。

在指定定义域中，最大误差随极限过程趋零。

- 论文用法：支持对整个区间的控制。
- 易混边界：逐点收敛通常更弱，不能自动交换极限与其他运算。
- 依据与用例：[文献用例](../sources.md#s016)


<a id="term-13"></a>

## 13 测度

英文：Measure。

在规定集合族上以可列可加方式赋予大小的数学对象。

- 论文用法：推广长度、面积、体积和概率。
- 易混边界：测度为零与集合为空不同。
- 依据与用例：[文献用例](../sources.md#s064)


<a id="term-14"></a>

## 14 Hausdorff 维数

英文：Hausdorff dimension。

由任意小尺度覆盖及相应测度确定的维数。

- 论文用法：刻画集合的细尺度大小。
- 易混边界：满维集合仍可具有零 Lebesgue 测度。
- 依据与用例：[文献用例](../sources.md#s064)


<a id="term-15"></a>

## 15 Minkowski 维数

英文：Minkowski dimension。

通过固定尺度覆盖数或邻域体积增长定义的维数。

- 论文用法：研究尺度 δ 下集合占据多少空间。
- 易混边界：上、下维数可不同，与 Hausdorff 维数也未必相同。
- 依据与用例：[文献用例](../sources.md#s064)


<a id="term-16"></a>

## 16 Kakeya 集

英文：Kakeya set。

在每个方向都包含一条单位线段的集合。

- 论文用法：研究方向覆盖与集合维数。
- 易混边界：含所有方向的线段不要求包含任意位置的线段。
- 依据与用例：[文献用例](../sources.md#s064)


<a id="term-17"></a>

## 17 δ 管

英文：δ-tube。

围绕一定长度线段的细管状邻域。

- 论文用法：将方向问题转成有限尺度体积估计。
- 易混边界：长宽比及重叠条件直接影响估计。
- 依据与用例：[文献用例](../sources.md#s064)


<a id="term-18"></a>

## 18 粗粒化

英文：Coarse-graining。

保留较大尺度变量，汇总或忽略部分微观细节。

- 论文用法：连接微观状态与宏观描述。
- 易混边界：有效方程需要闭合或极限论证，信息损失本身不足以证明它。
- 依据与用例：[文献用例](../sources.md#s016)


<a id="term-19"></a>

## 19 动理学方程

英文：Kinetic equation。

描述粒子分布函数如何随输运及相互作用变化的方程。

- 论文用法：以中观层连接粒子与流体。
- 易混边界：分布函数演化与单条确定粒子轨道不同。
- 依据与用例：[文献用例](../sources.md#s016)


<a id="term-20"></a>

## 20 Boltzmann-Grad 极限

英文：Boltzmann-Grad limit。

粒子数增加、尺度减小并保持合适碰撞标度的稀薄极限。

- 论文用法：从硬球系统推导动理学。
- 易混边界：体积分数与碰撞频度有不同尺度，不能混作一个密度。
- 依据与用例：[文献用例](../sources.md#s016)


<a id="term-21"></a>

## 21 流体力学极限

英文：Hydrodynamic limit。

在适当尺度下由动理学或微观系统得到宏观流体方程。

- 论文用法：连接多个描述层级。
- 易混边界：初始条件、边界、缩放和解的光滑性限定结论。
- 依据与用例：[文献用例](../sources.md#s016)


<a id="term-22"></a>

## 22 混沌传播

英文：Propagation of chaos。

有限多个粒子的联合分布在极限中保持近似乘积结构。

- 论文用法：控制关联并导出动理学描述。
- 易混边界：这里的 chaos 与敏感依赖初值的动力学混沌含义不同。
- 依据与用例：[文献用例](../sources.md#s016)


<a id="term-23"></a>

## 23 信息熵

英文：Information entropy（H）。

离散情形为 $H=-\sum_i p_i\log p_i$，量化分布不确定性。

- 论文用法：组织概率推断。
- 易混边界：对数底决定单位；不能直接等同任意系统的物理熵。
- 依据与用例：[文献用例](../sources.md#s035)


<a id="term-24"></a>

## 24 最大熵原理

英文：Maximum entropy principle（MaxEnt）。

在给定约束下选取熵最大的概率分布。

- 论文用法：从有限已知信息构造统计描述。
- 易混边界：约束及状态空间决定答案，并非无假设推断。
- 依据与用例：[文献用例](../sources.md#s035)


<a id="term-25"></a>

## 25 配分函数

英文：Partition function（Z）。

汇总状态权重并提供归一化的函数。

- 论文用法：连接统计分布与热力学量。
- 易混边界：具体形式取决于系综、能量与自由度。
- 依据与用例：[文献用例](../sources.md#s035)


<a id="term-26"></a>

## 26 系综

英文：Ensemble。

满足指定宏观条件的一组可能微观状态及其概率描述。

- 论文用法：计算统计物理平均量。
- 易混边界：系综平均与单系统时间平均的等同需要条件。
- 依据与用例：[文献用例](../sources.md#s035)


<a id="term-27"></a>

## 27 Bell 不等式

英文：Bell inequality。

满足指定局域性、测量设置独立性等假设的关联统计必须遵守的约束。

- 论文用法：检验局域隐藏变量模型类别。
- 易混边界：违背不意味着可控的超光速通信，实验解释依赖各项假设。
- 依据与用例：[文献用例](../sources.md#s022)


<a id="term-28"></a>

## 28 量子纠缠

英文：Quantum entanglement。

复合系统状态不能表示为局域乘积态的概率混合。

- 论文用法：描述量子关联结构。
- 易混边界：纠缠、Bell 非定域性和普通相关各有不同判据。
- 依据与用例：[文献用例](../sources.md#s022)


<a id="term-29"></a>

## 29 条件复杂度下界

英文：Conditional complexity lower bound。

在某个复杂度假设成立时，算法所需资源的下限。

- 论文用法：解释为何某速度提升可能不成立。
- 易混边界：假设尚未证明时，下界也带该条件。
- 依据与用例：[文献用例](../sources.md#s026)


<a id="term-30"></a>

## 30 强指数时间假设

英文：Strong Exponential Time Hypothesis（SETH）。

粗略说，任意固定指数改进都无法统一适用于所有 k 的 k-SAT。

- 论文用法：作为细粒度复杂度规约的起点。
- 易混边界：它是关于最坏情况算法的假设，不是已证定理。
- 依据与用例：[文献用例](../sources.md#s026)


<a id="term-31"></a>

## 31 规约

英文：Reduction。

把一个问题实例转为另一问题实例并保留所需答案关系。

- 论文用法：传递算法或困难性。
- 易混边界：必须检查转换资源和参数，方向写反会改变结论。
- 依据与用例：[文献用例](../sources.md#s026)


<a id="term-32"></a>

## 32 近似最近邻

英文：Approximate nearest neighbor（ANN）。

放宽精确最近要求，以较低代价检索近邻。

- 论文用法：比较向量检索的速度与误差。
- 易混边界：经验召回率、概率误差界和最坏情况近似保证分别报告。
- 依据与用例：[文献用例](../sources.md#s027)
