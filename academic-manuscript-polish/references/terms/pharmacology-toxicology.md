# 药学与毒理学：基础术语

领域编号：m04。本册 40 条短释义，正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。本册用于阅读和表达，不提供诊断、用药、护理处置或实验操作建议。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>pharmacokinetics | 药代动力学 | 研究机体对药物处置的时间过程 |
| <a id="t02"></a>pharmacodynamics | 药效动力学 | 研究药物作用与效应的关系 |
| <a id="t03"></a>absorption | 药物吸收 | 药物进入系统循环等的过程 |
| <a id="t04"></a>distribution | 药物分布 | 药物在组织和体液中的转移 |
| <a id="t05"></a>metabolism | 药物代谢 | 机体对药物的化学转化 |
| <a id="t06"></a>excretion | 排泄 | 药物及代谢产物离开机体 |
| <a id="t07"></a>bioavailability | 生物利用度 | 药物到达系统循环的程度等表征 |
| <a id="t08"></a>clearance | 清除率 | 单位时间相当于被清除药物的体液体积 |
| <a id="t09"></a>volume of distribution | 表观分布容积 | 体内药量与浓度关系的表观体积 |
| <a id="t10"></a>elimination half-life | 消除半衰期 | 药物浓度按规定阶段减半的时间 |
| <a id="t11"></a>area under the curve | 曲线下面积 | 浓度时间曲线的累计暴露量度 |
| <a id="t12"></a>Cmax | 峰浓度 | 观察到或估计的最高药物浓度 |
| <a id="t13"></a>Tmax | 达峰时间 | 达到峰浓度的时间 |
| <a id="t14"></a>steady-state concentration | 稳态浓度 | 反复给药下规律性稳定的浓度水平 |
| <a id="t15"></a>dose-response relationship | 剂量反应关系 | 剂量与效应大小或概率的关系 |
| <a id="t16"></a>potency | 效价强度 | 产生规定效应所需剂量或浓度的尺度 |
| <a id="t17"></a>efficacy | 效能 | 药物能产生的效应能力 |
| <a id="t18"></a>agonist | 激动剂 | 结合受体并引发相应作用的配体 |
| <a id="t19"></a>antagonist | 拮抗剂 | 减弱或阻断受体相关作用的配体 |
| <a id="t20"></a>partial agonist | 部分激动剂 | 最大效应低于完全激动剂的配体 |
| <a id="t21"></a>affinity | 亲和力 | 配体与靶标结合的倾向 |
| <a id="t22"></a>selectivity | 药物选择性 | 药物对不同靶标作用的相对差异 |
| <a id="t23"></a>therapeutic window | 治疗窗 | 有效与不可接受毒性之间的暴露范围 |
| <a id="t24"></a>therapeutic index | 治疗指数 | 毒性与有效剂量等的规定比值 |
| <a id="t25"></a>off-target effect | 脱靶效应 | 作用于目标之外分子产生的效应 |
| <a id="t26"></a>drug interaction | 药物相互作用 | 一种药物改变另一种药物作用 |
| <a id="t27"></a>prodrug | 前药 | 经体内转化形成主要活性物质的药物 |
| <a id="t28"></a>active metabolite | 活性代谢物 | 仍具有药理作用的代谢产物 |
| <a id="t29"></a>formulation | 制剂配方 | 药物及辅料的组合与剂型安排 |
| <a id="t30"></a>excipient | 辅料 | 制剂中承担辅助功能的组分 |
| <a id="t31"></a>bioequivalence | 生物等效性 | 规定条件下药物暴露相似的判定 |
| <a id="t32"></a>pharmacovigilance | 药物警戒 | 监测和评估药物相关安全问题 |
| <a id="t33"></a>toxicity | 毒性 | 物质产生不利生物效应的能力 |
| <a id="t34"></a>hazard | 危害性 | 造成损害的内在可能性 |
| <a id="t35"></a>risk characterization | 风险表征 | 结合暴露和危害信息描述风险 |
| <a id="t36"></a>NOAEL | 未观察到不良效应水平 | 研究中未见不良效应的最高测试水平 |
| <a id="t37"></a>LOAEL | 最低观察到不良效应水平 | 研究中观察到不良效应的最低测试水平 |
| <a id="t38"></a>benchmark dose | 基准剂量 | 对应规定反应幅度的模型剂量 |
| <a id="t39"></a>genotoxicity | 遗传毒性 | 对遗传物质造成损害的性质 |
| <a id="t40"></a>toxicokinetics | 毒代动力学 | 研究毒性相关物质体内处置过程 |

## 使用时

缩写全称、计量基准、定义版本与稿件逐一对应。同名指标在不同学科可以有不同分母或时间范围。简释不替代正式定义。见 [教学示例](../worked-examples.md)。
