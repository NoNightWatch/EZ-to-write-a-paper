# 新闻与传播：基础术语

领域编号：s09。本册 40 条短释义；同一术语可随传统、流派或法域产生不同含义。未逐条外部审定；[来源属性](../foundation-sources.md)。法律词条仅作学术阅读对照。

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>communication | 传播 | 意义或信息在主体间形成与传递 |
| <a id="t02"></a>media | 媒介 | 承载和组织传播的技术与机构 |
| <a id="t03"></a>audience | 受众 | 接收解释或参与媒介内容的人群 |
| <a id="t04"></a>public sphere | 公共领域 | 围绕公共事务进行讨论的社会空间 |
| <a id="t05"></a>agenda-setting | 议程设置 | 媒介关注与公众议题关注的联系 |
| <a id="t06"></a>framing | 框架化 | 通过选择组织信息形成理解角度 |
| <a id="t07"></a>priming | 启动效应 | 先前信息影响后续判断标准等 |
| <a id="t08"></a>gatekeeping | 把关 | 筛选信息进入传播流程的过程 |
| <a id="t09"></a>newsworthiness | 新闻价值 | 事件被选择为新闻的相关属性 |
| <a id="t10"></a>editorial independence | 编辑独立性 | 编辑判断免受不当外部干预的程度 |
| <a id="t11"></a>source credibility | 信源可信度 | 受众对信息来源可靠性的判断 |
| <a id="t12"></a>media trust | 媒介信任 | 公众对媒介机构或内容的信赖 |
| <a id="t13"></a>media literacy | 媒介素养 | 理解分析和使用媒介的能力 |
| <a id="t14"></a>uses and gratifications | 使用与满足 | 从受众需求理解媒介使用的取向 |
| <a id="t15"></a>selective exposure | 选择性接触 | 偏向接触特定信息的行为 |
| <a id="t16"></a>media effects | 媒介效果 | 媒介接触与认知行为变化的关系 |
| <a id="t17"></a>cultivation | 涵化 | 长期媒介接触与现实观形成的联系 |
| <a id="t18"></a>spiral of silence | 沉默的螺旋 | 意见环境感知影响表达的理论概念 |
| <a id="t19"></a>two-step flow | 两级传播 | 经意见领袖中介的信息流动概念 |
| <a id="t20"></a>opinion leader | 意见领袖 | 在群体中影响他人判断的行动者 |
| <a id="t21"></a>diffusion of innovations | 创新扩散 | 创新在社会系统中传播和采纳 |
| <a id="t22"></a>networked publics | 网络化公众 | 通过网络媒介形成的公众群体 |
| <a id="t23"></a>platform affordance | 平台可供性 | 平台结构为行动提供的可能条件 |
| <a id="t24"></a>algorithmic curation | 算法策展 | 算法选择和排列可见内容 |
| <a id="t25"></a>engagement metric | 互动指标 | 衡量点击评论分享等参与的数量 |
| <a id="t26"></a>reach | 触达人数 | 内容接触到的不同受众数量 |
| <a id="t27"></a>impression | 展示次数 | 内容被显示的次数 |
| <a id="t28"></a>virality | 病毒式传播性 | 内容通过用户扩散快速传播的特征 |
| <a id="t29"></a>participatory culture | 参与式文化 | 用户积极创作分享协作的文化 |
| <a id="t30"></a>user-generated content | 用户生成内容 | 由普通使用者创作发布的内容 |
| <a id="t31"></a>misinformation | 错误信息 | 不论意图的错误或误导性信息 |
| <a id="t32"></a>disinformation | 蓄意虚假信息 | 有意传播的虚假或误导信息 |
| <a id="t33"></a>fact-checking | 事实核查 | 核对可验证陈述与依据的过程 |
| <a id="t34"></a>content analysis | 内容分析 | 系统编码和分析传播材料的方法 |
| <a id="t35"></a>discourse analysis | 话语分析 | 研究语言实践与意义关系的方法 |
| <a id="t36"></a>multimodal analysis | 多模态分析 | 联合分析文字图像声音等模式 |
| <a id="t37"></a>visual framing | 视觉框架 | 视觉材料组织问题理解的方式 |
| <a id="t38"></a>strategic communication | 战略传播 | 围绕组织目标协调传播活动 |
| <a id="t39"></a>public relations | 公共关系 | 组织与相关公众关系的管理 |
| <a id="t40"></a>crisis communication | 危机传播 | 危机情境中的信息与关系沟通 |
