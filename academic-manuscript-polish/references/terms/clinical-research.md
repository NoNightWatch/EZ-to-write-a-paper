# 临床研究：基础术语

领域编号：m02。本册 40 条短释义，正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。本册用于阅读和表达，不提供诊断、用药、护理处置或实验操作建议。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>clinical trial | 临床试验 | 前瞻性分配干预以研究健康结果 |
| <a id="t02"></a>observational study | 观察性研究 | 不由研究者分配目标干预的研究 |
| <a id="t03"></a>randomization | 随机分配 | 依据随机机制分配研究组别 |
| <a id="t04"></a>allocation concealment | 分配隐藏 | 防止提前预知将分配组别的措施 |
| <a id="t05"></a>blinding | 盲法 | 让特定参与者不知组别等信息 |
| <a id="t06"></a>placebo | 安慰剂 | 用于比较且缺少目标活性成分的处理 |
| <a id="t07"></a>comparator | 对照干预 | 用于比较研究干预的处理 |
| <a id="t08"></a>eligibility criteria | 入选资格标准 | 决定能否纳入研究的条件 |
| <a id="t09"></a>recruitment | 招募 | 接触并纳入研究参与者的过程 |
| <a id="t10"></a>informed consent | 知情同意 | 了解相关信息后自愿同意参与 |
| <a id="t11"></a>primary endpoint | 主要终点 | 预先指定的主要评价结果 |
| <a id="t12"></a>secondary endpoint | 次要终点 | 主要终点之外的预定评价结果 |
| <a id="t13"></a>surrogate endpoint | 替代终点 | 用于替代临床结果评价的指标 |
| <a id="t14"></a>composite endpoint | 复合终点 | 由多个结局事件组合的终点 |
| <a id="t15"></a>adverse event | 不良事件 | 参与期间出现的不利健康事件 |
| <a id="t16"></a>serious adverse event | 严重不良事件 | 符合死亡等规定严重性标准的事件 |
| <a id="t17"></a>adherence | 依从性 | 实际行为符合约定方案的程度 |
| <a id="t18"></a>protocol deviation | 方案偏离 | 实施过程与既定方案的差异 |
| <a id="t19"></a>intention-to-treat | 意向性分析 | 按原始分配组别进行分析的原则 |
| <a id="t20"></a>per-protocol analysis | 符合方案分析 | 针对符合规定方案条件者的分析 |
| <a id="t21"></a>follow-up | 随访 | 在后续时间追踪研究对象 |
| <a id="t22"></a>loss to follow-up | 失访 | 无法获得对象预定后续信息 |
| <a id="t23"></a>withdrawal | 退出 | 参与者停止研究参与 |
| <a id="t24"></a>interim analysis | 期中分析 | 研究完成前进行的计划分析 |
| <a id="t25"></a>noninferiority | 非劣效性 | 在预定界值内排除较差程度 |
| <a id="t26"></a>equivalence trial | 等效性试验 | 检验差异位于预定等效范围的试验 |
| <a id="t27"></a>superiority trial | 优效性试验 | 检验一项干预优于比较对象 |
| <a id="t28"></a>minimal important difference | 最小重要差异 | 对患者等具有意义的最小变化 |
| <a id="t29"></a>patient-reported outcome | 患者报告结局 | 由患者直接报告的健康结果 |
| <a id="t30"></a>quality of life | 生活质量 | 个人对生活状况等的综合体验 |
| <a id="t31"></a>hazard ratio | 风险率比 | 两组瞬时事件发生率的比值 |
| <a id="t32"></a>absolute risk reduction | 绝对风险降低 | 两组事件风险的绝对差 |
| <a id="t33"></a>number needed to treat | 需治疗人数 | 特定时段获一个额外获益所需人数 |
| <a id="t34"></a>diagnostic accuracy | 诊断准确性 | 检查识别目标状态的表现 |
| <a id="t35"></a>sensitivity | 灵敏度 | 有目标状态者中检出阳性的比例 |
| <a id="t36"></a>specificity | 特异度 | 无目标状态者中检出阴性的比例 |
| <a id="t37"></a>positive predictive value | 阳性预测值 | 检测阳性者实际具有目标状态的比例 |
| <a id="t38"></a>negative predictive value | 阴性预测值 | 检测阴性者实际无目标状态的比例 |
| <a id="t39"></a>reference standard | 参考标准 | 用于判定目标状态的比较依据 |
| <a id="t40"></a>trial registration | 试验注册 | 在公开注册平台记录试验信息 |

## 使用时

缩写全称、计量基准、定义版本与稿件逐一对应。同名指标在不同学科可以有不同分母或时间范围。简释不替代正式定义。见 [教学示例](../worked-examples.md)。
