# 基础医学：基础术语

领域编号：m01。本册 40 条短释义，正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。本册用于阅读和表达，不提供诊断、用药、护理处置或实验操作建议。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>anatomy | 解剖学 | 研究身体结构与关系的学科 |
| <a id="t02"></a>physiology | 生理学 | 研究生命体正常功能的学科 |
| <a id="t03"></a>histology | 组织学 | 研究组织微观结构的学科 |
| <a id="t04"></a>pathology | 病理学 | 研究疾病结构与功能变化的学科 |
| <a id="t05"></a>etiology | 病因学 | 研究疾病发生原因的领域 |
| <a id="t06"></a>pathogenesis | 发病过程 | 疾病形成与发展的过程 |
| <a id="t07"></a>lesion | 病变 | 局部组织或功能的异常改变 |
| <a id="t08"></a>inflammation | 炎症 | 机体对损伤等的组织反应 |
| <a id="t09"></a>edema | 水肿 | 组织间等液体异常积聚 |
| <a id="t10"></a>fibrosis | 纤维化 | 组织中纤维性基质过度沉积 |
| <a id="t11"></a>necrosis | 坏死 | 损伤相关的细胞或组织死亡 |
| <a id="t12"></a>atrophy | 萎缩 | 细胞组织或器官体积减小 |
| <a id="t13"></a>hypertrophy | 肥大 | 细胞体积增大导致组织增大 |
| <a id="t14"></a>hyperplasia | 增生 | 细胞数量增多 |
| <a id="t15"></a>metaplasia | 化生 | 一种成熟细胞类型被另一类型替代 |
| <a id="t16"></a>dysplasia | 异型增生 | 细胞及组织排列出现异常 |
| <a id="t17"></a>neoplasm | 肿瘤 | 异常增生形成的组织新生物 |
| <a id="t18"></a>benign | 良性 | 具有相对局限等特征的病变性质 |
| <a id="t19"></a>malignant | 恶性 | 具有侵袭等特征的肿瘤性质 |
| <a id="t20"></a>metastasis | 转移 | 肿瘤在原发部位之外形成病灶 |
| <a id="t21"></a>perfusion | 灌注 | 血液流经组织微循环 |
| <a id="t22"></a>ischemia | 缺血 | 局部供血不足 |
| <a id="t23"></a>hypoxia | 缺氧 | 组织氧供应或利用不足 |
| <a id="t24"></a>hematopoiesis | 造血 | 生成血细胞的过程 |
| <a id="t25"></a>hemostasis | 止血 | 限制血液流失的生理过程 |
| <a id="t26"></a>coagulation | 凝血 | 形成纤维蛋白凝块的过程 |
| <a id="t27"></a>innate immunity | 先天免疫 | 依赖固有识别系统的免疫防御 |
| <a id="t28"></a>adaptive immunity | 适应性免疫 | 具有抗原特异性及记忆特征的免疫 |
| <a id="t29"></a>antigen | 抗原 | 可被特异性免疫识别的物质 |
| <a id="t30"></a>antibody | 抗体 | 由 B 细胞谱系产生的识别分子 |
| <a id="t31"></a>cytokine | 细胞因子 | 调节细胞间通信的分泌性分子 |
| <a id="t32"></a>immune tolerance | 免疫耐受 | 对特定抗原保持低反应的状态 |
| <a id="t33"></a>autoimmunity | 自身免疫 | 针对自身成分的免疫反应 |
| <a id="t34"></a>endocrine | 内分泌 | 通过体液等传递激素的调节方式 |
| <a id="t35"></a>hormone | 激素 | 调节靶细胞活动的信号分子 |
| <a id="t36"></a>neuron | 神经元 | 接收和传递神经信息的细胞 |
| <a id="t37"></a>synapse | 突触 | 神经细胞间传递信息的连接 |
| <a id="t38"></a>neurotransmitter | 神经递质 | 在突触传递中作用的信号分子 |
| <a id="t39"></a>homeostatic regulation | 稳态调节 | 维持内环境相对稳定的调节 |
| <a id="t40"></a>organ system | 器官系统 | 共同完成生理功能的器官组合 |

## 使用时

缩写全称、计量基准、定义版本与稿件逐一对应。同名指标在不同学科可以有不同分母或时间范围。简释不替代正式定义。见 [教学示例](../worked-examples.md)。
