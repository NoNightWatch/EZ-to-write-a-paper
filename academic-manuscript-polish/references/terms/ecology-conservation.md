# 生态与保护：基础术语

领域编号：n09。本册 40 条短释义，用于阅读定位和中英用语对照。正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>organism | 个体生物 | 作为独立生命单位的生物体 |
| <a id="t02"></a>population ecology | 种群生态学 | 研究同种个体集合动态的领域 |
| <a id="t03"></a>community | 群落 | 一定区域内相互共存的种群集合 |
| <a id="t04"></a>ecosystem | 生态系统 | 生物群落及其非生物环境整体 |
| <a id="t05"></a>habitat | 生境 | 生物生活的环境 |
| <a id="t06"></a>niche | 生态位 | 物种利用条件及生态关系的位置 |
| <a id="t07"></a>species richness | 物种丰富度 | 指定范围内的物种数量 |
| <a id="t08"></a>species evenness | 物种均匀度 | 不同物种数量分配的均衡程度 |
| <a id="t09"></a>alpha diversity | α 多样性 | 样地或局地尺度的多样性 |
| <a id="t10"></a>beta diversity | β 多样性 | 地点或群落之间的组成差异 |
| <a id="t11"></a>gamma diversity | γ 多样性 | 较大区域整体的多样性 |
| <a id="t12"></a>functional diversity | 功能多样性 | 生物功能特征的差异程度 |
| <a id="t13"></a>phylogenetic diversity | 系统发育多样性 | 谱系关系所包含的演化多样性 |
| <a id="t14"></a>abundance | 丰度 | 指定范围内对象的数量 |
| <a id="t15"></a>occupancy | 占据率 | 调查单元中对象出现的比例 |
| <a id="t16"></a>biomass | 生物量 | 生物体物质量的总和 |
| <a id="t17"></a>primary productivity | 初级生产力 | 自养生物生成有机物的速率 |
| <a id="t18"></a>trophic level | 营养级 | 食物关系中的能量传递层级 |
| <a id="t19"></a>food web | 食物网 | 群落中相互连接的取食关系 |
| <a id="t20"></a>competition | 竞争 | 生物对有限资源等的共同需求 |
| <a id="t21"></a>mutualism | 互利关系 | 相互作用双方获得益处的关系 |
| <a id="t22"></a>commensalism | 偏利关系 | 一方受益而另一方近中性的关系 |
| <a id="t23"></a>predation | 捕食 | 捕食者取食猎物的相互作用 |
| <a id="t24"></a>parasitism | 寄生 | 寄生者利用宿主并使其受损的关系 |
| <a id="t25"></a>dispersal | 扩散 | 个体或传播单位在地点间移动 |
| <a id="t26"></a>succession | 演替 | 群落组成随时间有序变化 |
| <a id="t27"></a>disturbance | 干扰 | 改变生态结构或资源的事件 |
| <a id="t28"></a>resistance | 抵抗力 | 系统受扰动时维持原状态的程度 |
| <a id="t29"></a>resilience | 恢复力 | 系统受扰动后恢复的能力或过程 |
| <a id="t30"></a>carrying capacity | 环境容纳量 | 给定条件下可维持的种群规模 |
| <a id="t31"></a>density dependence | 密度制约 | 过程速率随种群密度而变化 |
| <a id="t32"></a>metapopulation | 集合种群 | 由扩散联系的局地种群集合 |
| <a id="t33"></a>source-sink dynamics | 源汇动态 | 净输出与依赖输入种群的联系 |
| <a id="t34"></a>fragmentation | 破碎化 | 连续生境分成较小片块的过程 |
| <a id="t35"></a>connectivity | 连通性 | 景观允许移动或生态联系的程度 |
| <a id="t36"></a>endemic species | 特有种 | 自然分布限于特定区域的物种 |
| <a id="t37"></a>invasive species | 入侵物种 | 扩展后产生负面影响的外来物种 |
| <a id="t38"></a>extinction risk | 灭绝风险 | 物种在指定条件下灭绝的可能性 |
| <a id="t39"></a>ecosystem service | 生态系统服务 | 人类从生态系统获得的益处 |
| <a id="t40"></a>restoration ecology | 恢复生态学 | 研究受损生态系统恢复的领域 |

## 使用时

按稿件语境解释；相同英文跨领域可有不同含义。不能用本册简释替换原文的正式定义或条件。例句与修改解释见 [教学示例](../worked-examples.md)。
