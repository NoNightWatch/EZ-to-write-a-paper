# 艺术史与设计：基础术语

领域编号：h06。本册 40 条短释义；同一术语可随传统、流派或法域产生不同含义。未逐条外部审定；[来源属性](../foundation-sources.md)。法律词条仅作学术阅读对照。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>medium | 媒介材料 | 艺术表达使用的材料或形式 |
| <a id="t02"></a>support | 承载体 | 承托绘画等材料的基底 |
| <a id="t03"></a>composition | 构图 | 画面或作品要素的组织 |
| <a id="t04"></a>perspective | 透视 | 在平面表现空间关系的方式 |
| <a id="t05"></a>vanishing point | 消失点 | 透视中平行线视觉汇聚的位置 |
| <a id="t06"></a>chiaroscuro | 明暗造型 | 通过明暗对比组织体积和效果 |
| <a id="t07"></a>palette | 调色体系 | 作品采用的色彩集合 |
| <a id="t08"></a>hue | 色相 | 区分红黄等的颜色属性 |
| <a id="t09"></a>saturation | 饱和度 | 颜色接近纯色的程度 |
| <a id="t10"></a>value | 明度 | 色彩相对明暗的程度 |
| <a id="t11"></a>texture | 肌理 | 表面或视觉上的质地特征 |
| <a id="t12"></a>form | 形态 | 作品的三维或组织形态 |
| <a id="t13"></a>negative space | 负空间 | 主体周围或之间的空白区域 |
| <a id="t14"></a>iconography | 图像学识别 | 识别图像题材符号与传统 |
| <a id="t15"></a>iconology | 图像意义阐释 | 在文化语境中解释图像意义 |
| <a id="t16"></a>style | 风格 | 作品持续呈现的形式特征 |
| <a id="t17"></a>attribution | 归属判断 | 确定作品作者时期或流派 |
| <a id="t18"></a>provenance | 作品流传记录 | 作品所有和流转的历史 |
| <a id="t19"></a>patronage | 赞助关系 | 支持艺术创作与展示的制度关系 |
| <a id="t20"></a>conservation | 文物保存修护 | 维护作品材料及价值的活动 |
| <a id="t21"></a>restoration | 修复 | 按规范恢复作品可理解性的工作 |
| <a id="t22"></a>installation art | 装置艺术 | 以空间组合构成的艺术形式 |
| <a id="t23"></a>performance art | 行为艺术 | 以行动和身体过程构成的艺术 |
| <a id="t24"></a>curation | 策展 | 选择组织和解释展览内容 |
| <a id="t25"></a>design brief | 设计任务书 | 说明目标受众约束和交付的文件 |
| <a id="t26"></a>user research | 用户研究 | 理解使用者需求行为和情境 |
| <a id="t27"></a>persona | 用户画像 | 基于资料形成的代表性使用者描述 |
| <a id="t28"></a>user journey | 用户旅程 | 用户跨阶段完成目标的经历 |
| <a id="t29"></a>prototype | 原型 | 用于试用和沟通的初步设计 |
| <a id="t30"></a>wireframe | 线框图 | 展示界面结构的简化图 |
| <a id="t31"></a>information architecture | 信息架构 | 组织内容层级与导航的结构 |
| <a id="t32"></a>usability | 可用性 | 用户有效高效完成任务的程度 |
| <a id="t33"></a>affordance | 可供性 | 对象与行动者之间的行动可能关系 |
| <a id="t34"></a>signifier | 指示线索 | 提示使用方式的可感知标记 |
| <a id="t35"></a>visual hierarchy | 视觉层级 | 通过差异安排信息关注顺序 |
| <a id="t36"></a>typography | 字体排印 | 文字字体及布局的设计 |
| <a id="t37"></a>kerning | 字偶距调整 | 调整特定字符之间的间距 |
| <a id="t38"></a>leading | 行间距 | 相邻文字基线之间的距离 |
| <a id="t39"></a>grid system | 网格系统 | 辅助版面组织的对齐结构 |
| <a id="t40"></a>design system | 设计系统 | 支持一致设计的组件与规则集合 |

保留作者采用的理论传统、译名与版本；需要统一译名时先检查引用出处。受争议概念只整理作者已有界定。例句见 [教学示例](../worked-examples.md)。
