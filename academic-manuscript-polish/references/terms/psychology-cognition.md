# 心理与认知：基础术语

领域编号：s05。本册 40 条短释义，用于识别稿件用语。涉及流派、量表或指标时，以作者所用来源和定义为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>cognition | 认知 | 获取处理和使用信息的过程 |
| <a id="t02"></a>perception | 知觉 | 组织和解释感觉信息的过程 |
| <a id="t03"></a>sensation | 感觉 | 感官接收刺激的过程 |
| <a id="t04"></a>attention | 注意 | 选择和分配有限认知资源 |
| <a id="t05"></a>working memory | 工作记忆 | 短时保持并操作信息的系统 |
| <a id="t06"></a>short-term memory | 短时记忆 | 短时间保持信息的能力 |
| <a id="t07"></a>long-term memory | 长时记忆 | 较长期储存的信息系统 |
| <a id="t08"></a>episodic memory | 情景记忆 | 对具体经历及其情境的记忆 |
| <a id="t09"></a>semantic memory | 语义记忆 | 关于概念和一般知识的记忆 |
| <a id="t10"></a>procedural memory | 程序性记忆 | 技能和习惯等的记忆 |
| <a id="t11"></a>encoding | 编码 | 把信息形成可存储表征 |
| <a id="t12"></a>retrieval | 提取 | 从记忆中恢复信息 |
| <a id="t13"></a>executive function | 执行功能 | 调节目标导向行为的控制过程 |
| <a id="t14"></a>inhibitory control | 抑制控制 | 停止或限制优势反应的能力 |
| <a id="t15"></a>cognitive flexibility | 认知灵活性 | 在规则或视角间切换的能力 |
| <a id="t16"></a>decision-making | 决策 | 在可选行动之间作出选择 |
| <a id="t17"></a>judgment | 判断 | 对对象性质和可能性作出评价 |
| <a id="t18"></a>heuristic | 启发式 | 简化判断过程的经验规则 |
| <a id="t19"></a>cognitive bias | 认知偏差 | 判断中具有方向性的偏离 |
| <a id="t20"></a>affect | 情感状态 | 情绪与情感体验的概括术语 |
| <a id="t21"></a>emotion | 情绪 | 对情境产生的多成分反应 |
| <a id="t22"></a>mood | 心境 | 较弥散且持续的情感状态 |
| <a id="t23"></a>personality | 人格 | 相对稳定的心理与行为特征 |
| <a id="t24"></a>trait | 特质 | 跨情境相对持续的个体倾向 |
| <a id="t25"></a>state | 状态 | 某时刻或情境中的暂时表现 |
| <a id="t26"></a>intelligence | 智力 | 理解学习推理等能力的概念 |
| <a id="t27"></a>psychometrics | 心理测量学 | 测量心理属性的理论与方法 |
| <a id="t28"></a>construct | 心理构念 | 用来解释现象的理论属性 |
| <a id="t29"></a>scale | 量表 | 按规则测量构念的题目集合 |
| <a id="t30"></a>reliability | 信度 | 测量结果的一致性程度 |
| <a id="t31"></a>validity | 效度 | 证据支持特定分数解释和用途的程度 |
| <a id="t32"></a>factor loading | 因子载荷 | 观测变量与潜在因子的关系系数 |
| <a id="t33"></a>measurement invariance | 测量不变性 | 不同群体时间中测量关系的可比性 |
| <a id="t34"></a>response bias | 反应偏差 | 回答方式带来的系统性偏离 |
| <a id="t35"></a>social desirability | 社会赞许性 | 按社会认可方式作答的倾向 |
| <a id="t36"></a>reaction time | 反应时 | 刺激出现到反应的时间 |
| <a id="t37"></a>habituation | 习惯化 | 重复刺激后反应逐渐减弱 |
| <a id="t38"></a>conditioning | 条件作用 | 通过关联经验改变反应的学习 |
| <a id="t39"></a>reinforcement | 强化 | 增加行为后续发生可能性的结果 |
| <a id="t40"></a>attachment | 依恋 | 个体与重要他人形成的情感联系 |

## 使用时

不要把不同测量口径、流派定义或地域制度统一成一个近义词。首次使用时提供必要上下文。需要更多说明可读 [教学示例](../worked-examples.md)，专业判断请作者确认。
