# 法学：基础术语

领域编号：s08。本册 40 条短释义；同一术语可随传统、流派或法域产生不同含义。未逐条外部审定；[来源属性](../foundation-sources.md)。法律词条仅作学术阅读对照。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>jurisdiction | 管辖权 | 机构或法院处理特定事项的权限 |
| <a id="t02"></a>statute | 制定法 | 经立法程序制定的成文法律 |
| <a id="t03"></a>regulation | 法规或规章 | 行政等机关依权限制定的规则 |
| <a id="t04"></a>case law | 判例法 | 司法裁判形成的法律规则体系 |
| <a id="t05"></a>precedent | 先例 | 可供后续裁判参考或遵循的判决 |
| <a id="t06"></a>ratio decidendi | 裁判理由 | 支持判决且可能具有先例作用的理由 |
| <a id="t07"></a>obiter dictum | 附带意见 | 判决中非决定结果必需的论述 |
| <a id="t08"></a>binding authority | 有约束力的法律依据 | 相关法院须遵循的权威来源 |
| <a id="t09"></a>persuasive authority | 说服性法律依据 | 可参考但无强制拘束力的来源 |
| <a id="t10"></a>statutory interpretation | 法律解释 | 确定成文法含义及适用的过程 |
| <a id="t11"></a>legal doctrine | 法律学说或规则体系 | 围绕法律问题形成的概念规则 |
| <a id="t12"></a>cause of action | 诉因 | 请求司法救济所依的法律理由 |
| <a id="t13"></a>standing | 诉讼资格 | 主体请求法院审理事项的资格 |
| <a id="t14"></a>burden of proof | 证明责任 | 对事实成立承担证明后果的责任 |
| <a id="t15"></a>standard of proof | 证明标准 | 认定事实所需的证明程度 |
| <a id="t16"></a>evidence admissibility | 证据可采性 | 证据能否进入裁判考虑的资格 |
| <a id="t17"></a>liability | 法律责任 | 违反义务等产生的法律后果 |
| <a id="t18"></a>negligence | 过失 | 未达到适用注意标准的行为 |
| <a id="t19"></a>duty of care | 注意义务 | 合理避免使他人受损的义务 |
| <a id="t20"></a>breach | 违反义务 | 未履行法律或合同要求 |
| <a id="t21"></a>damages | 损害赔偿金 | 补偿或其他目的的金钱救济 |
| <a id="t22"></a>injunction | 禁令 | 要求实施或停止行为的法院命令 |
| <a id="t23"></a>remedy | 救济 | 回应权利侵害等的法律措施 |
| <a id="t24"></a>contract | 合同 | 当事人之间具有法律意义的约定 |
| <a id="t25"></a>consideration | 约因 | 部分法系中支持合同的交换要素 |
| <a id="t26"></a>tort | 侵权行为 | 合同之外违反法定义务的致损行为 |
| <a id="t27"></a>fiduciary duty | 信义义务 | 为他人利益忠实谨慎行事的义务 |
| <a id="t28"></a>due process | 正当程序 | 权力行使须遵循的程序保障 |
| <a id="t29"></a>judicial review | 司法审查 | 法院审查公共行为等合法性的制度 |
| <a id="t30"></a>constitutional review | 合宪性审查 | 审查法律行为是否符合宪法 |
| <a id="t31"></a>proportionality | 比例原则 | 权力措施与目标相适应的审查原则 |
| <a id="t32"></a>legal certainty | 法律确定性 | 规则可理解和可预期的要求 |
| <a id="t33"></a>legal person | 法人 | 法律认可具有独立权利义务的组织 |
| <a id="t34"></a>natural person | 自然人 | 作为权利义务主体的个人 |
| <a id="t35"></a>intellectual property | 知识产权 | 对特定智力成果等的法定权利 |
| <a id="t36"></a>patent | 专利权 | 对符合条件发明等授予的排他权 |
| <a id="t37"></a>copyright | 著作权 | 对作品赋予的相关专有权利 |
| <a id="t38"></a>trademark | 商标 | 识别商品服务来源的标识 |
| <a id="t39"></a>arbitration | 仲裁 | 由约定裁判者处理争议的程序 |
| <a id="t40"></a>conflict of laws | 法律冲突 | 涉及多个法域时确定适用法等的领域 |
