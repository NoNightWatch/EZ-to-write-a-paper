# 农学与园艺：基础术语

领域编号：a01。本册 40 条短释义，用于识别稿件用语。涉及流派、量表或指标时，以作者所用来源和定义为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>crop | 作物 | 为食用或其他用途栽培的植物 |
| <a id="t02"></a>cultivar | 栽培品种 | 经选择且具有可识别特征的栽培植物群 |
| <a id="t03"></a>landrace | 地方品种 | 长期地方栽培形成的适应性群体 |
| <a id="t04"></a>germplasm | 种质 | 可用于保存和育种的遗传材料 |
| <a id="t05"></a>breeding | 育种 | 选择或组合遗传变异以改良品种 |
| <a id="t06"></a>phenology | 物候 | 生物季节性发育事件及时间 |
| <a id="t07"></a>germination | 萌发 | 种子开始恢复生长的过程 |
| <a id="t08"></a>emergence | 出苗 | 幼苗从土面等显露的阶段 |
| <a id="t09"></a>seed dormancy | 种子休眠 | 适宜外部条件下仍暂不萌发的状态 |
| <a id="t10"></a>flowering | 开花 | 花形成并进入开放阶段 |
| <a id="t11"></a>pollination | 授粉 | 花粉到达相应受粉部位 |
| <a id="t12"></a>fruit set | 坐果 | 花转化并发育为果实的过程 |
| <a id="t13"></a>maturity | 成熟度 | 作物达到规定发育或收获阶段的程度 |
| <a id="t14"></a>harvest index | 收获指数 | 经济产量占规定总生物量的比例 |
| <a id="t15"></a>crop yield | 作物产量 | 规定面积或对象获得的收获量 |
| <a id="t16"></a>yield component | 产量构成因素 | 共同组成最终产量的数量特征 |
| <a id="t17"></a>planting density | 种植密度 | 单位面积配置的植物数量 |
| <a id="t18"></a>row spacing | 行距 | 相邻种植行之间的距离 |
| <a id="t19"></a>intercropping | 间作 | 同一田地同时种植多种作物 |
| <a id="t20"></a>crop rotation | 轮作 | 同一田地按时序更换作物 |
| <a id="t21"></a>monoculture | 单作 | 田地主要栽培一种作物的方式 |
| <a id="t22"></a>cover crop | 覆盖作物 | 以覆盖保护土壤等为目的的作物 |
| <a id="t23"></a>green manure | 绿肥 | 主要用于培肥的植物材料 |
| <a id="t24"></a>tillage | 耕作 | 对土壤实施机械扰动的作业 |
| <a id="t25"></a>no-till | 免耕 | 减少播前全面翻动土壤的耕作方式 |
| <a id="t26"></a>mulching | 覆盖 | 用材料覆盖土表的管理措施 |
| <a id="t27"></a>irrigation | 灌溉 | 人为向作物土壤等供水 |
| <a id="t28"></a>fertigation | 水肥一体化施用 | 通过灌溉体系输送肥料 |
| <a id="t29"></a>nutrient use efficiency | 养分利用效率 | 作物产出相对养分基准的量度 |
| <a id="t30"></a>water use efficiency | 水分利用效率 | 产出相对用水量的量度 |
| <a id="t31"></a>integrated pest management | 有害生物综合管理 | 结合多类措施管理有害生物 |
| <a id="t32"></a>disease incidence | 病害发生率 | 调查单位中患病单位的比例 |
| <a id="t33"></a>disease severity | 病害严重度 | 患病组织或症状程度的量度 |
| <a id="t34"></a>weed competition | 杂草竞争 | 杂草与作物争用资源的关系 |
| <a id="t35"></a>lodging | 倒伏 | 作物茎秆等倾倒或折伏 |
| <a id="t36"></a>vernalization | 春化 | 低温经历促进后续开花的过程 |
| <a id="t37"></a>photoperiodism | 光周期反应 | 生物对昼夜长度的发育响应 |
| <a id="t38"></a>grafting | 嫁接 | 结合不同植物部分形成植株 |
| <a id="t39"></a>pruning | 修剪 | 选择性移除植物部分的管理 |
| <a id="t40"></a>postharvest physiology | 采后生理 | 收获后产品生理变化的研究 |

## 使用时

不要把不同测量口径、流派定义或地域制度统一成一个近义词。首次使用时提供必要上下文。需要更多说明可读 [教学示例](../worked-examples.md)，专业判断请作者确认。
