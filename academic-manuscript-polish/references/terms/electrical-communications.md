# 电气电子与通信：基础术语

领域编号：e01。本册 40 条短释义，用于阅读定位和中英用语对照。正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>electric charge | 电荷 | 参与电磁相互作用的物理属性 |
| <a id="t02"></a>electric current | 电流 | 电荷流动的速率 |
| <a id="t03"></a>electric potential | 电势 | 单位电荷对应的电势能 |
| <a id="t04"></a>resistance | 电阻 | 导体阻碍电流的电学量 |
| <a id="t05"></a>conductance | 电导 | 电阻的倒数 |
| <a id="t06"></a>capacitance | 电容 | 储存电荷与电势差关系的量度 |
| <a id="t07"></a>inductance | 电感 | 电流变化与感应电动势关系的量度 |
| <a id="t08"></a>impedance | 阻抗 | 交流中电势差与电流的复数比 |
| <a id="t09"></a>admittance | 导纳 | 阻抗的倒数 |
| <a id="t10"></a>reactance | 电抗 | 阻抗中与储能相关的虚部 |
| <a id="t11"></a>circuit | 电路 | 电学元件形成的连接网络 |
| <a id="t12"></a>node | 节点 | 电路中电势相同的连接位置 |
| <a id="t13"></a>ground | 接地参考点 | 电路采用的参考电势位置 |
| <a id="t14"></a>direct current | 直流 | 方向不随时间交替的电流 |
| <a id="t15"></a>alternating current | 交流 | 方向随时间交替的电流 |
| <a id="t16"></a>rectifier | 整流器 | 把交流转换为直流的电路或装置 |
| <a id="t17"></a>inverter | 逆变器 | 把直流转换为交流的装置 |
| <a id="t18"></a>amplifier | 放大器 | 增大信号幅度或功率的电路 |
| <a id="t19"></a>oscillator | 振荡器 | 产生周期信号的电路 |
| <a id="t20"></a>filter | 滤波器 | 按频率等特征选择信号的系统 |
| <a id="t21"></a>semiconductor | 半导体 | 导电性质可调的材料类别 |
| <a id="t22"></a>transistor | 晶体管 | 用于开关或放大的半导体器件 |
| <a id="t23"></a>diode | 二极管 | 具有方向性导电特征的器件 |
| <a id="t24"></a>integrated circuit | 集成电路 | 多个电子元件集于基片的电路 |
| <a id="t25"></a>sensor | 传感器 | 把被测量转换成可处理信号的器件 |
| <a id="t26"></a>transducer | 换能器 | 转换不同能量或信号形式的器件 |
| <a id="t27"></a>signal-to-noise ratio | 信噪比 | 信号功率相对噪声功率的比值 |
| <a id="t28"></a>bandwidth | 带宽 | 系统使用或通过的频率范围 |
| <a id="t29"></a>sampling rate | 采样率 | 单位时间取得离散样本的次数 |
| <a id="t30"></a>quantization | 量化 | 把连续值映射到有限离散级别 |
| <a id="t31"></a>modulation | 调制 | 用信息改变载波特征 |
| <a id="t32"></a>demodulation | 解调 | 从调制信号恢复信息 |
| <a id="t33"></a>carrier | 载波 | 承载信息变化的基础信号 |
| <a id="t34"></a>channel capacity | 信道容量 | 规定条件下可靠传输速率的上限 |
| <a id="t35"></a>bit error rate | 误码率 | 错误比特占传输比特的比例 |
| <a id="t36"></a>coding gain | 编码增益 | 采用编码获得的性能改善量 |
| <a id="t37"></a>multiplexing | 复用 | 多个信息流共享传输资源 |
| <a id="t38"></a>antenna | 天线 | 辐射或接收电磁波的结构 |
| <a id="t39"></a>propagation loss | 传播损耗 | 信号传播过程中强度的衰减 |
| <a id="t40"></a>link budget | 链路预算 | 收发增益和损耗的合计核算 |
