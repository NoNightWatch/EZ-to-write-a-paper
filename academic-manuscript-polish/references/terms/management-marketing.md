# 管理与市场营销：基础术语

领域编号：s03。本册 40 条短释义，用于识别稿件用语。涉及流派、量表或指标时，以作者所用来源和定义为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>organization | 组织 | 围绕目标协调行动的社会实体 |
| <a id="t02"></a>strategy | 战略 | 实现组织目标的总体选择与安排 |
| <a id="t03"></a>business model | 商业模式 | 创造提供和获取价值的活动安排 |
| <a id="t04"></a>capability | 组织能力 | 协调资源完成任务的能力 |
| <a id="t05"></a>resource-based view | 资源基础观 | 从资源差异理解组织优势的视角 |
| <a id="t06"></a>dynamic capabilities | 动态能力 | 调整和重组资源以应对变化的能力 |
| <a id="t07"></a>competitive advantage | 竞争优势 | 相对竞争者更有利的表现基础 |
| <a id="t08"></a>organizational culture | 组织文化 | 组织成员共享的意义和惯例 |
| <a id="t09"></a>organizational climate | 组织氛围 | 成员对工作环境的共同感知 |
| <a id="t10"></a>leadership | 领导 | 影响群体目标与行动的过程 |
| <a id="t11"></a>motivation | 动机 | 启动和维持行为的因素 |
| <a id="t12"></a>job satisfaction | 工作满意度 | 对工作的总体评价与感受 |
| <a id="t13"></a>organizational commitment | 组织承诺 | 成员与组织的心理联系 |
| <a id="t14"></a>employee engagement | 员工投入 | 工作中的精力和参与状态 |
| <a id="t15"></a>psychological safety | 心理安全感 | 表达疑问或犯错时的人际安全感 |
| <a id="t16"></a>team coordination | 团队协调 | 成员活动之间的衔接安排 |
| <a id="t17"></a>knowledge sharing | 知识共享 | 成员交换经验和信息的活动 |
| <a id="t18"></a>absorptive capacity | 吸收能力 | 识别吸收并应用外部知识的能力 |
| <a id="t19"></a>organizational learning | 组织学习 | 组织经验转化为知识或行动改变 |
| <a id="t20"></a>exploration | 探索 | 寻找新知识与可能性的活动 |
| <a id="t21"></a>exploitation | 利用 | 运用改进既有知识与能力 |
| <a id="t22"></a>ambidexterity | 双元性 | 兼顾探索与利用等不同活动 |
| <a id="t23"></a>innovation | 创新 | 新产品过程或组织方式的形成应用 |
| <a id="t24"></a>entrepreneurship | 创业活动 | 识别并组织实现机会的活动 |
| <a id="t25"></a>stakeholder | 利益相关者 | 受组织活动影响或能影响组织的主体 |
| <a id="t26"></a>corporate governance | 公司治理 | 安排公司决策监督与责任的制度 |
| <a id="t27"></a>supply chain | 供应链 | 产品服务供给中相互联系的组织网络 |
| <a id="t28"></a>operations management | 运营管理 | 组织产品服务生产交付的管理 |
| <a id="t29"></a>customer segmentation | 客户细分 | 按特征或需求划分客户群 |
| <a id="t30"></a>target market | 目标市场 | 组织选择重点服务的市场群体 |
| <a id="t31"></a>positioning | 定位 | 在目标受众认知中建立的相对位置 |
| <a id="t32"></a>brand equity | 品牌资产 | 品牌名称带来的价值与响应差异 |
| <a id="t33"></a>customer value | 顾客价值 | 顾客感知收益相对付出的评价 |
| <a id="t34"></a>customer satisfaction | 顾客满意度 | 体验与预期关系形成的评价 |
| <a id="t35"></a>customer loyalty | 顾客忠诚 | 持续偏好或选择某提供者的倾向 |
| <a id="t36"></a>purchase intention | 购买意愿 | 未来购买的主观倾向 |
| <a id="t37"></a>word of mouth | 口碑传播 | 消费者之间的非正式信息交流 |
| <a id="t38"></a>customer lifetime value | 客户终身价值 | 客户关系期内净收益的价值估计 |
| <a id="t39"></a>market orientation | 市场导向 | 组织关注并响应市场信息的取向 |
| <a id="t40"></a>service quality | 服务质量 | 服务满足需求与期待的程度 |

## 使用时

不要把不同测量口径、流派定义或地域制度统一成一个近义词。首次使用时提供必要上下文。需要更多说明可读 [教学示例](../worked-examples.md)，专业判断请作者确认。
