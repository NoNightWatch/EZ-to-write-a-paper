# 林学：基础术语

领域编号：a03。本册 40 条短释义，用于识别稿件用语。涉及流派、量表或指标时，以作者所用来源和定义为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>stand | 林分 | 组成和结构相对一致的森林单元 |
| <a id="t02"></a>stand density | 林分密度 | 单位面积林木数量等的量度 |
| <a id="t03"></a>basal area | 胸高断面积 | 规定胸高处树干截面积的合计 |
| <a id="t04"></a>diameter at breast height | 胸径 | 规定胸高位置的树干直径 |
| <a id="t05"></a>tree height | 树高 | 树木基部至顶部的高度 |
| <a id="t06"></a>canopy | 林冠 | 树冠形成的上部覆盖层 |
| <a id="t07"></a>understory | 林下植被层 | 位于林冠下的植被层 |
| <a id="t08"></a>crown | 树冠 | 树木枝叶组成的部分 |
| <a id="t09"></a>canopy cover | 林冠覆盖度 | 林冠投影占地面积的比例 |
| <a id="t10"></a>leaf area index | 叶面积指数 | 叶面积相对地表面积的量度 |
| <a id="t11"></a>growing stock | 蓄积量 | 规定范围内活立木材积 |
| <a id="t12"></a>increment | 生长量 | 林木量值在一定时期的增加 |
| <a id="t13"></a>site index | 地位指数 | 以标准林龄树高表征立地生产力 |
| <a id="t14"></a>site quality | 立地质量 | 地点支持林木生长的条件 |
| <a id="t15"></a>rotation age | 轮伐期 | 林分从建立到计划主伐的时间 |
| <a id="t16"></a>thinning | 间伐 | 移除部分林木调节林分 |
| <a id="t17"></a>clear-cutting | 皆伐 | 一次移除规定区域主要林木的采伐 |
| <a id="t18"></a>selective cutting | 择伐 | 选择部分林木进行采伐 |
| <a id="t19"></a>regeneration | 森林更新 | 新一代林木建立的过程 |
| <a id="t20"></a>afforestation | 造林 | 在原非林地建立森林 |
| <a id="t21"></a>reforestation | 再造林 | 在原有林地恢复森林 |
| <a id="t22"></a>deforestation | 森林转为非林地 | 森林土地用途发生长期转换 |
| <a id="t23"></a>forest degradation | 森林退化 | 森林结构或功能等下降 |
| <a id="t24"></a>silviculture | 森林培育 | 建立和调节林分的学科与实践 |
| <a id="t25"></a>plantation | 人工林 | 通过栽植或播种建立的林分 |
| <a id="t26"></a>old-growth forest | 老龄林 | 长期发展且具有老龄结构的森林 |
| <a id="t27"></a>even-aged stand | 同龄林 | 林木年龄差异较小的林分 |
| <a id="t28"></a>uneven-aged stand | 异龄林 | 由多个年龄级构成的林分 |
| <a id="t29"></a>deadwood | 死木 | 死亡后仍留在森林中的木质材料 |
| <a id="t30"></a>coarse woody debris | 粗木质残体 | 达到规定尺寸的死亡木质材料 |
| <a id="t31"></a>fuel load | 可燃物载量 | 单位面积可燃材料的数量 |
| <a id="t32"></a>fire regime | 火情格局 | 火发生频率强度季节等的组合 |
| <a id="t33"></a>burn severity | 火烧严重度 | 火对植被土壤等造成的改变程度 |
| <a id="t34"></a>windthrow | 风倒 | 树木受风作用连根或整体倾倒 |
| <a id="t35"></a>forest fragmentation | 森林破碎化 | 连续森林分为较小片块 |
| <a id="t36"></a>forest inventory | 森林资源清查 | 系统测量森林数量与状态 |
| <a id="t37"></a>allometry | 异速生长关系 | 生物不同尺度量之间的比例关系 |
| <a id="t38"></a>dendrochronology | 树轮年代学 | 利用年轮确定年代和环境信息 |
| <a id="t39"></a>wood density | 木材密度 | 木材质量相对规定体积的比值 |
| <a id="t40"></a>sustainable forest management | 可持续森林管理 | 兼顾长期生态社会经济功能的管理 |

## 使用时

不要把不同测量口径、流派定义或地域制度统一成一个近义词。首次使用时提供必要上下文。需要更多说明可读 [教学示例](../worked-examples.md)，专业判断请作者确认。
