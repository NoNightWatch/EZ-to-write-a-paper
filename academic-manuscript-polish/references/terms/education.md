# 教育学：基础术语

领域编号：s04。本册 40 条短释义，用于识别稿件用语。涉及流派、量表或指标时，以作者所用来源和定义为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>curriculum | 课程体系 | 教育目标内容与活动的整体安排 |
| <a id="t02"></a>syllabus | 课程大纲 | 单门课程的目标内容及规则说明 |
| <a id="t03"></a>pedagogy | 教学法 | 组织教学的理念与方式 |
| <a id="t04"></a>didactics | 教学论 | 研究教学内容及其组织的领域 |
| <a id="t05"></a>learning objective | 学习目标 | 预期学习者达到的知识能力 |
| <a id="t06"></a>learning outcome | 学习成果 | 学习后实际表现的知识与能力 |
| <a id="t07"></a>assessment | 评价 | 收集信息判断学习情况的过程 |
| <a id="t08"></a>formative assessment | 形成性评价 | 为学习过程提供反馈的评价 |
| <a id="t09"></a>summative assessment | 总结性评价 | 在阶段结束时评价学习成果 |
| <a id="t10"></a>rubric | 评分量规 | 按维度和等级说明评分标准 |
| <a id="t11"></a>criterion-referenced assessment | 标准参照评价 | 依据预定标准判断表现 |
| <a id="t12"></a>norm-referenced assessment | 常模参照评价 | 依据参照群体比较表现 |
| <a id="t13"></a>feedback | 学习反馈 | 帮助理解表现及改进方向的信息 |
| <a id="t14"></a>scaffolding | 学习支架 | 随学习进展调整的支持 |
| <a id="t15"></a>zone of proximal development | 最近发展区 | 独立能力与支持下能力之间的范围 |
| <a id="t16"></a>constructivism | 建构主义 | 强调学习者主动建构理解的取向 |
| <a id="t17"></a>inquiry-based learning | 探究式学习 | 围绕问题进行探索的学习 |
| <a id="t18"></a>problem-based learning | 问题式学习 | 以真实或模拟问题组织学习 |
| <a id="t19"></a>project-based learning | 项目式学习 | 围绕持续项目组织学习 |
| <a id="t20"></a>collaborative learning | 协作学习 | 通过共同活动促进学习 |
| <a id="t21"></a>active learning | 主动学习 | 学习者积极参与认知活动的方式 |
| <a id="t22"></a>self-regulated learning | 自我调节学习 | 学习者规划监控调整自身学习 |
| <a id="t23"></a>metacognition | 元认知 | 对自身认知过程的认识与调节 |
| <a id="t24"></a>learning transfer | 学习迁移 | 在新情境使用所学的过程 |
| <a id="t25"></a>cognitive load | 认知负荷 | 任务对工作记忆等的要求 |
| <a id="t26"></a>prior knowledge | 先备知识 | 进入学习任务前已有的知识 |
| <a id="t27"></a>conceptual change | 概念转变 | 学习者既有理解发生结构性改变 |
| <a id="t28"></a>misconception | 错误概念 | 与目标知识不一致的既有理解 |
| <a id="t29"></a>literacy | 读写素养 | 理解和使用书面符号等的能力 |
| <a id="t30"></a>numeracy | 数理素养 | 理解和运用数量信息的能力 |
| <a id="t31"></a>digital literacy | 数字素养 | 有效理解和使用数字信息工具 |
| <a id="t32"></a>inclusive education | 融合教育 | 使不同需求学习者参与共同教育 |
| <a id="t33"></a>differentiated instruction | 差异化教学 | 依据学习者差异调整教学 |
| <a id="t34"></a>special educational needs | 特殊教育需要 | 需要额外支持的学习需求 |
| <a id="t35"></a>educational attainment | 教育获得 | 已完成的教育层级或资格 |
| <a id="t36"></a>academic achievement | 学业成就 | 在规定学习任务中的表现 |
| <a id="t37"></a>student engagement | 学生参与 | 学习活动中的行为情感认知投入 |
| <a id="t38"></a>school climate | 学校氛围 | 师生对学校关系与环境的体验 |
| <a id="t39"></a>teacher professional development | 教师专业发展 | 教师持续改进知识能力的过程 |
| <a id="t40"></a>educational equity | 教育公平 | 教育机会资源与待遇的公正性 |

## 使用时

不要把不同测量口径、流派定义或地域制度统一成一个近义词。首次使用时提供必要上下文。需要更多说明可读 [教学示例](../worked-examples.md)，专业判断请作者确认。
