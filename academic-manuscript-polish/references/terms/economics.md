# 经济学：基础术语

领域编号：s01。本册 40 条短释义，用于识别稿件用语。涉及流派、量表或指标时，以作者所用来源和定义为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>scarcity | 稀缺性 | 资源相对需求有限的状态 |
| <a id="t02"></a>opportunity cost | 机会成本 | 选择放弃的最佳替代价值 |
| <a id="t03"></a>marginal cost | 边际成本 | 增加一单位产出带来的成本变化 |
| <a id="t04"></a>marginal benefit | 边际收益 | 增加一单位活动带来的收益变化 |
| <a id="t05"></a>utility | 效用 | 模型中表示偏好满足的量 |
| <a id="t06"></a>preference | 偏好 | 对不同选择的排序关系 |
| <a id="t07"></a>budget constraint | 预算约束 | 收入价格限定的可选消费范围 |
| <a id="t08"></a>demand | 需求 | 在不同条件下愿意且能够购买的量 |
| <a id="t09"></a>supply | 供给 | 在不同条件下愿意且能够提供的量 |
| <a id="t10"></a>elasticity | 弹性 | 一个变量对另一变量相对变化的响应 |
| <a id="t11"></a>market equilibrium | 市场均衡 | 供需等相互一致的市场状态 |
| <a id="t12"></a>consumer surplus | 消费者剩余 | 支付意愿超过实际支出的部分 |
| <a id="t13"></a>producer surplus | 生产者剩余 | 收入超过相关供给成本的部分 |
| <a id="t14"></a>externality | 外部性 | 交易外他人受到的未定价影响 |
| <a id="t15"></a>public good | 公共品 | 具有非竞争和非排他特征的物品 |
| <a id="t16"></a>common-pool resource | 公共池资源 | 难排他且使用有竞争的资源 |
| <a id="t17"></a>information asymmetry | 信息不对称 | 参与者掌握信息存在差异 |
| <a id="t18"></a>adverse selection | 逆向选择 | 私人信息影响参与者构成的现象 |
| <a id="t19"></a>moral hazard | 道德风险 | 难观察行动引起的激励问题 |
| <a id="t20"></a>transaction cost | 交易成本 | 达成和执行交易所需成本 |
| <a id="t21"></a>property rights | 产权 | 关于资源使用和收益的权利安排 |
| <a id="t22"></a>market power | 市场势力 | 参与者影响价格等条件的能力 |
| <a id="t23"></a>monopoly | 垄断 | 市场由单一主要供给者支配 |
| <a id="t24"></a>oligopoly | 寡头市场 | 少数主要供给者相互竞争的市场 |
| <a id="t25"></a>perfect competition | 完全竞争 | 满足特定理想条件的竞争模型 |
| <a id="t26"></a>general equilibrium | 一般均衡 | 多个市场相互一致的整体状态 |
| <a id="t27"></a>partial equilibrium | 局部均衡 | 集中分析单个市场的均衡 |
| <a id="t28"></a>gross domestic product | 国内生产总值 | 一定时期境内最终生产价值的量度 |
| <a id="t29"></a>inflation | 通货膨胀 | 总体价格水平持续上升 |
| <a id="t30"></a>unemployment rate | 失业率 | 劳动力中失业者所占比例 |
| <a id="t31"></a>productivity | 生产率 | 单位投入对应的产出 |
| <a id="t32"></a>total factor productivity | 全要素生产率 | 超出所计投入贡献的产出效率量度 |
| <a id="t33"></a>human capital | 人力资本 | 个人知识技能健康等生产性积累 |
| <a id="t34"></a>capital stock | 资本存量 | 某时点可用于生产的资本数量 |
| <a id="t35"></a>discount rate | 贴现率 | 将未来价值折算到当前的比率 |
| <a id="t36"></a>present value | 现值 | 未来价值按贴现规则折算的当前值 |
| <a id="t37"></a>social welfare | 社会福利 | 评价社会成员福祉的概念或函数 |
| <a id="t38"></a>Gini coefficient | 基尼系数 | 收入等分配不均程度的量度 |
| <a id="t39"></a>purchasing power parity | 购买力平价 | 依据相同购买能力比较货币的比率 |
| <a id="t40"></a>balance of payments | 国际收支 | 经济体与境外交易的系统记录 |

## 使用时

不要把不同测量口径、流派定义或地域制度统一成一个近义词。首次使用时提供必要上下文。需要更多说明可读 [教学示例](../worked-examples.md)，专业判断请作者确认。
