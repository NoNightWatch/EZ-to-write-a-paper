# 社会学与人类学：基础术语

领域编号：s06。本册 40 条短释义，用于识别稿件用语。涉及流派、量表或指标时，以作者所用来源和定义为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>social structure | 社会结构 | 相对持续的社会关系安排 |
| <a id="t02"></a>social institution | 社会制度 | 组织社会活动的规范与实践体系 |
| <a id="t03"></a>social norm | 社会规范 | 群体认可或期待的行为规则 |
| <a id="t04"></a>social role | 社会角色 | 与特定位置相关的行为期待 |
| <a id="t05"></a>social status | 社会地位 | 个体或群体在关系中的位置 |
| <a id="t06"></a>social stratification | 社会分层 | 资源和地位的层级化分配 |
| <a id="t07"></a>social class | 社会阶级 | 基于经济关系等形成的群体位置 |
| <a id="t08"></a>social mobility | 社会流动 | 个体或群体社会位置的变化 |
| <a id="t09"></a>social capital | 社会资本 | 经社会关系获得的资源 |
| <a id="t10"></a>cultural capital | 文化资本 | 具有社会价值的知识品味资格等 |
| <a id="t11"></a>habitus | 惯习 | 经验塑造的持续感知和行动倾向 |
| <a id="t12"></a>agency | 能动性 | 行动者作出选择并行动的能力 |
| <a id="t13"></a>structure-agency relationship | 结构与能动性关系 | 社会条件与行动之间的联系 |
| <a id="t14"></a>socialization | 社会化 | 学习社会规则和身份的过程 |
| <a id="t15"></a>identity | 身份认同 | 对自身和所属群体的理解 |
| <a id="t16"></a>intersectionality | 交叉性 | 多种社会分类共同构成处境的视角 |
| <a id="t17"></a>gender | 社会性别 | 与性别相关的社会角色和意义 |
| <a id="t18"></a>kinship | 亲属关系 | 经血缘婚姻等认定的社会联系 |
| <a id="t19"></a>household | 家庭户 | 共同生活或安排生活资源的单位 |
| <a id="t20"></a>community study | 社区研究 | 对地方性社会关系的研究 |
| <a id="t21"></a>network tie | 网络关系 | 网络中行动者之间的联系 |
| <a id="t22"></a>network centrality | 网络中心性 | 节点在关系结构中的位置量度 |
| <a id="t23"></a>homophily | 同质性联结 | 相似行动者更易形成联系的倾向 |
| <a id="t24"></a>social exclusion | 社会排斥 | 参与社会资源和活动受到限制 |
| <a id="t25"></a>marginalization | 边缘化 | 群体被置于权力资源边缘的过程 |
| <a id="t26"></a>stigma | 污名 | 某属性引发的社会贬低与区别 |
| <a id="t27"></a>deviance | 越轨 | 偏离特定社会规范的行为 |
| <a id="t28"></a>collective action | 集体行动 | 多人围绕共同事项的协调行动 |
| <a id="t29"></a>social movement | 社会运动 | 持续推动社会变化的集体行动 |
| <a id="t30"></a>ethnography | 民族志 | 以情境化田野理解社会生活的研究 |
| <a id="t31"></a>participant observation | 参与观察 | 在参与活动中进行系统观察 |
| <a id="t32"></a>fieldwork | 田野工作 | 在研究对象所处环境中收集材料 |
| <a id="t33"></a>fieldnotes | 田野笔记 | 记录观察及情境的研究笔记 |
| <a id="t34"></a>emic perspective | 主位视角 | 从参与者自身意义系统理解 |
| <a id="t35"></a>etic perspective | 客位视角 | 使用研究者分析概念进行理解 |
| <a id="t36"></a>reflexivity | 反身性 | 考察研究者位置对研究的影响 |
| <a id="t37"></a>positionality | 研究者位置 | 影响理解与关系的身份和处境 |
| <a id="t38"></a>thick description | 深描 | 结合情境意义的细致描述 |
| <a id="t39"></a>cultural relativism | 文化相对主义 | 在文化自身语境中理解实践 |
| <a id="t40"></a>reciprocity | 互惠 | 给予和回报相联系的交换关系 |

## 使用时

不要把不同测量口径、流派定义或地域制度统一成一个近义词。首次使用时提供必要上下文。需要更多说明可读 [教学示例](../worked-examples.md)，专业判断请作者确认。
