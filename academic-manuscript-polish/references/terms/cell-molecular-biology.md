# 细胞与分子生物学：基础术语

领域编号：n07。本册 40 条短释义，用于阅读定位和中英用语对照。正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>cell | 细胞 | 生命体的基本结构与功能单位 |
| <a id="t02"></a>organelle | 细胞器 | 细胞内具有特定功能的结构 |
| <a id="t03"></a>cell membrane | 细胞膜 | 界定细胞并调节物质交换的膜 |
| <a id="t04"></a>cytoplasm | 细胞质 | 细胞膜内核以外的内容物 |
| <a id="t05"></a>nucleus | 细胞核 | 真核细胞内包围主要遗传物质的结构 |
| <a id="t06"></a>mitochondrion | 线粒体 | 参与能量代谢等功能的细胞器 |
| <a id="t07"></a>ribosome | 核糖体 | 根据 RNA 信息合成蛋白质的复合体 |
| <a id="t08"></a>cytoskeleton | 细胞骨架 | 维持形态并参与运动的蛋白质网络 |
| <a id="t09"></a>DNA | 脱氧核糖核酸 | 储存遗传信息的一类核酸 |
| <a id="t10"></a>RNA | 核糖核酸 | 参与信息表达与调控的一类核酸 |
| <a id="t11"></a>nucleotide | 核苷酸 | 组成核酸的基本单体 |
| <a id="t12"></a>gene | 基因 | 产生功能性产物的遗传序列单位 |
| <a id="t13"></a>genome | 基因组 | 对象所具有的整套遗传信息 |
| <a id="t14"></a>transcript | 转录本 | 由转录产生的 RNA 分子 |
| <a id="t15"></a>transcription | 转录 | 以 DNA 等模板形成 RNA 的过程 |
| <a id="t16"></a>translation | 翻译 | 按信使 RNA 信息合成多肽的过程 |
| <a id="t17"></a>messenger RNA | 信使 RNA | 向蛋白质合成传递编码信息的 RNA |
| <a id="t18"></a>ribosomal RNA | 核糖体 RNA | 组成核糖体核心结构的 RNA |
| <a id="t19"></a>transfer RNA | 转运 RNA | 在翻译中携带氨基酸的 RNA |
| <a id="t20"></a>complementary DNA | 互补 DNA | 以 RNA 为模板生成的 DNA 副本 |
| <a id="t21"></a>protein | 蛋白质 | 由氨基酸链形成的功能分子 |
| <a id="t22"></a>peptide | 肽 | 由肽键连接的氨基酸链 |
| <a id="t23"></a>enzyme | 酶 | 催化生化反应的生物大分子 |
| <a id="t24"></a>substrate | 底物 | 酶促反应直接作用的物质 |
| <a id="t25"></a>metabolite | 代谢物 | 代谢过程中产生或利用的化合物 |
| <a id="t26"></a>metabolism | 代谢 | 生物体内物质与能量转化过程 |
| <a id="t27"></a>signalling pathway | 信号通路 | 细胞传递和响应信号的过程链 |
| <a id="t28"></a>receptor | 受体 | 识别信号并参与响应的分子 |
| <a id="t29"></a>ligand | 配体 | 与特定靶分子结合的分子 |
| <a id="t30"></a>gene expression | 基因表达 | 基因信息形成 RNA 或蛋白产物 |
| <a id="t31"></a>transcriptome | 转录组 | 指定状态下的 RNA 转录本集合 |
| <a id="t32"></a>proteome | 蛋白质组 | 指定状态下的蛋白质集合 |
| <a id="t33"></a>metabolome | 代谢组 | 指定状态下的小分子代谢物集合 |
| <a id="t34"></a>apoptosis | 细胞凋亡 | 受调控的细胞死亡形式 |
| <a id="t35"></a>cell cycle | 细胞周期 | 细胞从一次分裂到下一次的过程 |
| <a id="t36"></a>differentiation | 分化 | 细胞获得专门结构与功能 |
| <a id="t37"></a>stem cell | 干细胞 | 具有自我更新及分化潜能的细胞 |
| <a id="t38"></a>homeostasis | 稳态 | 通过调节维持相对稳定状态 |
| <a id="t39"></a>extracellular matrix | 细胞外基质 | 细胞外的结构与信号支持网络 |
| <a id="t40"></a>biomarker | 生物标志物 | 指示特定生物状态的可测特征 |
