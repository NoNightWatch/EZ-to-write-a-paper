# 研究设计与统计表达：基础术语

领域编号：g02。本册 40 条短释义，用于阅读定位和中英用语对照。术语的正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>population | 总体 | 研究所指向的对象集合 |
| <a id="t02"></a>sample | 样本 | 实际纳入研究的对象子集 |
| <a id="t03"></a>sampling frame | 抽样框 | 可供抽取样本的对象名单或范围 |
| <a id="t04"></a>unit of analysis | 分析单位 | 分析中一个观测对象的层级 |
| <a id="t05"></a>variable | 变量 | 可在对象之间变化的属性 |
| <a id="t06"></a>outcome | 结局变量 | 研究关注的结果性指标 |
| <a id="t07"></a>exposure | 暴露因素 | 对象接触或具有的因素 |
| <a id="t08"></a>covariate | 协变量 | 分析中一并纳入的变量 |
| <a id="t09"></a>estimand | 目标估计量 | 研究希望估计的明确数量 |
| <a id="t10"></a>estimate | 估计值 | 由样本计算出的目标近似值 |
| <a id="t11"></a>parameter | 参数 | 模型或总体中的数量特征 |
| <a id="t12"></a>statistic | 统计量 | 由样本数据计算的函数 |
| <a id="t13"></a>mean | 均值 | 观测值总和除以观测数 |
| <a id="t14"></a>median | 中位数 | 排序后位于中间的位置值 |
| <a id="t15"></a>quantile | 分位数 | 分布中对应指定累计比例的值 |
| <a id="t16"></a>standard deviation | 标准差 | 数据相对均值的离散程度 |
| <a id="t17"></a>standard error | 标准误 | 估计值抽样变动的尺度 |
| <a id="t18"></a>confidence interval | 置信区间 | 具有规定重复抽样覆盖性质的区间 |
| <a id="t19"></a>credible interval | 可信区间 | 贝叶斯后验分布中的概率区间 |
| <a id="t20"></a>effect size | 效应量 | 差异或关系大小的量化表达 |
| <a id="t21"></a>p-value | p 值 | 零假设及模型成立时，统计量至少同样极端的概率 |
| <a id="t22"></a>null hypothesis | 零假设 | 检验中作为参照的统计假设 |
| <a id="t23"></a>statistical power | 统计功效 | 指定真实效应下拒绝零假设的概率 |
| <a id="t24"></a>likelihood | 似然 | 给定数据下比较参数的模型函数 |
| <a id="t25"></a>prior distribution | 先验分布 | 观察当前数据前的参数分布 |
| <a id="t26"></a>posterior distribution | 后验分布 | 结合先验与数据得到的参数分布 |
| <a id="t27"></a>missing data | 缺失数据 | 应有但未被观测或记录的数据 |
| <a id="t28"></a>outlier | 离群值 | 明显偏离其余观测的数据点 |
| <a id="t29"></a>censoring | 删失 | 事件时间或值仅部分可知的记录 |
| <a id="t30"></a>weighting | 加权 | 赋予观测不同的计算权重 |
| <a id="t31"></a>standardization | 标准化 | 按指定基准转换量值或分布 |
| <a id="t32"></a>interaction term | 交互项 | 表示变量联合作用形式的模型项 |
| <a id="t33"></a>multilevel model | 多层模型 | 表示嵌套或分层数据的模型 |
| <a id="t34"></a>sensitivity analysis | 敏感性分析 | 检查结果随分析设定的变化 |
| <a id="t35"></a>preregistration | 预注册 | 分析前公开记录研究计划 |
| <a id="t36"></a>protocol | 研究方案 | 预先说明研究如何开展的文件 |
| <a id="t37"></a>reporting guideline | 报告规范 | 帮助完整呈现研究信息的清单 |
| <a id="t38"></a>data availability statement | 数据可用性声明 | 说明数据位置和获取条件 |
| <a id="t39"></a>code availability statement | 代码可用性声明 | 说明代码位置和获取条件 |
| <a id="t40"></a>conflict of interest | 利益冲突 | 可能影响判断的相关利益关系 |

## 使用时

先确认此词在原句中的对象和含义，再决定是否替换。短释义不适合直接充当论文中的正式定义。首次出现的专业缩写按目标期刊要求展开；全稿中的同一概念统一用词。具体教学示例见 [编辑示例](../worked-examples.md)。
