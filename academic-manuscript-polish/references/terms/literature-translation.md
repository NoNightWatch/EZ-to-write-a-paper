# 文学与翻译：基础术语

领域编号：h05。本册 40 条短释义；同一术语可随传统、流派或法域产生不同含义。未逐条外部审定；[来源属性](../foundation-sources.md)。法律词条仅作学术阅读对照。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>genre | 体裁 | 具有共同约定的文本类别 |
| <a id="t02"></a>narrator | 叙述者 | 文本中讲述故事的声音或位置 |
| <a id="t03"></a>narrative voice | 叙述声音 | 叙述表达的身份与语调 |
| <a id="t04"></a>focalization | 聚焦 | 叙事信息通过何种视角呈现 |
| <a id="t05"></a>point of view | 叙事视角 | 故事被观察和表达的位置 |
| <a id="t06"></a>plot | 情节 | 文本组织事件的结构 |
| <a id="t07"></a>story | 故事 | 被叙述的事件内容和顺序 |
| <a id="t08"></a>setting | 故事背景 | 事件发生的时间空间与环境 |
| <a id="t09"></a>characterization | 人物塑造 | 文本建立人物特征的方式 |
| <a id="t10"></a>unreliable narrator | 不可靠叙述者 | 其陈述需与文本其他线索区分的叙述者 |
| <a id="t11"></a>stream of consciousness | 意识流 | 呈现连续心理活动的叙事方式 |
| <a id="t12"></a>free indirect discourse | 自由间接话语 | 结合叙述者语法与人物表达的形式 |
| <a id="t13"></a>metafiction | 元小说 | 对自身虚构和叙述活动作出反思的小说 |
| <a id="t14"></a>intertextuality | 互文性 | 文本之间引用回应和关联的关系 |
| <a id="t15"></a>allusion | 典故或暗引 | 对其他文本人物事件的间接指涉 |
| <a id="t16"></a>motif | 母题 | 在文本或传统中反复出现的元素 |
| <a id="t17"></a>theme | 主题 | 文本持续处理的中心问题 |
| <a id="t18"></a>imagery | 意象 | 通过感官和形象组织的表达 |
| <a id="t19"></a>metaphor | 隐喻 | 以一个领域理解另一个领域的表达 |
| <a id="t20"></a>metonymy | 转喻 | 用相邻或关联对象指代目标 |
| <a id="t21"></a>irony | 反讽 | 表层表达与意图等存在张力的修辞 |
| <a id="t22"></a>allegory | 寓言式象征叙事 | 通过完整叙事表达另一层意义 |
| <a id="t23"></a>satire | 讽刺文学 | 通过讽刺形式批评对象的写作 |
| <a id="t24"></a>close reading | 细读 | 围绕文本细节展开的解释 |
| <a id="t25"></a>paratext | 副文本 | 标题序言等围绕主体文本的材料 |
| <a id="t26"></a>reception | 接受 | 作品被读者理解评价和使用的过程 |
| <a id="t27"></a>literary canon | 文学经典体系 | 被传统和制度认可的重要作品集合 |
| <a id="t28"></a>textual variant | 异文 | 不同文本见证中的字句差异 |
| <a id="t29"></a>critical edition | 校勘本 | 结合版本比较形成的学术文本 |
| <a id="t30"></a>source text | 源文本 | 翻译所依据的原文 |
| <a id="t31"></a>target text | 目标文本 | 翻译形成的文本 |
| <a id="t32"></a>translation equivalence | 翻译等值 | 源文与译文之间规定层面的对应 |
| <a id="t33"></a>domestication | 归化 | 使译文贴近目标文化惯例的取向 |
| <a id="t34"></a>foreignization | 异化 | 保留源文化差异特征的翻译取向 |
| <a id="t35"></a>skopos | 翻译目的 | 指导翻译任务的使用目标 |
| <a id="t36"></a>localization | 本地化 | 适应目标地区语言文化使用环境 |
| <a id="t37"></a>back-translation | 回译 | 把译文再译回源语言的过程 |
| <a id="t38"></a>transliteration | 转写 | 按规则把文字形式映射到另一文字 |
| <a id="t39"></a>transcreation | 创译 | 围绕传播效果进行较大幅度改写翻译 |
| <a id="t40"></a>translator visibility | 译者可见性 | 译者介入在文本文化中显现的程度 |

## 使用时

保留作者采用的理论传统、译名与版本；需要统一译名时先检查引用出处。受争议概念只整理作者已有界定。例句见 [教学示例](../worked-examples.md)。
