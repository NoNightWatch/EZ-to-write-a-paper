# 动物科学与兽医：基础术语

领域编号：a05。本册 40 条短释义，用于识别稿件用语。涉及流派、量表或指标时，以作者所用来源和定义为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>livestock | 家畜 | 用于农业生产等的驯养动物 |
| <a id="t02"></a>breed | 品种 | 具有相对稳定遗传特征的家养群体 |
| <a id="t03"></a>herd | 畜群 | 共同管理的一组家畜 |
| <a id="t04"></a>flock | 禽群或羊群 | 共同饲养的一组禽类或羊 |
| <a id="t05"></a>pedigree | 系谱 | 记录个体亲缘关系的资料 |
| <a id="t06"></a>breeding value | 育种值 | 个体可传递加性遗传贡献的估计 |
| <a id="t07"></a>selection index | 选择指数 | 结合多个性状信息的选择指标 |
| <a id="t08"></a>inbreeding coefficient | 近交系数 | 同源等位基因相同概率的量度 |
| <a id="t09"></a>reproductive performance | 繁殖性能 | 繁殖相关产出和效率的表现 |
| <a id="t10"></a>fertility | 繁殖力 | 产生后代的能力或实际表现 |
| <a id="t11"></a>fecundity | 产仔或产卵能力 | 产生生殖产物或后代的数量能力 |
| <a id="t12"></a>gestation | 妊娠 | 胚胎胎儿在母体内发育的时期 |
| <a id="t13"></a>parturition | 分娩 | 后代出生的过程 |
| <a id="t14"></a>lactation | 泌乳 | 乳腺产生和分泌乳汁的过程 |
| <a id="t15"></a>weaning | 断奶 | 后代由吃奶转向其他食物 |
| <a id="t16"></a>growth performance | 生长性能 | 增重等生长相关指标的表现 |
| <a id="t17"></a>average daily gain | 平均日增重 | 规定时间内增重的日均量 |
| <a id="t18"></a>body condition score | 体况评分 | 按体脂等状态给出的等级指标 |
| <a id="t19"></a>dry matter intake | 干物质采食量 | 扣除水分后的饲料摄入量 |
| <a id="t20"></a>ration | 日粮 | 规定时间供给动物的饲料组合 |
| <a id="t21"></a>roughage | 粗饲料 | 纤维等含量较高的饲料 |
| <a id="t22"></a>concentrate feed | 精饲料 | 营养密度较高且纤维较低的饲料 |
| <a id="t23"></a>rumen | 瘤胃 | 反刍动物前胃中的主要发酵室 |
| <a id="t24"></a>rumination | 反刍 | 食团返回口腔重新咀嚼的过程 |
| <a id="t25"></a>digestive efficiency | 消化效率 | 摄入物被消化利用的表现 |
| <a id="t26"></a>feed additive | 饲料添加剂 | 以特定目的加入饲料的少量组分 |
| <a id="t27"></a>animal welfare | 动物福利 | 动物生理和行为等整体状态 |
| <a id="t28"></a>husbandry | 饲养管理 | 动物日常照护与生产管理 |
| <a id="t29"></a>stockmanship | 饲养照护技能 | 理解并照护动物的实际能力 |
| <a id="t30"></a>lameness | 跛行 | 行走异常或疼痛相关的步态问题 |
| <a id="t31"></a>mastitis | 乳腺炎 | 乳腺组织的炎症 |
| <a id="t32"></a>body temperature | 体温 | 机体内部或指定部位温度 |
| <a id="t33"></a>clinical sign | 临床体征 | 检查或观察到的动物异常表现 |
| <a id="t34"></a>differential diagnosis | 鉴别诊断 | 比较多种可能疾病的判断过程 |
| <a id="t35"></a>prognosis | 预后 | 对疾病后续过程和结果的判断 |
| <a id="t36"></a>zoonosis | 人畜共患病 | 可在人与脊椎动物间传播的疾病 |
| <a id="t37"></a>preventive veterinary medicine | 预防兽医学 | 预防动物疾病及相关风险的领域 |
| <a id="t38"></a>herd health | 群体健康 | 畜群层面的健康状态与管理 |
| <a id="t39"></a>companion animal | 伴侣动物 | 主要为陪伴而饲养的动物 |
| <a id="t40"></a>One Health | 同一健康 | 联系人类动物环境健康的框架 |

## 使用时

不要把不同测量口径、流派定义或地域制度统一成一个近义词。首次使用时提供必要上下文。需要更多说明可读 [教学示例](../worked-examples.md)，专业判断请作者确认。
