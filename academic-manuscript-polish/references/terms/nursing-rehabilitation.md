# 护理与康复：基础术语

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>nursing assessment | 护理评估 | 系统收集患者需求和状态信息 |
| <a id="t02"></a>nursing diagnosis | 护理诊断 | 对护理相关反应和需求的专业判断 |
| <a id="t03"></a>care plan | 照护计划 | 围绕需求安排目标和照护行动 |
| <a id="t04"></a>care coordination | 照护协调 | 组织不同提供者之间的服务联系 |
| <a id="t05"></a>continuity of care | 照护连续性 | 跨时间和机构保持连贯的照护 |
| <a id="t06"></a>person-centred care | 以人为中心的照护 | 围绕个人目标与处境组织服务 |
| <a id="t07"></a>shared decision-making | 共同决策 | 患者与专业人员共同讨论选择 |
| <a id="t08"></a>self-management | 自我管理 | 个人管理健康状况和日常行为 |
| <a id="t09"></a>self-efficacy | 自我效能 | 对完成特定任务能力的信念 |
| <a id="t10"></a>caregiver burden | 照护者负担 | 照护责任带来的多方面影响 |
| <a id="t11"></a>patient safety | 患者安全 | 减少医疗照护中可避免伤害 |
| <a id="t12"></a>fall risk | 跌倒风险 | 发生跌倒的可能性及相关因素 |
| <a id="t13"></a>frailty | 衰弱 | 生理储备下降及易受扰动的状态 |
| <a id="t14"></a>functional status | 功能状态 | 完成日常活动等的能力水平 |
| <a id="t15"></a>activities of daily living | 日常生活活动 | 进食穿衣等基本自理活动 |
| <a id="t16"></a>instrumental activities of daily living | 工具性日常生活活动 | 购物理财等较复杂生活活动 |
| <a id="t17"></a>mobility | 活动能力 | 改变位置并在环境中移动的能力 |
| <a id="t18"></a>gait | 步态 | 行走时的运动模式 |
| <a id="t19"></a>balance | 平衡能力 | 维持身体稳定和姿态的能力 |
| <a id="t20"></a>range of motion | 关节活动范围 | 关节可运动的角度范围 |
| <a id="t21"></a>muscle strength | 肌力 | 肌肉产生力量的能力 |
| <a id="t22"></a>muscle endurance | 肌耐力 | 肌肉持续或重复工作的能力 |
| <a id="t23"></a>spasticity | 痉挛状态 | 与速度相关的牵张反射增强表现 |
| <a id="t24"></a>proprioception | 本体感觉 | 感知身体位置与运动的能力 |
| <a id="t25"></a>motor control | 运动控制 | 组织和调节动作的过程 |
| <a id="t26"></a>motor learning | 运动学习 | 练习等带来的运动能力持续改变 |
| <a id="t27"></a>neuroplasticity | 神经可塑性 | 神经系统随经验等改变的性质 |
| <a id="t28"></a>occupational performance | 作业表现 | 完成有意义日常活动的表现 |
| <a id="t29"></a>participation | 参与 | 投入生活情境和社会活动 |
| <a id="t30"></a>activity limitation | 活动受限 | 执行任务或行动的困难 |
| <a id="t31"></a>participation restriction | 参与限制 | 参与生活情境时受到的限制 |
| <a id="t32"></a>assistive technology | 辅助技术 | 支持功能和参与的产品与系统 |

| <a id="t34"></a>orthosis | 矫形器 | 支持或调整身体部位功能的装置 |
| <a id="t35"></a>telerehabilitation | 远程康复 | 通过远程通信提供康复服务 |
| <a id="t36"></a>discharge planning | 出院计划 | 安排离院后的照护衔接 |
| <a id="t37"></a>palliative care | 姑息照护 | 减轻严重疾病相关痛苦的照护 |
| <a id="t38"></a>symptom management | 症状管理 | 评估并减轻症状影响 |
| <a id="t39"></a>rehabilitation goal | 康复目标 | 与个人需求相关的预期功能结果 |

## 使用时

缩写全称、计量基准、定义版本与稿件逐一对应。同名指标在不同学科可以有不同分母或时间范围。简释不替代正式定义。见 [教学示例](../worked-examples.md)。
