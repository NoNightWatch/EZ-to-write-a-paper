# 历史与考古：基础术语

领域编号：h01。本册 40 条短释义；同一术语可随传统、流派或法域产生不同含义。未逐条外部审定；[来源属性](../foundation-sources.md)。法律词条仅作学术阅读对照。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>primary source | 一手史料 | 与研究时代事件直接相关的材料 |
| <a id="t02"></a>secondary source | 二手研究 | 分析解释一手材料的研究文本 |
| <a id="t03"></a>archive | 档案馆藏 | 按来源保存的记录材料集合 |
| <a id="t04"></a>manuscript source | 手稿史料 | 以手写形式保存的历史材料 |
| <a id="t05"></a>paleography | 古文字书写研究 | 辨读和研究历史书写形式 |
| <a id="t06"></a>diplomatics | 文书学 | 研究文书形式真实性与形成过程 |
| <a id="t07"></a>provenance | 来源沿革 | 物件或材料的出处与流传历史 |
| <a id="t08"></a>source criticism | 史料批判 | 判断史料来源语境及可信范围 |
| <a id="t09"></a>historiography | 史学史与史学书写 | 历史解释及其形成传统 |
| <a id="t10"></a>periodization | 分期 | 按特征把历史划分为时期 |
| <a id="t11"></a>chronology | 年代序列 | 事件或材料的时间顺序 |
| <a id="t12"></a>anachronism | 时代错置 | 把后世观念等误置于早期情境 |
| <a id="t13"></a>contextualization | 语境化 | 把材料放回相关历史条件理解 |
| <a id="t14"></a>historical agency | 历史能动性 | 行动者影响历史过程的能力 |
| <a id="t15"></a>microhistory | 微观史 | 通过小范围对象开展细密历史研究 |
| <a id="t16"></a>social history | 社会史 | 研究社会关系和日常生活的取向 |
| <a id="t17"></a>cultural history | 文化史 | 研究意义实践与文化形式的取向 |
| <a id="t18"></a>oral history | 口述史 | 通过访谈记录回忆与历史经验 |
| <a id="t19"></a>collective memory | 集体记忆 | 群体共享和组织的过去认识 |
| <a id="t20"></a>material culture | 物质文化 | 物件及其使用所承载的社会意义 |
| <a id="t21"></a>artifact | 人工遗物 | 人类制作或改造的物质对象 |
| <a id="t22"></a>ecofact | 生态遗存 | 与人类活动相关的天然生物材料 |
| <a id="t23"></a>feature | 遗迹 | 不能轻易移动的考古结构或痕迹 |
| <a id="t24"></a>assemblage | 遗物组合 | 同一背景等中的物件集合 |
| <a id="t25"></a>archaeological context | 考古背景 | 遗存的位置层位及关联关系 |
| <a id="t26"></a>stratigraphic unit | 地层单位 | 考古记录中可区分的沉积或事件单位 |
| <a id="t27"></a>stratigraphic sequence | 地层序列 | 地层单位形成先后关系 |
| <a id="t28"></a>seriation | 序列分析 | 按类型变化排列遗物或遗址 |
| <a id="t29"></a>typology | 类型学 | 按共有特征对物件分类 |
| <a id="t30"></a>relative dating | 相对定年 | 判断先后而不给绝对年份 |
| <a id="t31"></a>absolute dating | 绝对定年 | 给出日历或数值年代的定年 |
| <a id="t32"></a>radiocarbon dating | 放射性碳定年 | 依据碳十四衰变估计有机材料年代 |
| <a id="t33"></a>calibration | 年代校准 | 把测量年代转换为日历年代等 |
| <a id="t34"></a>terminus post quem | 不早于界标 | 事件不可能早于的参照时间 |
| <a id="t35"></a>terminus ante quem | 不晚于界标 | 事件不可能晚于的参照时间 |
| <a id="t36"></a>taphonomy | 埋藏学 | 研究遗存形成保存与改变的过程 |
| <a id="t37"></a>site formation process | 遗址形成过程 | 人类自然作用形成遗址的过程 |
| <a id="t38"></a>excavation | 发掘 | 按记录程序揭示考古遗存 |
| <a id="t39"></a>survey | 考古调查 | 识别和记录地表等遗存 |
| <a id="t40"></a>cultural heritage | 文化遗产 | 具有文化历史价值的传承对象 |

## 使用时

保留作者采用的理论传统、译名与版本；需要统一译名时先检查引用出处。受争议概念只整理作者已有界定。例句见 [教学示例](../worked-examples.md)。
