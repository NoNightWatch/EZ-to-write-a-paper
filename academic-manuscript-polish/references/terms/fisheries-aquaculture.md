# 渔业与水产：基础术语

领域编号：a04。本册 40 条短释义，用于识别稿件用语。涉及流派、量表或指标时，以作者所用来源和定义为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>fish stock | 渔业种群 | 作为评估管理单元的鱼类群体 |
| <a id="t02"></a>stock assessment | 资源评估 | 估算渔业种群状态及变化 |
| <a id="t03"></a>recruitment | 补充量 | 进入规定种群或可捕阶段的数量 |
| <a id="t04"></a>spawning stock biomass | 产卵群体生物量 | 达到繁殖条件个体的总生物量 |
| <a id="t05"></a>fishing mortality | 捕捞死亡率 | 由捕捞造成的瞬时死亡速率 |
| <a id="t06"></a>natural mortality | 自然死亡率 | 由捕捞之外因素造成的死亡速率 |
| <a id="t07"></a>total mortality | 总死亡率 | 各来源死亡过程的合计速率 |
| <a id="t08"></a>catch | 渔获量 | 捕捞获得的水生生物数量 |
| <a id="t09"></a>landings | 上岸渔获量 | 被带回岸上记录的渔获量 |
| <a id="t10"></a>bycatch | 兼捕 | 捕获的非目标物种或尺寸组 |
| <a id="t11"></a>discard | 弃捕物 | 捕获后弃回水中的部分 |
| <a id="t12"></a>catch per unit effort | 单位捕捞努力量渔获量 | 渔获量相对作业投入的指标 |
| <a id="t13"></a>fishing effort | 捕捞努力量 | 捕捞设备时间等投入的量度 |
| <a id="t14"></a>selectivity | 渔具选择性 | 捕获不同大小或种类的相对概率 |
| <a id="t15"></a>maximum sustainable yield | 最大可持续产量 | 特定模型下可持续的最大平均渔获量 |
| <a id="t16"></a>reference point | 管理参考点 | 用于判断资源状态的指标基准 |
| <a id="t17"></a>harvest control rule | 捕捞控制规则 | 依资源状态调整捕捞的预定规则 |
| <a id="t18"></a>quota | 配额 | 规定允许捕捞或使用的数量 |
| <a id="t19"></a>overfishing | 过度捕捞过程 | 捕捞强度超过规定可持续基准 |
| <a id="t20"></a>overfished stock | 资源量不足种群 | 生物量低于规定管理基准的种群 |
| <a id="t21"></a>marine protected area | 海洋保护区 | 为保护目标划定管理的海域 |
| <a id="t22"></a>aquaculture | 水产养殖 | 人为管理下培育水生生物 |
| <a id="t23"></a>mariculture | 海水养殖 | 在海水环境中开展养殖 |
| <a id="t24"></a>hatchery | 育苗场 | 生产早期水生个体的设施 |
| <a id="t25"></a>broodstock | 亲本群 | 用于产生后代的繁殖个体 |
| <a id="t26"></a>larva | 幼体 | 部分水生动物的早期发育阶段 |
| <a id="t27"></a>juvenile | 幼鱼或幼体后期 | 未达到成熟的较后发育阶段 |
| <a id="t28"></a>stocking density | 放养密度 | 单位空间放养个体数量或生物量 |
| <a id="t29"></a>survival rate | 存活率 | 规定时段存活个体的比例 |
| <a id="t30"></a>specific growth rate | 特定生长率 | 相对体量的单位时间增长率 |
| <a id="t31"></a>feed conversion ratio | 饲料系数 | 饲料投入相对增重的比值 |
| <a id="t32"></a>feed efficiency | 饲料效率 | 增重等产出相对饲料投入的比值 |
| <a id="t33"></a>recirculating aquaculture system | 循环水养殖系统 | 处理并重复利用养殖水的系统 |
| <a id="t34"></a>carrying capacity | 养殖承载能力 | 给定环境支持养殖规模的能力 |
| <a id="t35"></a>biofouling | 生物附着污损 | 生物在设施表面附着积累 |
| <a id="t36"></a>benthic impact | 底栖环境影响 | 活动对底部生境和生物的改变 |
| <a id="t37"></a>escapement | 逃脱捕捞后的存留量 | 逃脱捕捞而存留或到达繁殖地的数量 |
| <a id="t38"></a>traceability | 可追溯性 | 追踪产品来源和流转的能力 |
| <a id="t39"></a>fish welfare | 鱼类福利 | 鱼类健康及行为状态等的整体状况 |
| <a id="t40"></a>ecosystem-based fisheries management | 基于生态系统的渔业管理 | 把渔业置于生态系统联系中管理 |

## 使用时

不要把不同测量口径、流派定义或地域制度统一成一个近义词。首次使用时提供必要上下文。需要更多说明可读 [教学示例](../worked-examples.md)，专业判断请作者确认。
