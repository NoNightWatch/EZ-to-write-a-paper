# 环境工程：基础术语

领域编号：e10。本册 40 条短释义，正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>pollutant | 污染物 | 可能造成环境不利影响的物质 |
| <a id="t02"></a>contaminant | 外源或污染组分 | 出现在介质中且需关注的组分 |
| <a id="t03"></a>emission | 排放 | 物质从来源进入环境 |
| <a id="t04"></a>effluent | 出流水 | 处理设施或系统排出的水 |
| <a id="t05"></a>influent | 进流水 | 进入处理设施或系统的水 |
| <a id="t06"></a>effluent quality | 出水水质 | 处理输出水的质量特征 |
| <a id="t07"></a>removal efficiency | 去除效率 | 进入量中被移除部分的比例 |
| <a id="t08"></a>loading rate | 负荷率 | 单位时间或容积接收的物质量 |
| <a id="t09"></a>hydraulic retention time | 水力停留时间 | 水在处理单元中的平均时间尺度 |
| <a id="t10"></a>solids retention time | 固体停留时间 | 固体在处理系统中的平均滞留时间 |
| <a id="t11"></a>biochemical oxygen demand | 生化需氧量 | 规定条件下生物过程消耗的氧量 |
| <a id="t12"></a>chemical oxygen demand | 化学需氧量 | 规定化学氧化条件对应的需氧量 |
| <a id="t13"></a>total organic carbon | 总有机碳 | 样品中有机形态碳的总量 |
| <a id="t14"></a>total suspended solids | 总悬浮固体 | 水中可按方法截留的悬浮物总量 |
| <a id="t15"></a>coagulation | 混凝 | 使胶体等失稳聚集的过程 |
| <a id="t16"></a>flocculation | 絮凝 | 促进颗粒形成较大絮体的过程 |
| <a id="t17"></a>sedimentation | 沉淀分离 | 颗粒依重力从流体中分离 |
| <a id="t18"></a>activated sludge | 活性污泥 | 用于生物处理的微生物絮体体系 |
| <a id="t19"></a>anaerobic digestion | 厌氧消化 | 无氧条件下分解有机物的处理过程 |
| <a id="t20"></a>constructed wetland | 人工湿地 | 利用湿地过程进行净化的工程系统 |
| <a id="t21"></a>membrane bioreactor | 膜生物反应器 | 生物处理与膜分离结合的系统 |
| <a id="t22"></a>disinfection | 消毒 | 降低有害微生物风险的处理 |
| <a id="t23"></a>advanced oxidation | 高级氧化 | 利用高反应活性物种处理污染物 |
| <a id="t24"></a>remediation | 修复 | 降低受污染环境危害的处理 |
| <a id="t25"></a>containment | 围控 | 限制污染物扩散的工程措施 |
| <a id="t26"></a>leachate | 渗滤液 | 流经废物等后形成的含溶质液体 |
| <a id="t27"></a>landfill | 填埋设施 | 按规定集中处置固体废物的设施 |
| <a id="t28"></a>composting | 堆肥 | 有氧分解有机材料形成稳定产物 |
| <a id="t29"></a>resource recovery | 资源回收 | 从废物流中获得可利用物质或能量 |
| <a id="t30"></a>circular economy | 循环经济 | 促进资源循环利用的经济组织理念 |
| <a id="t31"></a>waste hierarchy | 废物管理层级 | 对预防回用回收处置等的优先排序 |
| <a id="t32"></a>environmental footprint | 环境足迹 | 活动环境需求或影响的量化描述 |
| <a id="t33"></a>functional unit | 功能单位 | 生命周期比较采用的服务基准 |
| <a id="t34"></a>system boundary | 系统边界 | 评价纳入过程与排除过程的界线 |
| <a id="t35"></a>inventory analysis | 清单分析 | 汇总系统输入输出的评价阶段 |
| <a id="t36"></a>impact assessment | 影响评价 | 将清单等信息联系到影响类别 |
| <a id="t37"></a>exposure pathway | 暴露路径 | 受体接触污染因素的途径 |
| <a id="t38"></a>environmental monitoring | 环境监测 | 按方案记录环境状态与变化 |
| <a id="t39"></a>detection limit | 检出限 | 按规定方法可辨识的最低水平 |
| <a id="t40"></a>quantification limit | 定量限 | 按规定精度可定量的最低水平 |

## 使用时

缩写全称、计量基准、定义版本与稿件逐一对应。同名指标在不同学科可以有不同分母或时间范围。简释不替代正式定义。见 [教学示例](../worked-examples.md)。
