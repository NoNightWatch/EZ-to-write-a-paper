# 金融与会计：基础术语

领域编号：s02。本册 40 条短释义，用于识别稿件用语。涉及流派、量表或指标时，以作者所用来源和定义为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>asset | 资产 | 主体控制并预期产生利益的资源 |
| <a id="t02"></a>liability | 负债 | 主体承担的现时义务 |
| <a id="t03"></a>equity | 权益 | 资产扣除负债后的剩余利益 |
| <a id="t04"></a>revenue | 收入 | 日常经营活动形成的经济利益增加 |
| <a id="t05"></a>expense | 费用 | 经营活动等中的资源耗用 |
| <a id="t06"></a>profit | 利润 | 收入扣除相关费用后的结果 |
| <a id="t07"></a>cash flow | 现金流 | 现金及等价物的流入流出 |
| <a id="t08"></a>accrual | 应计项目 | 确认时点与收付现金时点的差额 |
| <a id="t09"></a>depreciation | 折旧 | 有形长期资产成本的期间分配 |
| <a id="t10"></a>amortization | 摊销 | 无形资产等成本的系统分配 |
| <a id="t11"></a>impairment | 减值 | 资产账面价值超过可收回基准的减少 |
| <a id="t12"></a>fair value | 公允价值 | 按适用准则定义的市场交易价值 |
| <a id="t13"></a>historical cost | 历史成本 | 取得资产等时的原始计量金额 |
| <a id="t14"></a>materiality | 重要性 | 信息遗漏错报对使用者决策的影响 |
| <a id="t15"></a>audit opinion | 审计意见 | 审计者对报表等形成的正式判断 |
| <a id="t16"></a>internal control | 内部控制 | 实现报告经营合规目标的控制体系 |
| <a id="t17"></a>earnings management | 盈余管理 | 通过选择影响报告盈余的行为 |
| <a id="t18"></a>financial disclosure | 财务披露 | 向使用者提供财务相关信息 |
| <a id="t19"></a>financial statement | 财务报表 | 反映财务状况和业绩的结构化报告 |
| <a id="t20"></a>balance sheet | 资产负债表 | 某时点资产负债权益的报告 |
| <a id="t21"></a>income statement | 利润表 | 某期间收入费用及利润的报告 |
| <a id="t22"></a>leverage | 杠杆 | 使用债务等放大财务敞口的程度 |
| <a id="t23"></a>liquidity | 流动性 | 及时变现或履行短期支付的能力 |
| <a id="t24"></a>solvency | 偿债能力 | 持续履行债务义务的能力 |
| <a id="t25"></a>return | 收益率 | 收益相对投入或价值的变化比例 |
| <a id="t26"></a>volatility | 波动率 | 收益等变量变动幅度的量度 |
| <a id="t27"></a>risk premium | 风险溢价 | 承担风险要求的额外预期回报 |
| <a id="t28"></a>diversification | 分散化 | 通过组合不同资产调整风险 |
| <a id="t29"></a>portfolio | 投资组合 | 共同持有的一组资产 |
| <a id="t30"></a>asset allocation | 资产配置 | 在不同资产类别间安排投资 |
| <a id="t31"></a>beta | 贝塔系数 | 收益对市场等基准变化的敏感度 |
| <a id="t32"></a>alpha | 阿尔法 | 相对模型基准的额外收益部分 |
| <a id="t33"></a>yield curve | 收益率曲线 | 利率与期限之间的关系 |
| <a id="t34"></a>duration | 久期 | 债券现金流时间与利率敏感度量度 |
| <a id="t35"></a>credit spread | 信用利差 | 相对基准的信用风险相关利差 |
| <a id="t36"></a>default risk | 违约风险 | 未按约履行债务的可能性 |
| <a id="t37"></a>derivative | 衍生工具 | 价值依赖标的变量的金融合约 |
| <a id="t38"></a>option | 期权 | 按约定条件交易标的的权利 |
| <a id="t39"></a>futures | 期货 | 标准化的未来交割合约 |
| <a id="t40"></a>net present value | 净现值 | 现金流入流出现值的净额 |

## 使用时

不要把不同测量口径、流派定义或地域制度统一成一个近义词。首次使用时提供必要上下文。需要更多说明可读 [教学示例](../worked-examples.md)，专业判断请作者确认。
