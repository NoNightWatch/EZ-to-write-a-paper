# 数学：基础术语

领域编号：n01。本册 40 条短释义，用于阅读定位和中英用语对照。术语的正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>set | 集合 | 由确定元素组成的整体 |
| <a id="t02"></a>element | 元素 | 集合中的一个对象 |
| <a id="t03"></a>subset | 子集 | 其元素均属于另一集合的集合 |
| <a id="t04"></a>function | 函数 | 将定义域元素对应到值的规则 |
| <a id="t05"></a>domain | 定义域 | 函数允许输入的集合 |
| <a id="t06"></a>codomain | 陪域 | 函数声明可取值的目标集合 |
| <a id="t07"></a>range | 值域 | 函数实际取得的值的集合 |
| <a id="t08"></a>injective | 单射 | 不同输入对应不同输出 |
| <a id="t09"></a>surjective | 满射 | 陪域中每个元素均有原像 |
| <a id="t10"></a>bijective | 双射 | 同时满足单射与满射 |
| <a id="t11"></a>axiom | 公理 | 理论中接受为起点的命题 |
| <a id="t12"></a>definition | 定义 | 规定概念含义的陈述 |
| <a id="t13"></a>theorem | 定理 | 在指定前提下已证明的命题 |
| <a id="t14"></a>lemma | 引理 | 常用于支持其他证明的命题 |
| <a id="t15"></a>corollary | 推论 | 由已有结果直接导出的命题 |
| <a id="t16"></a>conjecture | 猜想 | 尚未得到证明的数学命题 |
| <a id="t17"></a>counterexample | 反例 | 使普遍命题不成立的实例 |
| <a id="t18"></a>proof by contradiction | 反证法 | 由否定目标导致矛盾的证明形式 |
| <a id="t19"></a>mathematical induction | 数学归纳法 | 基于起点与递推步骤的证明形式 |
| <a id="t20"></a>necessary condition | 必要条件 | 结论成立时必须满足的条件 |
| <a id="t21"></a>sufficient condition | 充分条件 | 满足时足以推出结论的条件 |
| <a id="t22"></a>equivalence | 等价性 | 两个陈述或结构的相互对应关系 |
| <a id="t23"></a>sequence | 序列 | 按次序排列的数学对象 |
| <a id="t24"></a>convergence | 收敛 | 按规定意义趋向某个极限 |
| <a id="t25"></a>continuity | 连续性 | 函数值与输入变化相容的性质 |
| <a id="t26"></a>derivative | 导数 | 函数局部变化率 |
| <a id="t27"></a>integral | 积分 | 累积量或与微分相关的数学运算 |
| <a id="t28"></a>measure | 测度 | 为集合赋予大小的数学规则 |
| <a id="t29"></a>metric | 度量 | 满足特定条件的距离函数 |
| <a id="t30"></a>topology | 拓扑 | 用开集描述空间结构的体系 |
| <a id="t31"></a>compactness | 紧致性 | 开覆盖具有有限子覆盖等性质 |
| <a id="t32"></a>vector space | 向量空间 | 支持向量加法与数乘的结构 |
| <a id="t33"></a>linear transformation | 线性变换 | 保持加法与数乘的映射 |
| <a id="t34"></a>eigenvalue | 特征值 | 线性变换保持方向时的倍数 |
| <a id="t35"></a>norm | 范数 | 量化向量大小的函数 |
| <a id="t36"></a>group | 群 | 满足群公理的集合与运算 |
| <a id="t37"></a>ring | 环 | 具有相容加法和乘法的代数结构 |
| <a id="t38"></a>field | 域 | 满足域公理且非零元素可作除法的代数结构 |
| <a id="t39"></a>manifold | 流形 | 局部类似欧氏空间的空间 |
| <a id="t40"></a>boundary condition | 边界条件 | 在求解区域边界指定的条件 |

## 使用时

先确认此词在原句中的对象和含义，再决定是否替换。短释义不适合直接充当论文中的正式定义。首次出现的专业缩写按目标期刊要求展开；全稿中的同一概念统一用词。具体教学示例见 [编辑示例](../worked-examples.md)。
