# 哲学与伦理：基础术语

领域编号：h02。本册 40 条短释义；同一术语可随传统、流派或法域产生不同含义。未逐条外部审定；[来源属性](../foundation-sources.md)。法律词条仅作学术阅读对照。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>argument | 论证 | 以理由支持某结论的结构 |
| <a id="t02"></a>premise | 前提 | 论证中用来支持结论的陈述 |
| <a id="t03"></a>conclusion | 结论 | 论证试图支持的陈述 |
| <a id="t04"></a>validity | 逻辑有效性 | 前提真时结论不可能假的性质 |
| <a id="t05"></a>soundness | 健全性 | 论证有效且前提为真的性质 |
| <a id="t06"></a>deduction | 演绎 | 由前提按保真规则推出结论 |
| <a id="t07"></a>induction | 归纳 | 由实例等支持更广泛判断 |
| <a id="t08"></a>abduction | 溯因 | 从现象寻求较合适解释的推理 |
| <a id="t09"></a>fallacy | 谬误 | 论证中有缺陷的推理形式 |
| <a id="t10"></a>thought experiment | 思想实验 | 用设想情境考察概念与判断 |
| <a id="t11"></a>conceptual analysis | 概念分析 | 澄清概念含义及关系 |
| <a id="t12"></a>epistemology | 认识论 | 研究知识理由与认识的领域 |
| <a id="t13"></a>metaphysics | 形而上学 | 研究存在及现实基本结构的领域 |
| <a id="t14"></a>ontology | 本体论 | 研究何种事物存在及其类别 |
| <a id="t15"></a>ethics | 伦理学 | 研究行动价值和规范的领域 |
| <a id="t16"></a>aesthetics | 美学 | 研究审美艺术与体验的领域 |
| <a id="t17"></a>justification | 证成 | 支持信念或行动合理性的理由 |
| <a id="t18"></a>knowledge | 知识 | 关于认知成功的核心哲学概念 |
| <a id="t19"></a>belief | 信念 | 把某陈述视为真的心理态度 |
| <a id="t20"></a>skepticism | 怀疑论 | 质疑知识可能性或范围的立场 |
| <a id="t21"></a>realism | 实在论 | 承认对象具有独立存在等的立场 |
| <a id="t22"></a>anti-realism | 反实在论 | 对相应独立实在主张持保留的立场 |
| <a id="t23"></a>naturalism | 自然主义 | 强调自然解释或自然世界的立场 |
| <a id="t24"></a>physicalism | 物理主义 | 认为现实最终为物理性的立场 |
| <a id="t25"></a>dualism | 二元论 | 区分两类基本存在或性质的立场 |
| <a id="t26"></a>intentionality | 意向性 | 心灵状态关于或指向对象的性质 |
| <a id="t27"></a>consciousness | 意识 | 主观体验及觉知相关现象 |
| <a id="t28"></a>qualia | 感质 | 体验的主观质性特征 |
| <a id="t29"></a>free will | 自由意志 | 关于自主行动能力的哲学概念 |
| <a id="t30"></a>determinism | 决定论 | 先前状态与规律确定后续状态的主张 |
| <a id="t31"></a>compatibilism | 相容论 | 自由意志与决定论可相容的立场 |
| <a id="t32"></a>consequentialism | 后果主义 | 依据后果评价行动的伦理取向 |
| <a id="t33"></a>deontology | 义务论 | 重视义务规则等的伦理取向 |
| <a id="t34"></a>virtue ethics | 德性伦理 | 以人格德性为中心的伦理取向 |
| <a id="t35"></a>utilitarianism | 功利主义 | 依据总体福祉等评价的后果主义 |
| <a id="t36"></a>autonomy | 自主性 | 依据自身判断作出选择的能力 |
| <a id="t37"></a>justice | 正义 | 关于公正分配与对待的规范概念 |
| <a id="t38"></a>rights | 权利 | 主体可以正当主张的利益或资格 |
| <a id="t39"></a>moral responsibility | 道德责任 | 行动者应受道德评价的责任 |
| <a id="t40"></a>normativity | 规范性 | 涉及应当理由和评价的性质 |
