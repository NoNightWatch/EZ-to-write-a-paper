# 遗传与进化：基础术语

领域编号：n08。本册 40 条短释义，用于阅读定位和中英用语对照。正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>allele | 等位基因 | 同一基因座的不同序列形式 |
| <a id="t02"></a>locus | 基因座 | 遗传标记或基因在基因组中的位置 |
| <a id="t03"></a>genotype | 基因型 | 个体在指定位置的遗传组成 |
| <a id="t04"></a>phenotype | 表型 | 可观察的性状表现 |
| <a id="t05"></a>haplotype | 单倍型 | 同一染色体片段上的变异组合 |
| <a id="t06"></a>homozygosity | 纯合性 | 对应位点具有相同等位基因的状态 |
| <a id="t07"></a>heterozygosity | 杂合性 | 对应位点具有不同等位基因的状态 |
| <a id="t08"></a>dominance | 显性关系 | 杂合状态下等位基因的表型关系 |
| <a id="t09"></a>penetrance | 外显率 | 特定基因型表现相关表型的比例 |
| <a id="t10"></a>expressivity | 表现度 | 同一基因型表型表现的程度 |
| <a id="t11"></a>heritability | 遗传率 | 特定群体环境下遗传变异贡献的比例 |
| <a id="t12"></a>mutation | 突变 | 遗传序列发生的改变 |
| <a id="t13"></a>polymorphism | 多态性 | 群体中存在多个遗传或性状形式 |
| <a id="t14"></a>recombination | 重组 | 遗传片段形成新组合的过程 |
| <a id="t15"></a>linkage disequilibrium | 连锁不平衡 | 不同位点等位基因组合偏离独立性 |
| <a id="t16"></a>genetic drift | 遗传漂变 | 有限群体中的随机频率变化 |
| <a id="t17"></a>gene flow | 基因流 | 群体之间遗传变异的传递 |
| <a id="t18"></a>natural selection | 自然选择 | 遗传差异相关的繁殖成功差异 |
| <a id="t19"></a>sexual selection | 性选择 | 配偶获取等引起的繁殖成功差异 |
| <a id="t20"></a>fitness | 适合度 | 给定环境中的相对繁殖贡献 |
| <a id="t21"></a>adaptation | 适应 | 经演化形成的有利性状或相关过程 |
| <a id="t22"></a>exaptation | 外适应 | 已有性状被用于新的功能 |
| <a id="t23"></a>speciation | 物种形成 | 演化出相对独立谱系的过程 |
| <a id="t24"></a>reproductive isolation | 生殖隔离 | 限制群体间遗传交流的因素 |
| <a id="t25"></a>phylogeny | 系统发育 | 生物谱系之间的演化关系 |
| <a id="t26"></a>clade | 演化支 | 共同祖先及其全部后代组成的群 |
| <a id="t27"></a>homology | 同源性 | 特征因共同祖先而具有的关系 |
| <a id="t28"></a>analogy | 同功性 | 特征功能相似但来源不同的关系 |
| <a id="t29"></a>convergent evolution | 趋同演化 | 不同谱系独立形成相似性状 |
| <a id="t30"></a>ancestral state | 祖先状态 | 推定祖先具有的性状状态 |
| <a id="t31"></a>derived state | 衍生状态 | 相对祖先状态新出现的性状 |
| <a id="t32"></a>molecular clock | 分子钟 | 用分子变化估计分化时间的模型 |
| <a id="t33"></a>effective population size | 有效种群大小 | 与理想群体遗传过程相当的规模 |
| <a id="t34"></a>population bottleneck | 种群瓶颈 | 群体规模显著缩小的时期 |
| <a id="t35"></a>founder effect | 奠基者效应 | 少量建立者造成的遗传组成变化 |
| <a id="t36"></a>inbreeding | 近交 | 亲缘关系较近个体之间的繁殖 |
| <a id="t37"></a>outbreeding | 远交 | 亲缘关系较远个体之间的繁殖 |
| <a id="t38"></a>polyploidy | 多倍性 | 具有多于两套完整染色体组的状态 |
| <a id="t39"></a>pleiotropy | 多效性 | 一个遗传因素影响多个性状 |
| <a id="t40"></a>epistasis | 上位性 | 遗传因素之间的非独立表型作用 |
