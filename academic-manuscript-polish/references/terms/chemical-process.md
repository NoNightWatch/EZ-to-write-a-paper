# 化学工程：基础术语

领域编号：e08。本册 40 条短释义，正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>unit operation | 单元操作 | 基于物理过程的基本工艺环节 |
| <a id="t02"></a>unit process | 单元反应过程 | 涉及化学转化的基本工艺环节 |
| <a id="t03"></a>flowsheet | 工艺流程图 | 展示设备及物料连接的图 |
| <a id="t04"></a>process stream | 工艺物流 | 在设备之间流动的物料 |
| <a id="t05"></a>feedstock | 原料 | 进入生产转化过程的物质 |
| <a id="t06"></a>product stream | 产品流 | 含目标产物的输出物流 |
| <a id="t07"></a>material balance | 物料衡算 | 核算物质输入输出与积累 |
| <a id="t08"></a>energy balance | 能量衡算 | 核算能量输入输出与积累 |
| <a id="t09"></a>steady state | 稳态运行 | 过程变量无显著时间变化的状态 |
| <a id="t10"></a>transient operation | 瞬态运行 | 过程变量随时间变化的运行状态 |
| <a id="t11"></a>conversion | 转化率 | 反应物已被转化部分的比例 |
| <a id="t12"></a>recovery | 回收率 | 目标组分进入回收产品的比例 |
| <a id="t13"></a>separation factor | 分离因子 | 两组分相对分离程度的量度 |
| <a id="t14"></a>reactor | 反应器 | 进行规定反应过程的设备 |
| <a id="t15"></a>batch reactor | 间歇反应器 | 按批次装料反应的设备 |
| <a id="t16"></a>continuous reactor | 连续反应器 | 连续进出料的反应设备 |
| <a id="t17"></a>plug flow | 活塞流 | 流体依次通过且轴向混合很弱的理想流动 |
| <a id="t18"></a>residence time distribution | 停留时间分布 | 不同流体单元停留时间的分布 |
| <a id="t19"></a>mixing | 混合 | 使组分或性质在空间重新分布 |
| <a id="t20"></a>mass transfer | 传质 | 组分因梯度等发生的迁移 |
| <a id="t21"></a>diffusivity | 扩散系数 | 描述扩散速率的参数 |
| <a id="t22"></a>heat exchanger | 换热器 | 在不同物流之间传递热量的设备 |
| <a id="t23"></a>distillation | 蒸馏 | 利用挥发性差异分离组分 |
| <a id="t24"></a>absorption | 吸收 | 组分进入另一相内部的过程 |
| <a id="t25"></a>adsorption | 吸附 | 组分在表面或界面富集 |
| <a id="t26"></a>desorption | 解吸 | 已吸附组分离开表面的过程 |
| <a id="t27"></a>extraction | 萃取 | 利用相间分配差异转移组分 |
| <a id="t28"></a>filtration | 过滤 | 通过介质截留分散相 |
| <a id="t29"></a>membrane separation | 膜分离 | 利用膜的选择透过性分离组分 |
| <a id="t30"></a>crystallization | 结晶 | 从溶液或熔体等形成晶体 |
| <a id="t31"></a>drying | 干燥 | 从材料中移除水或其他挥发物 |
| <a id="t32"></a>evaporation | 蒸发 | 液体转变成气相的过程 |
| <a id="t33"></a>fluidization | 流化 | 颗粒床受流体作用呈流体状行为 |
| <a id="t34"></a>packed bed | 填充床 | 颗粒或填料组成的固定床层 |
| <a id="t35"></a>recycle stream | 循环物流 | 返回上游过程再次利用的物流 |
| <a id="t36"></a>purge stream | 排放支流 | 从循环体系移出部分物料的物流 |
| <a id="t37"></a>process intensification | 过程强化 | 通过工艺集成等提高过程表现 |
| <a id="t38"></a>scale-up | 放大 | 从较小规模转向较大规模 |
| <a id="t39"></a>techno-economic analysis | 技术经济分析 | 结合技术表现与经济成本的评估 |
| <a id="t40"></a>process safety | 过程安全 | 预防工艺系统失控与事故的领域 |

## 使用时

缩写全称、计量基准、定义版本与稿件逐一对应。同名指标在不同学科可以有不同分母或时间范围。简释不替代正式定义。见 [教学示例](../worked-examples.md)。
