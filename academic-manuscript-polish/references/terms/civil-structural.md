# 土木与结构工程：基础术语

领域编号：e04。本册 40 条短释义，用于阅读定位和中英用语对照。正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>load | 荷载 | 作用在结构上的力或其他作用 |
| <a id="t02"></a>dead load | 恒载 | 主要由结构自重等造成的长期荷载 |
| <a id="t03"></a>live load | 活载 | 使用活动等带来的可变荷载 |
| <a id="t04"></a>load combination | 荷载组合 | 设计中不同作用的组合方式 |
| <a id="t05"></a>load path | 传力路径 | 作用力在结构中传递的路线 |
| <a id="t06"></a>beam | 梁 | 主要承受横向荷载的杆件 |
| <a id="t07"></a>column | 柱 | 主要承受轴向作用的竖向构件 |
| <a id="t08"></a>slab | 板 | 厚度较小的平面承重构件 |
| <a id="t09"></a>foundation | 基础 | 将结构作用传给地基的部分 |
| <a id="t10"></a>pile | 桩 | 把荷载传至较深地层的构件 |
| <a id="t11"></a>retaining wall | 挡土墙 | 支挡侧向土体的结构 |
| <a id="t12"></a>truss | 桁架 | 由杆件组成的格构承重体系 |
| <a id="t13"></a>frame | 框架 | 由梁柱等连接形成的结构体系 |
| <a id="t14"></a>reinforcement | 配筋 | 增强混凝土等材料的筋材配置 |
| <a id="t15"></a>reinforced concrete | 钢筋混凝土 | 钢筋与混凝土共同工作的材料体系 |
| <a id="t16"></a>prestressing | 预应力 | 使用前人为施加的内力状态 |
| <a id="t17"></a>bending moment | 弯矩 | 导致构件弯曲的截面内力矩 |
| <a id="t18"></a>shear force | 剪力 | 使截面发生相对错动的内力 |
| <a id="t19"></a>deflection | 挠度 | 受力后构件轴线的横向位移 |
| <a id="t20"></a>buckling | 屈曲 | 结构变形形式突然改变的失稳现象 |
| <a id="t21"></a>stiffness | 刚度 | 抵抗变形的能力 |
| <a id="t22"></a>ductility | 延性 | 显著变形后仍维持承载的能力 |
| <a id="t23"></a>bearing capacity | 承载力 | 结构或地基承受作用的能力 |
| <a id="t24"></a>settlement | 沉降量 | 地基或结构向下位移的量 |
| <a id="t25"></a>differential settlement | 差异沉降 | 不同位置沉降量的差异 |
| <a id="t26"></a>serviceability | 适用性 | 正常使用功能满足要求的程度 |
| <a id="t27"></a>ultimate limit state | 承载能力极限状态 | 涉及破坏或失去承载能力的状态 |
| <a id="t28"></a>factor of safety | 安全系数 | 能力与需求等的规定比值 |
| <a id="t29"></a>seismic response | 地震响应 | 结构在地震作用下的行为 |
| <a id="t30"></a>damping ratio | 阻尼比 | 阻尼相对临界阻尼的比例 |
| <a id="t31"></a>natural period | 自振周期 | 系统自由振动的特征周期 |
| <a id="t32"></a>structural health monitoring | 结构健康监测 | 持续观测结构状态和变化 |
| <a id="t33"></a>durability | 耐久性 | 长期环境下保持性能的能力 |
| <a id="t34"></a>corrosion | 腐蚀 | 材料与环境作用导致的劣化 |
| <a id="t35"></a>concrete curing | 混凝土养护 | 维持适宜条件使混凝土形成性能 |
| <a id="t36"></a>water-cement ratio | 水灰比 | 拌合水质量与水泥质量之比 |
| <a id="t37"></a>aggregate | 骨料 | 混凝土等材料中的颗粒组分 |
| <a id="t38"></a>permeability | 渗透性 | 流体穿过材料的能力 |
| <a id="t39"></a>geotechnical investigation | 岩土勘察 | 查明地层及其工程性质 |
| <a id="t40"></a>building information modelling | 建筑信息建模 | 组织建筑全生命周期信息的建模方式 |

按稿件语境解释；相同英文跨领域可有不同含义。不能用本册简释替换原文的正式定义或条件。例句与修改解释见 [教学示例](../worked-examples.md)。
