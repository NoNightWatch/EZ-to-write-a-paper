# 公共卫生与流行病学：基础术语

领域编号：m03。本册 40 条短释义，正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。本册用于阅读和表达，不提供诊断、用药、护理处置或实验操作建议。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>incidence proportion | 累计发病风险 | 一定时段初始无病者中新发病例比例 |
| <a id="t02"></a>incidence rate | 发病率 | 新发病例数相对观察人时的速率 |
| <a id="t03"></a>prevalence | 患病率 | 某时点或期间具有疾病者的比例 |
| <a id="t04"></a>mortality rate | 死亡率 | 死亡数相对人群观察量的速率 |
| <a id="t05"></a>case fatality | 病死比例 | 病例中因该疾病死亡的比例 |
| <a id="t06"></a>morbidity | 患病状况 | 人群疾病发生与负担状况 |
| <a id="t07"></a>disease burden | 疾病负担 | 疾病造成健康等损失的综合描述 |
| <a id="t08"></a>life expectancy | 预期寿命 | 给定死亡水平下的平均生存年数 |
| <a id="t09"></a>DALY | 伤残调整寿命年 | 过早死亡与伤残所损失寿命年的合计 |
| <a id="t10"></a>QALY | 质量调整寿命年 | 按健康质量加权的生存时间 |
| <a id="t11"></a>surveillance | 监测 | 持续系统收集分析健康相关信息 |
| <a id="t12"></a>screening | 筛查 | 在无明确症状人群中寻找风险信号 |
| <a id="t13"></a>outbreak | 暴发 | 病例数在特定时间地点异常增加 |
| <a id="t14"></a>endemicity | 地方性流行 | 疾病在特定地区持续存在的状态 |
| <a id="t15"></a>epidemic | 流行 | 疾病发生超过通常预期水平 |
| <a id="t16"></a>pandemic | 大流行 | 波及多个国家或大区域的流行 |
| <a id="t17"></a>contact tracing | 接触者追踪 | 识别相关暴露接触者的公共卫生工作 |
| <a id="t18"></a>herd immunity | 群体免疫 | 群体免疫水平对传播形成的间接影响 |
| <a id="t19"></a>vaccination coverage | 疫苗接种覆盖率 | 目标人群中已接种者的比例 |
| <a id="t20"></a>health equity | 健康公平 | 减少可避免且不公正健康差异的目标 |
| <a id="t21"></a>health inequality | 健康不平等 | 群体间可观察的健康差异 |
| <a id="t22"></a>social determinants of health | 健康的社会决定因素 | 影响健康的社会生活条件 |
| <a id="t23"></a>health literacy | 健康素养 | 获取理解和运用健康信息的能力 |
| <a id="t24"></a>access to care | 医疗可及性 | 获得所需医疗服务的可能程度 |
| <a id="t25"></a>universal health coverage | 全民健康覆盖 | 所需服务可及且避免经济困难的目标 |
| <a id="t26"></a>primary prevention | 一级预防 | 在疾病出现前减少发生风险 |
| <a id="t27"></a>secondary prevention | 二级预防 | 早期发现并及时干预疾病 |
| <a id="t28"></a>tertiary prevention | 三级预防 | 减轻已患疾病造成的影响 |
| <a id="t29"></a>cohort | 队列 | 按共同特征或时间组织的人群 |
| <a id="t30"></a>case-control study | 病例对照研究 | 按疾病状态选人并比较既往因素 |
| <a id="t31"></a>cross-sectional study | 横断面研究 | 在特定时间考察状态与因素 |
| <a id="t32"></a>person-time | 人时 | 各参与者被观察时间的合计 |
| <a id="t33"></a>relative risk | 相对风险 | 两组事件发生风险的比值 |
| <a id="t34"></a>odds ratio | 优势比 | 两组事件优势的比值 |
| <a id="t35"></a>confounding | 混杂 | 其他因素影响目标关系解释的现象 |
| <a id="t36"></a>selection bias | 选择偏倚 | 纳入过程造成系统性差异 |
| <a id="t37"></a>information bias | 信息偏倚 | 信息获取误差造成的系统性差异 |
| <a id="t38"></a>age standardization | 年龄标准化 | 以统一年龄结构调整指标 |
| <a id="t39"></a>population attributable fraction | 人群归因分值 | 特定假设下归因于暴露的病例比例 |
| <a id="t40"></a>health impact assessment | 健康影响评价 | 评估政策或项目可能产生的健康影响 |

## 使用时

缩写全称、计量基准、定义版本与稿件逐一对应。同名指标在不同学科可以有不同分母或时间范围。简释不替代正式定义。见 [教学示例](../worked-examples.md)。
