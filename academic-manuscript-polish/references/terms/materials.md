# 材料科学：基础术语

领域编号：e06。本册 40 条短释义，用于阅读定位和中英用语对照。正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>microstructure | 微观组织 | 材料内部相与缺陷的空间结构 |
| <a id="t02"></a>crystal structure | 晶体结构 | 晶体中原子等的周期排列 |
| <a id="t03"></a>lattice | 晶格 | 描述周期结构的点阵 |
| <a id="t04"></a>unit cell | 晶胞 | 可重复构成晶格的基本单元 |
| <a id="t05"></a>grain | 晶粒 | 晶体取向相对一致的区域 |
| <a id="t06"></a>grain boundary | 晶界 | 相邻晶粒之间的界面 |
| <a id="t07"></a>dislocation | 位错 | 晶体中的线状结构缺陷 |
| <a id="t08"></a>vacancy | 空位 | 晶格中缺少原子的点缺陷 |
| <a id="t09"></a>interstitial | 间隙原子 | 处于正常晶格位置之间的原子 |
| <a id="t10"></a>phase diagram | 相图 | 平衡相随条件变化的图示 |
| <a id="t11"></a>phase transformation | 相变 | 材料从一种相转为另一种相 |
| <a id="t12"></a>nucleation | 形核 | 新相初始小区域的形成 |
| <a id="t13"></a>grain growth | 晶粒长大 | 晶粒尺寸随过程增大的现象 |
| <a id="t14"></a>annealing | 退火 | 通过热处理调整材料结构性能 |
| <a id="t15"></a>quenching | 淬火 | 快速冷却以改变材料结构的过程 |
| <a id="t16"></a>tempering | 回火 | 淬火后再加热调整组织性能 |
| <a id="t17"></a>sintering | 烧结 | 颗粒材料通过加热等结合致密化 |
| <a id="t18"></a>amorphous material | 非晶材料 | 缺乏长程周期结构的材料 |
| <a id="t19"></a>polymer | 聚合物 | 由重复结构单元组成的大分子材料 |
| <a id="t20"></a>monomer | 单体 | 可形成聚合物重复单元的小分子 |
| <a id="t21"></a>crosslinking | 交联 | 高分子链之间形成连接 |
| <a id="t22"></a>glass transition | 玻璃化转变 | 非晶部分由玻璃态到高弹态的转变 |
| <a id="t23"></a>composite | 复合材料 | 由不同组分组合形成的材料 |
| <a id="t24"></a>matrix | 基体 | 复合材料中连续的承载组分 |
| <a id="t25"></a>filler | 填料 | 加入材料以改变性质的分散组分 |
| <a id="t26"></a>ceramic | 陶瓷材料 | 通常为无机非金属的材料类别 |
| <a id="t27"></a>alloy | 合金 | 以金属为基础的多元素材料 |
| <a id="t28"></a>thin film | 薄膜 | 厚度显著小于其他尺寸的材料层 |
| <a id="t29"></a>coating | 涂层 | 覆盖基材表面以改变性质的层 |
| <a id="t30"></a>adhesion | 黏附 | 不同材料界面之间的结合 |
| <a id="t31"></a>wettability | 润湿性 | 液体在固体表面铺展的倾向 |
| <a id="t32"></a>contact angle | 接触角 | 液滴界面与固体表面的夹角 |
| <a id="t33"></a>surface energy | 表面能 | 形成单位面积表面所需的能量 |
| <a id="t34"></a>band gap | 带隙 | 允许电子能带之间的禁阻能区 |
| <a id="t35"></a>defect density | 缺陷密度 | 单位尺度内材料缺陷的数量 |
| <a id="t36"></a>nanostructure | 纳米结构 | 具有纳米尺度特征的结构 |
| <a id="t37"></a>specific surface area | 比表面积 | 单位质量或体积对应的表面积 |
| <a id="t38"></a>thermal expansion | 热膨胀 | 温度变化引起尺寸变化 |
| <a id="t39"></a>electrical conductivity | 电导率 | 材料传导电流能力的量度 |
| <a id="t40"></a>structure-property relationship | 结构性能关系 | 材料结构与表现之间的联系 |
