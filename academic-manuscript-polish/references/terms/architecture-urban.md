# 建筑与城市规划：基础术语

领域编号：e05。本册 40 条短释义，用于阅读定位和中英用语对照。正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>building typology | 建筑类型学 | 比较建筑形式和使用类型的研究 |
| <a id="t02"></a>site | 场地 | 建筑或规划对象所处的地点 |
| <a id="t03"></a>site plan | 总平面图 | 展示建筑与场地布局的图 |
| <a id="t04"></a>floor plan | 平面图 | 建筑水平剖切后的空间表示 |
| <a id="t05"></a>section drawing | 剖面图 | 展示垂直切面空间关系的图 |
| <a id="t06"></a>elevation drawing | 立面图 | 展示建筑外表面投影的图 |
| <a id="t07"></a>building envelope | 建筑围护结构 | 分隔室内外环境的外层体系 |
| <a id="t08"></a>facade | 建筑立面 | 建筑外侧可见的界面 |
| <a id="t09"></a>circulation | 流线 | 建筑中人员或物品移动的路线 |
| <a id="t10"></a>spatial configuration | 空间构型 | 空间单元之间的组织关系 |
| <a id="t11"></a>spatial syntax | 空间句法 | 分析空间关系与使用的理论方法 |
| <a id="t12"></a>daylighting | 天然采光 | 利用自然光照明室内空间 |
| <a id="t13"></a>thermal comfort | 热舒适 | 对热环境感到满意的状态 |
| <a id="t14"></a>indoor environmental quality | 室内环境品质 | 室内空气光热声等综合状况 |
| <a id="t15"></a>passive design | 被动式设计 | 利用形态材料等调节环境的设计 |
| <a id="t16"></a>adaptive reuse | 适应性再利用 | 为既有建筑赋予新的使用功能 |
| <a id="t17"></a>heritage conservation | 遗产保护 | 维护遗产价值及其物质载体 |
| <a id="t18"></a>post-occupancy evaluation | 使用后评估 | 建筑投入使用后的表现评估 |
| <a id="t19"></a>universal design | 通用设计 | 尽可能适应广泛使用者的设计 |
| <a id="t20"></a>accessibility | 可达性与无障碍 | 进入和使用空间或服务的便利程度 |
| <a id="t21"></a>urban morphology | 城市形态 | 城市物质空间的组成与演变 |
| <a id="t22"></a>urban fabric | 城市肌理 | 街道地块建筑组成的空间纹理 |
| <a id="t23"></a>land use | 土地利用 | 土地承担的实际用途 |
| <a id="t24"></a>zoning | 分区管制 | 对区域土地用途等的规则划分 |
| <a id="t25"></a>floor area ratio | 容积率 | 总建筑面积与用地面积之比 |
| <a id="t26"></a>building density | 建筑密度 | 建筑基底面积占用地面积的比例 |
| <a id="t27"></a>mixed-use development | 混合用途开发 | 同一区域结合多种使用功能 |
| <a id="t28"></a>transit-oriented development | 公共交通导向开发 | 围绕公共交通组织空间与用途 |
| <a id="t29"></a>walkability | 步行适宜性 | 环境支持步行活动的程度 |
| <a id="t30"></a>public realm | 公共空间领域 | 公众共同进入和使用的空间 |
| <a id="t31"></a>green infrastructure | 绿色基础设施 | 发挥生态等功能的绿地网络 |
| <a id="t32"></a>urban heat island | 城市热岛 | 城市相对周边地区较暖的现象 |
| <a id="t33"></a>urban regeneration | 城市更新 | 对既有城区功能环境的调整改善 |
| <a id="t34"></a>gentrification | 绅士化 | 社区阶层和空间价值上升的变迁 |
| <a id="t35"></a>informal settlement | 非正规住区 | 形成或管理超出现行正式制度的住区 |
| <a id="t36"></a>urban sprawl | 城市蔓延 | 低密度分散式城市外扩 |
| <a id="t37"></a>placemaking | 场所营造 | 围绕使用体验和地方意义组织空间 |
| <a id="t38"></a>participatory planning | 参与式规划 | 让相关群体参与规划过程 |
| <a id="t39"></a>master plan | 总体规划 | 较大范围空间发展的综合安排 |
| <a id="t40"></a>urban resilience | 城市韧性 | 城市应对扰动并维持或调整功能的能力 |
