# 能源工程：基础术语

领域编号：e07。本册 40 条短释义，正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>energy carrier | 能源载体 | 用于储存或传递能量的物质或形式 |
| <a id="t02"></a>primary energy | 一次能源 | 未经人为转换的能源形式 |
| <a id="t03"></a>final energy | 终端能源 | 交付最终使用者的能源 |
| <a id="t04"></a>useful energy | 有效能 | 最终设备提供的所需能量服务 |
| <a id="t05"></a>energy intensity | 能源强度 | 单位产出对应的能源使用量 |
| <a id="t06"></a>energy efficiency | 能源效率 | 有用输出相对能源输入的比例 |
| <a id="t07"></a>exergy | 火用 | 相对规定环境可转化为功的能力 |
| <a id="t08"></a>capacity factor | 容量因子 | 实际发电量相对满额发电量的比例 |
| <a id="t09"></a>installed capacity | 装机容量 | 设备额定输出能力的合计 |
| <a id="t10"></a>load factor | 负荷率 | 平均负荷与峰值负荷的比值 |
| <a id="t11"></a>peak demand | 峰值需求 | 指定时段的最大用能需求 |
| <a id="t12"></a>baseload | 基础负荷 | 较长时段持续存在的最低需求部分 |
| <a id="t13"></a>dispatch | 调度 | 安排能源设施运行和出力 |
| <a id="t14"></a>merit order | 优先次序 | 按规定成本等排序安排发电 |
| <a id="t15"></a>grid integration | 并网整合 | 将能源设施纳入电网运行体系 |
| <a id="t16"></a>grid flexibility | 电网灵活性 | 供需变化时调整运行的能力 |
| <a id="t17"></a>demand response | 需求响应 | 用户按信号调整用能行为 |
| <a id="t18"></a>energy storage | 储能 | 保存能量以供后续使用 |
| <a id="t19"></a>round-trip efficiency | 往返效率 | 储能放出量与充入量的比值 |
| <a id="t20"></a>state of charge | 荷电状态 | 电池当前容量相对规定容量的比例 |
| <a id="t21"></a>state of health | 健康状态 | 电池性能相对初始或额定状态的程度 |
| <a id="t22"></a>depth of discharge | 放电深度 | 已放出容量占规定容量的比例 |
| <a id="t23"></a>cycle life | 循环寿命 | 达到寿命标准前可完成的循环次数 |
| <a id="t24"></a>power density | 功率密度 | 单位质量或体积的输出功率 |
| <a id="t25"></a>energy density | 能量密度 | 单位质量或体积的储存能量 |
| <a id="t26"></a>photovoltaics | 光伏 | 利用光生电效应产生电能 |
| <a id="t27"></a>solar irradiance | 太阳辐照度 | 单位面积接收的太阳辐射功率 |
| <a id="t28"></a>wind resource | 风能资源 | 可用于发电的风况及能量潜力 |
| <a id="t29"></a>cut-in speed | 切入风速 | 风机开始发电的规定风速 |
| <a id="t30"></a>curtailment | 限发 | 可用发电能力被主动限制 |
| <a id="t31"></a>cogeneration | 热电联产 | 同一过程同时提供热与电 |
| <a id="t32"></a>heat pump | 热泵 | 消耗功把热从低温处转移到高温处 |
| <a id="t33"></a>coefficient of performance | 性能系数 | 有用供热或制冷量相对输入功 |
| <a id="t34"></a>electrolyser | 电解装置 | 利用电能驱动电解反应的设备 |
| <a id="t35"></a>fuel cell | 燃料电池 | 通过电化学反应持续产生电能 |
| <a id="t36"></a>levelized cost of energy | 平准化能源成本 | 全寿命折现成本相对能源产出的量度 |
| <a id="t37"></a>energy payback time | 能源回收期 | 产出抵偿投入能源所需时间 |
| <a id="t38"></a>life-cycle assessment | 生命周期评价 | 核算生命周期环境影响的框架 |
| <a id="t39"></a>decarbonization | 脱碳 | 降低活动相关碳排放的过程 |
| <a id="t40"></a>net-zero emissions | 净零排放 | 规定范围内排放与移除相平衡 |

## 使用时

缩写全称、计量基准、定义版本与稿件逐一对应。同名指标在不同学科可以有不同分母或时间范围。简释不替代正式定义。见 [教学示例](../worked-examples.md)。
