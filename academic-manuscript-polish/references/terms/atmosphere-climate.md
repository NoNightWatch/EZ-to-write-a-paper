| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>weather | 天气 | 较短时间内的大气状态 |
| <a id="t02"></a>climate | 气候 | 较长时段天气的统计特征 |
| <a id="t03"></a>climate variability | 气候变率 | 气候状态围绕平均状况的变动 |
| <a id="t04"></a>climate change | 气候变化 | 持续较长时间的气候统计变化 |

| <a id="t06"></a>baseline period | 基准期 | 计算变化时使用的参照时段 |
| <a id="t07"></a>radiative forcing | 辐射强迫 | 特定扰动造成的辐射收支变化量 |
| <a id="t08"></a>effective radiative forcing | 有效辐射强迫 | 包含规定快速调整的辐射强迫 |
| <a id="t09"></a>greenhouse effect | 温室效应 | 大气改变长波辐射传输的增温作用 |
| <a id="t10"></a>greenhouse gas | 温室气体 | 吸收和发射相关红外辐射的气体 |
| <a id="t11"></a>albedo | 反照率 | 反射辐射相对入射辐射的比例 |

| <a id="t13"></a>cloud feedback | 云反馈 | 云变化对初始气候变化的反馈 |
| <a id="t14"></a>climate sensitivity | 气候敏感度 | 温度对规定强迫的响应尺度 |
| <a id="t15"></a>equilibrium climate sensitivity | 平衡气候敏感度 | 二氧化碳加倍下的平衡增温尺度 |
| <a id="t16"></a>transient climate response | 瞬态气候响应 | 规定增浓实验中加倍时的增温尺度 |
| <a id="t17"></a>carbon budget | 碳预算 | 规定时期或目标下的碳收支 |
| <a id="t18"></a>carbon sink | 碳汇 | 净吸收碳的过程或储库 |

| <a id="t22"></a>forecast | 预报 | 对未来实际状态的预测判断 |
| <a id="t23"></a>ensemble | 集合模拟 | 一组不同初值或模型等的模拟 |
| <a id="t24"></a>downscaling | 降尺度 | 由较粗信息获得较细尺度信息 |
| <a id="t25"></a>reanalysis | 再分析 | 结合观测与模型重建历史状态 |
| <a id="t26"></a>attribution | 归因 | 评估所观测变化的来源与贡献 |

| <a id="t35"></a>precipitation | 降水 | 从大气到达地面的水物质 |

## 使用时

先确认此词在原句中的对象和含义，再决定是否替换。短释义不适合直接充当论文中的正式定义。首次出现的专业缩写按目标期刊要求展开；全稿中的同一概念统一用词。具体教学示例见 [编辑示例](../worked-examples.md)。
