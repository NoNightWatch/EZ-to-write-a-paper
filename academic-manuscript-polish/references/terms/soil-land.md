# 土壤与土地管理：基础术语

领域编号：a02。本册 40 条短释义，用于识别稿件用语。涉及流派、量表或指标时，以作者所用来源和定义为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>soil horizon | 土壤发生层 | 土体中性质相对不同的层次 |
| <a id="t02"></a>soil profile | 土壤剖面 | 从地表向下展示土层的截面 |
| <a id="t03"></a>soil texture | 土壤质地 | 不同粒级矿物颗粒的比例组成 |
| <a id="t04"></a>soil structure | 土壤结构 | 土粒及孔隙的组织形式 |
| <a id="t05"></a>soil aggregate | 土壤团聚体 | 多个土粒结合形成的单元 |
| <a id="t06"></a>bulk density | 容重 | 干土质量相对总体积的比值 |
| <a id="t07"></a>particle density | 颗粒密度 | 固体质量相对固体体积的比值 |
| <a id="t08"></a>soil moisture | 土壤水分 | 土体中水的数量与状态 |
| <a id="t09"></a>field capacity | 田间持水量 | 重力排水明显减缓后的含水量 |
| <a id="t10"></a>wilting point | 凋萎点 | 植物难以从土中获取水的参照含水状态 |
| <a id="t11"></a>available water capacity | 有效持水容量 | 规定田间持水量与凋萎点之间的水量 |
| <a id="t12"></a>soil organic carbon | 土壤有机碳 | 土壤有机物所含的碳 |
| <a id="t13"></a>soil organic matter | 土壤有机质 | 土壤中的有机物质总称 |
| <a id="t14"></a>particulate organic matter | 颗粒有机质 | 按颗粒等方法分离的有机质组分 |
| <a id="t15"></a>mineral-associated organic matter | 矿物结合有机质 | 与矿物组分关联的有机质 |
| <a id="t16"></a>dissolved organic carbon | 溶解性有机碳 | 按规定过滤等界定的溶解有机碳 |
| <a id="t17"></a>microbial biomass carbon | 微生物生物量碳 | 活体微生物组分所含碳的估计 |
| <a id="t18"></a>soil respiration | 土壤呼吸 | 土壤相关生物过程释放二氧化碳 |
| <a id="t19"></a>mineralization | 矿化 | 有机形态元素转化为无机形态 |
| <a id="t20"></a>immobilization | 固持 | 无机养分进入生物或有机组分 |
| <a id="t21"></a>priming effect | 激发效应 | 新增底物改变原有有机质分解 |
| <a id="t22"></a>carbon use efficiency | 碳利用效率 | 规定碳输入中用于生长等的比例 |
| <a id="t23"></a>rhizosphere | 根际 | 受根系显著影响的土壤区域 |
| <a id="t24"></a>root exudate | 根系分泌物 | 根系释放到周围的物质 |
| <a id="t25"></a>mycorrhiza | 菌根 | 真菌与植物根形成的共生结构 |
| <a id="t26"></a>cation exchange capacity | 阳离子交换容量 | 土壤可交换阳离子的容量量度 |
| <a id="t27"></a>base saturation | 盐基饱和度 | 交换位点中盐基阳离子所占比例 |
| <a id="t28"></a>soil acidity | 土壤酸度 | 土壤酸性状态及其组分 |
| <a id="t29"></a>salinization | 盐渍化 | 可溶盐在土壤中积累的过程 |
| <a id="t30"></a>sodicity | 钠质化程度 | 交换性钠对土壤性质影响的程度 |
| <a id="t31"></a>redox potential | 氧化还原电位 | 体系氧化还原状态的电位表征 |
| <a id="t32"></a>sorption | 吸持 | 吸附和吸收等保留过程的统称 |
| <a id="t33"></a>leaching | 淋失 | 溶质随水向下或离开土体 |
| <a id="t34"></a>soil erodibility | 土壤可蚀性 | 土壤受侵蚀的易感程度 |
| <a id="t35"></a>soil sealing | 土壤封闭 | 不透水覆盖等使土表功能受限 |
| <a id="t36"></a>land degradation | 土地退化 | 土地生态或生产功能下降 |
| <a id="t37"></a>land capability | 土地能力 | 土地支持不同利用的适宜能力 |
| <a id="t38"></a>soil health | 土壤健康 | 土壤维持生态与生产功能的状态 |
| <a id="t39"></a>soil carbon stock | 土壤碳储量 | 规定面积和深度内的碳总量 |
| <a id="t40"></a>equivalent soil mass | 等质量土层基准 | 以相同土壤质量比较库存的基准 |

## 使用时

不要把不同测量口径、流派定义或地域制度统一成一个近义词。首次使用时提供必要上下文。需要更多说明可读 [教学示例](../worked-examples.md)，专业判断请作者确认。
