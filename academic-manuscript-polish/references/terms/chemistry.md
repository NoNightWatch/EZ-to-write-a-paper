# 化学：基础术语

领域编号：n03。本册 40 条短释义，用于阅读定位和中英用语对照。术语的正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>atom | 原子 | 保留元素身份的基本粒子单位 |
| <a id="t02"></a>molecule | 分子 | 由成键原子构成的离散实体 |
| <a id="t03"></a>ion | 离子 | 带净电荷的原子或原子团 |
| <a id="t04"></a>isotope | 同位素 | 同元素中中子数不同的原子类型 |
| <a id="t05"></a>orbital | 轨道 | 描述电子量子状态的函数 |
| <a id="t06"></a>valence | 化合价 | 描述元素成键能力的形式概念 |
| <a id="t07"></a>oxidation state | 氧化态 | 按规定电子归属得到的形式电荷 |
| <a id="t08"></a>covalent bond | 共价键 | 原子共享电子形成的化学键 |
| <a id="t09"></a>ionic bond | 离子键 | 主要由离子间静电作用形成的键 |
| <a id="t10"></a>hydrogen bond | 氢键 | 特定氢原子参与的方向性相互作用 |
| <a id="t11"></a>electronegativity | 电负性 | 成键原子吸引电子的相对能力 |
| <a id="t12"></a>polarity | 极性 | 电荷分布不均的性质 |
| <a id="t13"></a>functional group | 官能团 | 赋予分子特征反应性质的原子团 |
| <a id="t14"></a>isomer | 异构体 | 组成相同而结构或排列不同的分子 |
| <a id="t15"></a>chirality | 手性 | 对象与镜像不能重合的性质 |
| <a id="t16"></a>enantiomer | 对映体 | 互为不可重合镜像的异构体 |
| <a id="t17"></a>diastereomer | 非对映异构体 | 不互为镜像的立体异构体 |
| <a id="t18"></a>conformation | 构象 | 单键旋转等产生的空间排列 |
| <a id="t19"></a>tautomerism | 互变异构 | 可相互转化的特定异构形式关系 |
| <a id="t20"></a>stoichiometry | 化学计量关系 | 反应或组成中的数量比例 |
| <a id="t21"></a>mole | 摩尔 | 物质的量的 SI 单位 |
| <a id="t22"></a>molar mass | 摩尔质量 | 单位物质的量对应的质量 |
| <a id="t23"></a>concentration | 浓度 | 组分含量相对混合体系的量度 |
| <a id="t24"></a>solubility | 溶解度 | 规定条件下可溶解的平衡量 |
| <a id="t25"></a>solvent | 溶剂 | 溶液中承担溶解介质的组分 |
| <a id="t26"></a>solute | 溶质 | 溶解在介质中的组分 |
| <a id="t27"></a>activity | 活度 | 热力学中有效浓度的量度 |
| <a id="t28"></a>pH | pH 值 | 氢离子活度的负常用对数 |
| <a id="t29"></a>buffer | 缓冲体系 | 减小酸碱加入所致 pH 变化的体系 |
| <a id="t30"></a>equilibrium constant | 平衡常数 | 平衡状态下反应物与产物活度关系 |
| <a id="t31"></a>reaction rate | 反应速率 | 反应进程随时间变化的快慢 |
| <a id="t32"></a>activation energy | 活化能 | 温度依赖中表征反应势垒的参数 |
| <a id="t33"></a>catalyst | 催化剂 | 改变反应速率且在循环中再生的物质 |
| <a id="t34"></a>intermediate | 中间体 | 反应过程中生成并进一步反应的物种 |
| <a id="t35"></a>transition state | 过渡态 | 反应路径中势垒附近的状态 |
| <a id="t36"></a>yield | 产率 | 目标产物量相对规定基准的比例 |
| <a id="t37"></a>selectivity | 选择性 | 形成目标产物或响应目标物的偏好 |
| <a id="t38"></a>chromatography | 色谱法 | 利用相间分配差异分离组分的方法 |
| <a id="t39"></a>spectroscopy | 光谱学 | 通过物质与辐射相互作用研究性质 |
| <a id="t40"></a>titration | 滴定 | 以定量反应测定待测物含量的方法 |

## 使用时

先确认此词在原句中的对象和含义，再决定是否替换。短释义不适合直接充当论文中的正式定义。首次出现的专业缩写按目标期刊要求展开；全稿中的同一概念统一用词。具体教学示例见 [编辑示例](../worked-examples.md)。
