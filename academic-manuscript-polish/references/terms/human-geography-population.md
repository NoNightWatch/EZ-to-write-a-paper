# 人文地理与人口：基础术语

领域编号：s11。本册 40 条短释义；同一术语可随传统、流派或法域产生不同含义。未逐条外部审定；[来源属性](../foundation-sources.md)。法律词条仅作学术阅读对照。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>place | 地方 | 具有位置和社会意义的空间 |
| <a id="t02"></a>space | 空间 | 对象活动和关系展开的范围 |
| <a id="t03"></a>scale | 尺度 | 观察或组织空间现象的层级 |
| <a id="t04"></a>territory | 领土或领域 | 由权力或身份界定的空间 |
| <a id="t05"></a>region | 区域 | 因共同特征等划定的空间单元 |
| <a id="t06"></a>spatial interaction | 空间相互作用 | 不同地点之间的流动和联系 |
| <a id="t07"></a>spatial autocorrelation | 空间自相关 | 相邻位置属性的相似或相异关系 |
| <a id="t08"></a>spatial heterogeneity | 空间异质性 | 属性或关系在空间上的差异 |
| <a id="t09"></a>spatial segregation | 空间隔离 | 群体在空间分布上的分离 |
| <a id="t10"></a>residential mobility | 居住流动 | 居住地点的变更 |
| <a id="t11"></a>migration | 迁移 | 跨一定空间界线改变居住地 |
| <a id="t12"></a>immigration | 迁入 | 从研究区域之外进入定居 |
| <a id="t13"></a>emigration | 迁出 | 离开研究区域到外部定居 |
| <a id="t14"></a>net migration | 净迁移 | 迁入人数减去迁出人数 |
| <a id="t15"></a>diaspora | 离散社群 | 跨地域分布且保有来源联系的群体 |
| <a id="t16"></a>transnationalism | 跨国联系 | 跨国家边界持续组织的社会关系 |
| <a id="t17"></a>urbanization | 城市化 | 人口活动和空间向城市形式转变 |
| <a id="t18"></a>suburbanization | 郊区化 | 人口活动向城市外围迁移扩展 |
| <a id="t19"></a>rurality | 乡村性 | 构成乡村特征的社会空间属性 |
| <a id="t20"></a>population density | 人口密度 | 单位面积的人口数量 |
| <a id="t21"></a>population composition | 人口构成 | 人口按年龄等属性的组成 |
| <a id="t22"></a>population pyramid | 人口金字塔 | 按年龄性别展示人口结构的图 |
| <a id="t23"></a>age structure | 年龄结构 | 人口在不同年龄组的分布 |
| <a id="t24"></a>sex ratio | 性别比 | 按规定口径计算的不同性别人数比 |
| <a id="t25"></a>dependency ratio | 抚养比 | 非劳动年龄人口相对劳动年龄人口的比值 |
| <a id="t26"></a>fertility rate | 生育率 | 出生数相对育龄等人口基准的量度 |
| <a id="t27"></a>total fertility rate | 总和生育率 | 按当期年龄别生育率合成的生育数量 |
| <a id="t28"></a>replacement fertility | 更替水平生育 | 长期维持代际人口更替的生育水平 |
| <a id="t29"></a>demographic transition | 人口转变 | 出生死亡水平随发展变化的过程 |
| <a id="t30"></a>population aging | 人口老龄化 | 较高年龄人口占比上升 |
| <a id="t31"></a>life table | 生命表 | 按年龄展示生存死亡规律的表 |
| <a id="t32"></a>cohort component method | 队列要素法 | 结合生育死亡迁移推算人口 |
| <a id="t33"></a>household size | 户规模 | 一个家庭户中的人数 |
| <a id="t34"></a>commuting | 通勤 | 居住地与工作学习地之间往返 |
| <a id="t35"></a>activity space | 活动空间 | 个人日常活动覆盖的空间 |
| <a id="t36"></a>accessibility index | 可达性指数 | 到达机会或服务便利性的量度 |
| <a id="t37"></a>distance decay | 距离衰减 | 联系强度随距离增加而下降的模式 |
| <a id="t38"></a>modifiable areal unit problem | 可变空间单元问题 | 统计结果随空间分区改变而变化 |
| <a id="t39"></a>ecological fallacy | 生态谬误 | 将群体层面关系直接归于个体 |
| <a id="t40"></a>geocoding | 地理编码 | 把地址等转换为空间位置标识 |
