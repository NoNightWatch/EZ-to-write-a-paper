# 计算机与人工智能：基础术语

领域编号：n10。本册 40 条短释义，用于阅读定位和中英用语对照。正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>algorithm | 算法 | 完成计算任务的有限规则步骤 |
| <a id="t02"></a>data structure | 数据结构 | 组织和存储数据的方式 |
| <a id="t03"></a>computational complexity | 计算复杂度 | 资源需求随问题规模变化的性质 |
| <a id="t04"></a>time complexity | 时间复杂度 | 计算时间随输入规模增长的描述 |
| <a id="t05"></a>space complexity | 空间复杂度 | 存储需求随输入规模增长的描述 |
| <a id="t06"></a>recursion | 递归 | 通过调用自身较小实例求解 |
| <a id="t07"></a>iteration | 迭代 | 重复执行更新过程 |
| <a id="t08"></a>database | 数据库 | 按结构组织并管理的数据集合 |
| <a id="t09"></a>query | 查询 | 从数据系统请求特定信息 |
| <a id="t10"></a>transaction | 事务 | 作为一个逻辑整体处理的数据库操作 |
| <a id="t11"></a>concurrency | 并发 | 多个任务交错推进的状态 |
| <a id="t12"></a>parallelism | 并行 | 多个任务同时执行 |
| <a id="t13"></a>distributed system | 分布式系统 | 由通信节点协作组成的系统 |
| <a id="t14"></a>latency | 时延 | 请求到响应等之间的等待时间 |
| <a id="t15"></a>throughput | 吞吐量 | 单位时间完成的工作量 |
| <a id="t16"></a>scalability | 可扩展性 | 资源或任务规模变化时的适应能力 |
| <a id="t17"></a>training set | 训练集 | 用于学习模型参数的数据 |
| <a id="t18"></a>validation set | 验证集 | 用于模型选择等的数据 |
| <a id="t19"></a>test set | 测试集 | 用于最终评估的数据 |
| <a id="t20"></a>feature | 特征 | 供模型利用的输入属性 |
| <a id="t21"></a>label | 标签 | 监督学习中的目标标注 |
| <a id="t22"></a>loss function | 损失函数 | 量化预测与目标差异的函数 |
| <a id="t23"></a>optimization | 优化 | 在约束下寻找较优目标值 |
| <a id="t24"></a>regularization | 正则化 | 通过约束或惩罚控制模型复杂性 |
| <a id="t25"></a>overfitting | 过拟合 | 过度适应训练细节而泛化较差 |
| <a id="t26"></a>generalization | 泛化 | 模型对新数据的适用表现 |
| <a id="t27"></a>embedding | 嵌入表示 | 将对象映射到向量空间的表示 |
| <a id="t28"></a>attention | 注意力机制 | 按相关性加权组合信息的机制 |
| <a id="t29"></a>transformer | Transformer 架构 | 以注意力为核心的神经网络架构 |
| <a id="t30"></a>language model | 语言模型 | 对语言序列进行概率建模的模型 |
| <a id="t31"></a>token | 词元 | 模型处理文本时的基本单元 |
| <a id="t32"></a>inference | 模型推断 | 已训练模型产生输出的过程 |
| <a id="t33"></a>fine-tuning | 微调 | 在既有模型上继续适配训练 |
| <a id="t34"></a>retrieval-augmented generation | 检索增强生成 | 结合外部检索内容生成文本 |
| <a id="t35"></a>benchmark | 基准任务集 | 用于比较系统表现的标准任务材料 |
| <a id="t36"></a>precision | 查准率 | 预测为正的实例中实际为正的比例 |
| <a id="t37"></a>recall | 查全率 | 实际为正的实例中被检出的比例 |
| <a id="t38"></a>F1 score | F1 分数 | 查准率与查全率的调和平均 |
| <a id="t39"></a>reproducibility | 可复现性 | 按所述条件重新获得结果的性质 |
| <a id="t40"></a>software dependency | 软件依赖 | 软件运行所需的其他组件 |
