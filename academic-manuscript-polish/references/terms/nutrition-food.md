# 营养与食品科学：基础术语

领域编号：m06。本册 40 条短释义，正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。本册用于阅读和表达，不提供诊断、用药、护理处置或实验操作建议。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>nutrient | 营养素 | 机体所需的食物成分 |
| <a id="t02"></a>macronutrient | 常量营养素 | 需要量较大的供能等营养组分 |
| <a id="t03"></a>micronutrient | 微量营养素 | 需要量较小的维生素矿物质等 |
| <a id="t04"></a>dietary intake | 膳食摄入 | 通过食物饮料摄取的量 |
| <a id="t05"></a>dietary pattern | 膳食模式 | 多类食物摄入的总体组合 |
| <a id="t06"></a>energy intake | 能量摄入 | 从食物饮料获得的能量 |
| <a id="t07"></a>energy expenditure | 能量消耗 | 机体活动和维持所用能量 |
| <a id="t08"></a>energy balance | 能量平衡 | 能量摄入与消耗的关系 |
| <a id="t09"></a>basal metabolic rate | 基础代谢率 | 规定基础状态下的能量消耗速率 |
| <a id="t10"></a>recommended dietary allowance | 推荐膳食供给量 | 满足多数健康个体需要的推荐摄入量 |
| <a id="t11"></a>adequate intake | 适宜摄入量 | 证据不足以定推荐量时的参考摄入量 |
| <a id="t12"></a>tolerable upper intake level | 可耐受最高摄入量 | 通常不致不良影响的最高日摄入水平 |
| <a id="t13"></a>bioaccessibility | 生物可及性 | 消化等后可供吸收的组分比例 |
| <a id="t14"></a>digestibility | 消化率 | 被消化部分占摄入部分的比例 |
| <a id="t15"></a>dietary fiber | 膳食纤维 | 不被人体小肠充分消化的特定碳水组分 |
| <a id="t16"></a>glycemic index | 血糖生成指数 | 食物引起血糖反应的相对尺度 |
| <a id="t17"></a>glycemic load | 血糖负荷 | 结合血糖生成指数与摄入量的指标 |
| <a id="t18"></a>essential amino acid | 必需氨基酸 | 需由膳食提供足量的氨基酸 |
| <a id="t19"></a>fatty acid | 脂肪酸 | 构成多种脂质的羧酸 |
| <a id="t20"></a>saturated fat | 饱和脂肪 | 富含无碳碳双键脂肪酸的脂肪 |
| <a id="t21"></a>unsaturated fat | 不饱和脂肪 | 含有碳碳双键脂肪酸的脂肪 |
| <a id="t22"></a>food matrix | 食物基质 | 食物成分组成的物理化学结构 |
| <a id="t23"></a>food security | 粮食安全 | 持续获得足够适宜食物的状态 |
| <a id="t24"></a>food safety | 食品安全 | 食物不造成不可接受健康危害的状态 |
| <a id="t25"></a>shelf life | 货架期 | 规定储存下维持可接受品质的时间 |
| <a id="t26"></a>water activity | 水分活度 | 食品中水的热力学有效程度 |
| <a id="t27"></a>moisture content | 含水量 | 材料中水的数量比例 |
| <a id="t28"></a>texture | 质构 | 食物受力和口腔感知的结构性质 |
| <a id="t29"></a>sensory evaluation | 感官评价 | 用人的感官系统评价产品 |
| <a id="t30"></a>palatability | 适口性 | 食物引起愉悦和接受的程度 |
| <a id="t31"></a>emulsion | 乳状液 | 一种液体以微滴分散于另一液体 |
| <a id="t32"></a>gelation | 凝胶化 | 形成连续网络并固定流体的过程 |
| <a id="t33"></a>denaturation | 变性 | 蛋白质等原有结构发生改变 |
| <a id="t34"></a>Maillard reaction | 美拉德反应 | 还原糖与氨基组分相关的褐变反应 |
| <a id="t35"></a>oxidative rancidity | 氧化酸败 | 脂质氧化造成的品质劣变 |
| <a id="t36"></a>pasteurization | 巴氏杀菌 | 降低特定微生物风险的温和热处理 |
| <a id="t37"></a>fermentation | 发酵 | 利用生物代谢改变食品等材料 |
| <a id="t38"></a>fortification | 营养强化 | 向食品添加特定营养素 |
| <a id="t39"></a>nutritional epidemiology | 营养流行病学 | 研究饮食营养与人群健康的领域 |
| <a id="t40"></a>food frequency questionnaire | 食物频率问卷 | 记录一段时间食物摄入频率的工具 |

## 使用时

缩写全称、计量基准、定义版本与稿件逐一对应。同名指标在不同学科可以有不同分母或时间范围。简释不替代正式定义。见 [教学示例](../worked-examples.md)。
