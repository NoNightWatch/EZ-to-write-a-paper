# 政治与公共管理：基础术语

领域编号：s07。本册 40 条短释义；同一术语可随传统、流派或法域产生不同含义。未逐条外部审定；[来源属性](../foundation-sources.md)。法律词条仅作学术阅读对照。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>state | 国家 | 具有制度化统治权的政治组织 |
| <a id="t02"></a>government | 政府 | 执行公共权力的机构体系 |
| <a id="t03"></a>regime | 政体 | 组织政治权力和竞争的制度安排 |
| <a id="t04"></a>sovereignty | 主权 | 对一定领域具有最高权威的原则 |
| <a id="t05"></a>legitimacy | 合法性 | 权威被认可为正当的程度 |
| <a id="t06"></a>authority | 权威 | 被承认具有约束力的支配关系 |
| <a id="t07"></a>power | 权力 | 影响行动或结果的能力 |
| <a id="t08"></a>democracy | 民主 | 公众参与及问责等组成的政治原则 |
| <a id="t09"></a>representation | 代表 | 由特定行动者表达他人利益与意志 |
| <a id="t10"></a>accountability | 问责 | 对行为解释并承担责任的关系 |
| <a id="t11"></a>transparency | 透明度 | 决策和信息可被外部了解的程度 |
| <a id="t12"></a>rule of law | 法治 | 公共权力等受法律约束的原则 |
| <a id="t13"></a>separation of powers | 权力分立 | 国家权力在不同机关间分配 |
| <a id="t14"></a>federalism | 联邦制 | 中央与成员单位分权的制度 |
| <a id="t15"></a>decentralization | 分权化 | 权力责任向较低层级转移 |
| <a id="t16"></a>bureaucracy | 官僚制 | 依规则和层级运作的组织方式 |
| <a id="t17"></a>public administration | 公共行政 | 公共事务的组织和执行 |
| <a id="t18"></a>governance | 治理 | 多方协调公共事务的制度与过程 |
| <a id="t19"></a>public policy | 公共政策 | 公共机关处理事项的行动安排 |
| <a id="t20"></a>policy agenda | 政策议程 | 获得政策关注的事项集合 |
| <a id="t21"></a>policy formulation | 政策制定 | 形成和选择政策内容的过程 |
| <a id="t22"></a>policy implementation | 政策执行 | 将政策安排付诸行动 |
| <a id="t23"></a>policy evaluation | 政策评估 | 考察政策实施及结果 |
| <a id="t24"></a>policy instrument | 政策工具 | 实现政策目标所采用的手段 |
| <a id="t25"></a>regulation | 规制 | 以规则等约束活动的公共安排 |
| <a id="t26"></a>deregulation | 放松规制 | 减少或调整既有监管约束 |
| <a id="t27"></a>policy diffusion | 政策扩散 | 政策跨地区或机构传播 |
| <a id="t28"></a>policy feedback | 政策反馈 | 既有政策改变后续政治与政策过程 |
| <a id="t29"></a>path dependence | 路径依赖 | 先前选择持续影响后续选择 |
| <a id="t30"></a>institutional change | 制度变迁 | 正式或非正式规则发生变化 |
| <a id="t31"></a>public value | 公共价值 | 公共行动对集体利益的贡献 |
| <a id="t32"></a>public service | 公共服务 | 为公众需求提供的服务 |
| <a id="t33"></a>street-level bureaucracy | 街头官僚体系 | 直接面对公众且具有裁量的执行层 |
| <a id="t34"></a>discretion | 裁量权 | 在规则范围内作出判断的空间 |
| <a id="t35"></a>collective choice | 集体选择 | 由群体形成共同决策的过程 |
| <a id="t36"></a>voter turnout | 选举参与率 | 有资格者中参加投票的比例 |
| <a id="t37"></a>electoral system | 选举制度 | 把选票转换为代表席位的规则 |
| <a id="t38"></a>coalition | 联盟 | 围绕共同目标形成的合作组合 |
| <a id="t39"></a>interest group | 利益集团 | 组织起来影响公共决策的群体 |
| <a id="t40"></a>civil society | 公民社会 | 国家与市场之外的自主社会活动领域 |
