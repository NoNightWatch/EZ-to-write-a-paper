# 音乐影视与表演：基础术语

领域编号：h07。本册 40 条短释义；同一术语可随传统、流派或法域产生不同含义。未逐条外部审定；[来源属性](../foundation-sources.md)。法律词条仅作学术阅读对照。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>pitch | 音高 | 听觉中声音高低的属性 |
| <a id="t02"></a>timbre | 音色 | 区分同音高响度声音的质性 |
| <a id="t03"></a>rhythm | 节奏 | 声音事件时长与重音的组织 |
| <a id="t04"></a>meter | 节拍 | 强弱拍的规律性分组 |
| <a id="t05"></a>tempo | 速度 | 音乐时间推进的快慢 |
| <a id="t06"></a>melody | 旋律 | 具有组织性的音高序列 |
| <a id="t07"></a>harmony | 和声 | 多个音的同时关系及其连接 |
| <a id="t08"></a>counterpoint | 对位 | 相对独立声部的结合规则 |
| <a id="t09"></a>tonality | 调性 | 围绕中心音组织音高关系 |
| <a id="t10"></a>modulation | 转调 | 音乐从一种调性进入另一种 |
| <a id="t11"></a>cadence | 终止式 | 乐句结束或停顿的和声旋律形式 |
| <a id="t12"></a>musical texture | 音乐织体 | 声部数量及相互关系 |
| <a id="t13"></a>score | 乐谱 | 记录音乐结构与演奏信息的文本 |
| <a id="t14"></a>notation | 记谱法 | 表示音乐内容的符号体系 |
| <a id="t15"></a>orchestration | 配器 | 为不同乐器安排音乐材料 |
| <a id="t16"></a>improvisation | 即兴 | 演出中即时形成音乐或行动 |
| <a id="t17"></a>motif | 动机 | 可辨识并发展的短小音乐材料 |
| <a id="t18"></a>leitmotif | 主导动机 | 与人物观念等反复关联的音乐动机 |
| <a id="t19"></a>shot | 镜头 | 一次连续拍摄或剪辑单元 |
| <a id="t20"></a>scene | 场景段落 | 在相对统一时空中的叙事单元 |
| <a id="t21"></a>sequence | 段落组 | 围绕一项事件组织的多个场景 |
| <a id="t22"></a>mise-en-scène | 场面调度 | 镜头内空间人物光线等的组织 |
| <a id="t23"></a>cinematography | 摄影造型 | 影像拍摄中的视觉技术与选择 |
| <a id="t24"></a>framing | 取景构图 | 镜头边界内对象的安排 |
| <a id="t25"></a>depth of field | 景深 | 影像中可接受清晰的距离范围 |
| <a id="t26"></a>montage | 蒙太奇 | 通过镜头组合产生意义的方式 |
| <a id="t27"></a>continuity editing | 连续性剪辑 | 维持时空动作连贯的剪辑 |
| <a id="t28"></a>jump cut | 跳切 | 相近镜头连接造成明显时间位置跳跃 |
| <a id="t29"></a>diegetic sound | 叙事内声音 | 属于故事世界的声音 |
| <a id="t30"></a>non-diegetic sound | 叙事外声音 | 不属于故事世界的配乐等声音 |
| <a id="t31"></a>voice-over | 画外解说 | 不由画面中可见说话者发出的叙述 |
| <a id="t32"></a>sound design | 声音设计 | 组织声音材料及其空间时间关系 |
| <a id="t33"></a>dramaturgy | 戏剧构作 | 组织戏剧材料与演出逻辑的工作 |
| <a id="t34"></a>blocking | 舞台走位 | 演员在空间中的位置与移动安排 |
| <a id="t35"></a>choreography | 编舞 | 组织身体动作和舞蹈结构 |
| <a id="t36"></a>embodiment | 具身性 | 体验和意义通过身体形成的性质 |
| <a id="t37"></a>liveness | 现场性 | 演出当下共同在场的性质 |
| <a id="t38"></a>spectatorship | 观看关系 | 观众如何观看和参与意义形成 |
| <a id="t39"></a>adaptation | 改编 | 将既有作品转成另一作品或媒介 |
| <a id="t40"></a>performance analysis | 表演分析 | 结合动作空间声音等解释演出 |

## 使用时

保留作者采用的理论传统、译名与版本；需要统一译名时先检查引用出处。受争议概念只整理作者已有界定。例句见 [教学示例](../worked-examples.md)。
