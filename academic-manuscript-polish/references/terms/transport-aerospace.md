# 交通与航空航天：基础术语

领域编号：e09。本册 40 条短释义，正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>traffic flow | 交通流量 | 单位时间通过位置的交通单元数 |
| <a id="t02"></a>traffic density | 交通密度 | 单位长度道路上的车辆数 |
| <a id="t03"></a>headway | 车头时距 | 相邻车辆通过同一点的时间间隔 |
| <a id="t04"></a>travel time | 出行时间 | 完成一段出行所需的时间 |
| <a id="t05"></a>travel time reliability | 出行时间可靠性 | 出行时间的可预测程度 |
| <a id="t06"></a>modal split | 方式分担率 | 各交通方式在出行中所占比例 |
| <a id="t07"></a>trip generation | 出行生成 | 区域产生或吸引的出行量 |
| <a id="t08"></a>origin-destination matrix | 起讫点矩阵 | 不同起点终点之间的出行量表 |
| <a id="t09"></a>route choice | 路径选择 | 出行者对可用路线的选择 |
| <a id="t10"></a>network assignment | 网络分配 | 将出行需求分配到交通网络 |
| <a id="t11"></a>congestion | 拥堵 | 需求接近或超过通行能力的状态 |
| <a id="t12"></a>level of service | 服务水平 | 对交通运行质量的分级表述 |
| <a id="t13"></a>road capacity | 道路通行能力 | 规定条件下可通过的最大交通量 |
| <a id="t14"></a>public transit | 公共交通 | 面向公众提供的共享客运服务 |
| <a id="t15"></a>intermodal transport | 多式联运 | 组合多种运输方式完成运输 |
| <a id="t16"></a>last-mile delivery | 末端配送 | 货物送达最终接收者的环节 |
| <a id="t17"></a>logistics | 物流 | 组织物品运输储存等的过程 |
| <a id="t18"></a>freight | 货运 | 货物运输活动或所运货物 |
| <a id="t19"></a>fleet | 车队或机队 | 统一组织的一组运输工具 |
| <a id="t20"></a>vehicle dynamics | 车辆动力学 | 车辆运动及受力关系 |
| <a id="t21"></a>aerodynamics | 空气动力学 | 气流与物体运动相互作用的学科 |
| <a id="t22"></a>lift | 升力 | 主要垂直来流方向的气动力 |
| <a id="t23"></a>drag | 阻力 | 主要沿来流方向阻碍运动的力 |
| <a id="t24"></a>thrust | 推力 | 推进系统产生的驱动力 |
| <a id="t25"></a>angle of attack | 迎角 | 翼弦等参考方向与来流的夹角 |
| <a id="t26"></a>stall | 失速 | 分离加剧导致升力等性能骤变 |
| <a id="t27"></a>Mach number | 马赫数 | 速度与当地声速的比值 |
| <a id="t28"></a>Reynolds number | 雷诺数 | 惯性作用相对黏性作用的无量纲量 |
| <a id="t29"></a>airfoil | 翼型 | 机翼等结构的截面轮廓 |
| <a id="t30"></a>boundary-layer separation | 边界层分离 | 近壁流动脱离表面的现象 |
| <a id="t31"></a>flight envelope | 飞行包线 | 允许飞行状态范围的边界 |
| <a id="t32"></a>payload | 有效载荷 | 执行运输或任务所携带的有效质量 |
| <a id="t33"></a>range | 航程 | 在规定条件下可行进的距离 |
| <a id="t34"></a>endurance | 续航时间 | 在规定条件下可持续运行的时间 |
| <a id="t35"></a>specific impulse | 比冲 | 推进剂利用效率的推力时间尺度 |
| <a id="t36"></a>orbital period | 轨道周期 | 绕中心天体运行一周的时间 |
| <a id="t37"></a>orbital inclination | 轨道倾角 | 轨道平面与参考平面的夹角 |
| <a id="t38"></a>attitude control | 姿态控制 | 调节飞行器方向的控制 |
| <a id="t39"></a>re-entry | 再入 | 飞行器由外部空间返回大气层 |
| <a id="t40"></a>airworthiness | 适航性 | 航空器符合安全运行要求的状态 |

## 使用时

缩写全称、计量基准、定义版本与稿件逐一对应。同名指标在不同学科可以有不同分母或时间范围。简释不替代正式定义。见 [教学示例](../worked-examples.md)。
