# 机械与制造：基础术语

领域编号：e03。本册 40 条短释义，用于阅读定位和中英用语对照。正式技术条件以稿件采用的来源为准。未逐条外部审定；[来源属性](../foundation-sources.md)。

[返回学科目录](../discipline-map.md)

| 英文 | 中文 | 入门释义 |
|---|---|---|
| <a id="t01"></a>stress | 应力 | 材料内部单位面积上的作用力 |
| <a id="t02"></a>strain | 应变 | 材料形状或尺寸的相对变化 |
| <a id="t03"></a>elasticity | 弹性 | 卸载后恢复形变的性质 |
| <a id="t04"></a>plasticity | 塑性 | 卸载后保留永久形变的性质 |
| <a id="t05"></a>Young's modulus | 杨氏模量 | 单轴弹性应力与应变的比例 |
| <a id="t06"></a>Poisson's ratio | 泊松比 | 横向与轴向应变的相关比值 |
| <a id="t07"></a>yield strength | 屈服强度 | 开始显著塑性变形的应力尺度 |
| <a id="t08"></a>tensile strength | 抗拉强度 | 拉伸试验中的最大工程应力 |
| <a id="t09"></a>fatigue | 疲劳 | 循环载荷引起的损伤过程 |
| <a id="t10"></a>creep | 蠕变 | 持续载荷下随时间发展的形变 |
| <a id="t11"></a>fracture | 断裂 | 材料分离形成裂面的过程 |
| <a id="t12"></a>toughness | 韧性 | 材料吸收能量并抵抗断裂的能力 |
| <a id="t13"></a>hardness | 硬度 | 抵抗局部永久形变的能力 |
| <a id="t14"></a>tribology | 摩擦学 | 研究接触运动中的摩擦磨损润滑 |
| <a id="t15"></a>friction coefficient | 摩擦系数 | 摩擦力相对法向载荷的比值 |
| <a id="t16"></a>wear | 磨损 | 接触运动造成的材料损失或改变 |
| <a id="t17"></a>lubrication | 润滑 | 以介质调节接触摩擦磨损 |
| <a id="t18"></a>bearing | 轴承 | 支承并引导相对运动的部件 |
| <a id="t19"></a>gear | 齿轮 | 通过啮合传递运动的机械件 |
| <a id="t20"></a>shaft | 轴 | 传递旋转运动或支承转动件的构件 |
| <a id="t21"></a>tolerance | 公差 | 允许的尺寸或几何偏差范围 |
| <a id="t22"></a>surface roughness | 表面粗糙度 | 表面微小起伏的量化描述 |
| <a id="t23"></a>machining | 机械加工 | 以工具等形成目标几何形状 |
| <a id="t24"></a>milling | 铣削 | 旋转刀具去除材料的加工方式 |
| <a id="t25"></a>turning | 车削 | 旋转工件配合刀具的加工方式 |
| <a id="t26"></a>casting | 铸造 | 材料在模具中凝固成形的过程 |
| <a id="t27"></a>forging | 锻造 | 通过塑性变形加工金属的过程 |
| <a id="t28"></a>welding | 焊接 | 通过局部结合连接材料的工艺 |
| <a id="t29"></a>additive manufacturing | 增材制造 | 逐层等方式增加材料形成物件 |
| <a id="t30"></a>subtractive manufacturing | 减材制造 | 从原材料去除部分形成物件 |
| <a id="t31"></a>toolpath | 刀具路径 | 加工工具的运动路线 |
| <a id="t32"></a>process window | 工艺窗口 | 满足要求的一组工艺参数范围 |
| <a id="t33"></a>cycle time | 周期时间 | 完成一个作业循环的时间 |
| <a id="t34"></a>lead time | 交付周期 | 从请求到完成交付的历时 |
| <a id="t35"></a>quality control | 质量控制 | 监测并维持产品过程质量 |
| <a id="t36"></a>non-destructive testing | 无损检测 | 不破坏主要使用性能的检测 |
| <a id="t37"></a>finite element analysis | 有限元分析 | 把连续体离散化进行数值求解 |
| <a id="t38"></a>vibration mode | 振型 | 系统特定频率下的变形形式 |
| <a id="t39"></a>heat transfer | 传热 | 温差引起的能量转移 |
| <a id="t40"></a>thermal conductivity | 热导率 | 材料传导热量能力的量度 |

## 使用时

按稿件语境解释；相同英文跨领域可有不同含义。不能用本册简释替换原文的正式定义或条件。例句与修改解释见 [教学示例](../worked-examples.md)。
