# 学术英语表达工具页

用于已有内容的语言修改。以下例句均为自拟；方括号表示需要作者真实材料。句式只是表达功能，不暗示研究已经完成。

## 十种常用句子任务

| 任务 | 自拟句式 | 普通中文说明 | 使用限制 |
|---|---|---|---|
| 界定用语 | In this article, [term] refers to [definition]. | 本文把这个词用于什么含义 | 定义须来自作者 |
| 说明任务 | We examine [object] in [context]. | 本文考察什么、在什么情境中 | 不自动改成解释或证明 |
| 介绍材料 | The analysis draws on [materials]. | 分析使用哪些材料 | 必须确实使用过 |
| 说明范围 | The study focuses on [scope]. | 本文集中处理的范围 | 不遗漏关键限制 |
| 指向图表 | Table 2 summarizes [content]. | 表 2 汇总什么 | 表号及内容须对应 |
| 进行对照 | [A] and [B] differ in [reported feature]. | A 与 B 在哪个方面不同 | 差异须由作者提供 |
| 给出阶段 | We first describe [A] and then consider [B]. | 告诉读者后面的安排 | 仅用于真实章节顺序 |
| 引入文献 | [Source] describes [reported finding]. | 明确是谁提出的内容 | 引用与论述范围一致 |
| 标出未知 | The available material does not establish [claim]. | 说明材料没有确认哪句话 | 需基于已读取材料，不泛指领域未知 |
| 限定外推 | These observations concern [the studied context]. | 把观察限定在实际语境 | 不自行增加作者未声明的限制 |

## 常用动词怎样选

- describe：描述现象或材料。
- compare：比较明确对象。
- examine / investigate：考察问题，含义相对宽。
- estimate：由数据或模型估计量值；不把直接计数随意改名为估计。
- quantify：把对象表达为数量，需有实际量化材料。
- evaluate / assess：按作者给出的标准评价或评估。
- propose：提出主张或方法，不表示已经验证。
- develop：开发或形成对象，需与实际工作相符。
- demonstrate / establish / prove：可能使读者理解为更强确认，不能仅为避免重复而替换普通动词。

## 句子层面的常见修改

| 原表达 | 可选写法 | 说明 |
|---|---|---|
| an analysis of X was conducted | we analysed X | 作者或期刊允许第一人称时可简化 |
| in order to compare | to compare | 不影响含义时减少赘词 |
| due to the fact that | because | 原文确实表达原因时才保留原因连接 |
| a large number of | many | 数量已在其他地方交代时可简化 |
| it is important to note that X | X | 若提示语没有额外作用可删除 |
| this was higher | the mean score was higher | 先确认 this 的真实指代 |
| the data shows | the data show | 当全文采用 data 的复数用法时统一 |
| informations | information | 一般作不可数名词 |
| evidences | evidence | 一般指证据整体时用不可数形式 |
| researches on X | research on X / studies of X | 依研究整体或多项研究选择 |

data 的单复数等细节存在领域和出版习惯差异。保持全稿一致并核对目标期刊，不能把某一风格选择都当成语法错误。

## 时态、人称与语态

已完成的具体操作通常用过去时；文章当前呈现的表图可用现在时；前人研究可按具体历史事件或持续知识选择时态。不存在所有论文必须只用一种时态的规则。

作者执行的动作可用主动语态，关注对象或未知执行者时可用被动语态。某刊明确要求第三人称时依其规定，例如本包期刊卡中的农业期刊。不要把全篇机械改为 we 或机械删除 we。

## 段落衔接

先确定关系再选连接词：顺序、补充、比较、转折、原因与结果是不同关系。只知道两个段落相邻时，可用中性的文章安排句。没有作者依据时，不增加 therefore、because 或 consequently。

同一段尽量围绕一个清楚任务。段首交代对象，后续句子逐步补充，结尾按需要连接下段。段落可以很短，也可以较长；按内容和版式决定，不按固定句数打分。

## 简洁与保留含义

删掉重复开场、重复定义和对表格逐格复述。保留改变适用范围的限定，例如 finite、under the stated conditions、in the sampled population。不要为了短句删去否定词、比较基准或时间范围。

不追求生僻词密度，不任意替换专业术语，不模仿特定论文的独特措辞。原稿已经清楚时可以保持原句，并解释无需修改。
