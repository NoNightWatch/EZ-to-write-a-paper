# 第一篇论文：从材料到整稿

[English course entry](first-paper-course.en.md) · [新手入口](beginner-guide.md)

适合想从头学写论文的人。你可以先用本课程的虚构材料练习，也可以带自己的研究记录。无需先有英文稿或目标期刊。本课程练习如何组织和表达已有证据；真实研究仍需要相应领域的指导。

## 怎样开始

把下面的话发给能够读取完整指南的助手：

> 我想从零学写整篇论文。请读取 first-paper-course.md，使用其中的虚构案例，用中文讲解。先带我做 E01，只给当前任务和必要示范，让我尝试后再反馈。卡住时给一个具体提示。我可以随时要求参考答案。不要把教学材料写进我的真实论文。

想自己阅读：先打开[材料](paper-case-materials.md)，再做[学生练习](paper-workbook.zh-CN.md)。想先看完整过程：打开[连续带写](paper-case-walkthrough.md)和[完整英文范文](paper-case-manuscript.md)。练习与答案分开存放，选择“直接看示范”随时可用。

## 这条路线会留下什么

| 阶段 | 你动手做的事 | 得到的写作材料 |
|---|---|---|
| E01 材料 | 区分已经知道、没测过和还需确认的内容 | 事实清单与材料缺口 |
| E02 问题 | 把问题限定到现有资料能回答的范围 | 一句研究问题与全文提纲 |
| E03 方法 | 让别人知道材料怎样选、指标怎样数 | 可复查的方法段 |
| E04 结果 | 从原始记录计算、选数、写段落 | 结果表和结果段 |
| E05 引言 | 比较两份阅读卡，说明本文任务 | 有出处、范围清楚的引言 |
| E06 讨论 | 回答问题，说明解释及适用范围 | 与结果对应的讨论与结论 |
| E07 标题摘要 | 缩写已完成的全文 | 标题、摘要、关键词 |
| E08 整稿 | 合并各节，沿全文核对同一主张 | 一份有版本标记的完整练习稿 |
| T01 新材料 | 换成另一组材料，减少提示再写 | 独立练习和反馈记录 |

写作顺序和最终阅读顺序可以不同。这里先写方法、结果，再写引言；最终稿按标题、摘要、引言、方法、结果、讨论、结论、参考资料排列。这是一个描述性文档比较案例。数学证明、历史论述、质性研究、综述等体裁应按实际任务调整章节，可查[章节手册](section-handbook.md)。

## 一轮怎样进行

1. 说明本轮目标，只打开相关材料和练习。第一次可以先解释“研究对象”“结果”等当前用得上的词。
2. 给一个小示范或提示，再请学生写。学生可用中文、要点或英文作答，不因英语困难误判其理解。
3. 按[反馈流程](paper-feedback.md)指出原文位置、具体影响和一个修改动作。保留有依据、已经清楚的表达。
4. 学生重写后比较两版。记录本次哪些判断能自己完成、哪些使用了提示；这只描述当前任务。
5. 若学生愿意，推进下一步。要求直接给稿时交稿；要求一次读完整教程时直接提供路线和链接，不逐节等待授权。

助手默认先读材料和当前练习。学生尚未要求答案时，无需加载[参考答案](paper-answer-key.md)和范文。需要判断事实可读取材料、重新计算；需要评价措辞可接受不同的正确写法。学生要求答案后说明参考答案可有多种。

## 卡住时，怎样获得实质帮助

“缺少材料”需要配一个可执行动作：查哪张表、找哪条记录、问导师什么、当前哪一句可以先写。[材料缺口桥接](missing-materials.md)提供具体例子。没有真实数据的人可先做本课程；不能把虚构案例改名后当自己的研究。

## 怎样判断这一轮学到了什么

看学生能否定位一句话的依据、保留对象和范围、说明段落作用，以及换一份材料后能否调整写法。看到或复述答案只记录为“看过示范”。同一题重写正确，记录为“本题修订完成”。完成 T01 后按实际表现列出独立完成项和仍需帮助项，不给录用预测或综合能力标签。

E08 会得到一篇完整的教学稿。它仍然使用虚构材料，不能投稿。完成课程也不能证明已掌握研究设计或本学科专业判断。本包尚无真实学生学习成效验证。

暂停时用[续接卡](../assets/learning-checkpoint.md)记录练习编号、稿件版本、使用过的提示、未决事项和下一步。默认只在对话中展示；只有学生要求保存时才写到其工作区。
