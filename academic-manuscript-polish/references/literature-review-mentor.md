# 文献综述导师：从几篇材料到有组织的文字

给第一次写综述的作者，也供助手按需使用。先处理当前一段或一节，无需先学完整套综述方法。这里教阅读记录、材料比较和表达组织；专业理论、因果解释和研究设计需要相应领域的依据。

材料来源及取舍见 [教材评估](review-source-assessment.md)。流程为编辑综合，不是某篇论文原有的统一规范。可配合 [工作表](../assets/review-workbook.md) 与 [完整示例和练习](review-worked-example.md)。

材料包含史料、概念论述、数学命题或不同基准记录时，可选读 [四个跨学科练习](review-transfer-cases.md)。按对象与任务选择例子，不把实验指标作为所有材料的共同字段。

## 只想先写出一小段

把已有笔记或文献发来，并说这段想让读者理解什么。助手先挑与该问题直接有关的材料，列出能确认的内容，给一个限定范围的段落。材料只有一篇也可以先练准确概括，暂不声称多篇综合。无需填完整张工作表或读完本页。

如果不知道该问什么，可说：“请先指出这两份材料在讨论什么，找一个可以比较的地方，给我一段示范。”关键部分尚未读到时，助手说明缺哪一段；不要求你先提交完整综述。

本页常用词的普通解释：

| 词 | 在当前任务里做什么 |
|---|---|
| 来源 source | 提供信息的具体论文、书、资料或记录 |
| 引文 citation | 告诉读者这句话的信息来自哪里；准确改写后仍需要注明来源 |
| 概括 summary | 用自己的话保留一份材料的相关内容与范围 |
| 综合 synthesis | 围绕一个问题说明几份材料之间的关系，保留各自依据 |
| 比较维度 | 本次选来比较的方面，例如所讨论对象、时期或概念用法 |
| 范围 scope | 这段文字准备覆盖哪些材料和问题，哪些暂未覆盖 |

这些解释帮助开始写作，不替代具体领域的正式定义。读者只需查看当前遇到的词。

## 1. 先确定你在写哪一种文字

助手从作者现有要求判断；不清楚时只问：“这是正文中的一段、学位论文的一章，还是准备独立投稿的综述？”

| 当前任务 | 先完成什么 | 不强加的要求 |
|---|---|---|
| 引言中的文献段落、related work | 说明与本文直接有关的已有工作及联系 | 不要求为几句话重新做完整系统综述 |
| 学位论文综述章 | 按院系要求组织范围、概念及相关研究，让后续章节有依据 | 不照搬某篇期刊论文的段数或篇幅 |
| 独立综述论文 | 确认读者、综述问题、实际资料获取与综合方式、目标期刊文章类型 | 不因文献多、画了流程图就标为 systematic review |

没有期刊时可先写有来源的一段。题目很宽、材料只有几篇时，交付限定范围的提纲或试写段落；不声称覆盖领域。

系统综述重视明确问题与透明、预先考虑的检索筛选和综合过程。元分析是可选的统计综合方法，两者不可画等号。叙述性、整合性、范围综述等名称有各自方法语境，不能只凭标题选名。本教程不提供完整系统综述研究方案；确需开展时另核对该领域方法指南和目标期刊要求。[Snyder 的范围与限制](review-source-assessment.md#r01)

<a id="plan"></a>

## 2. 用三句话写出当前任务

先说清：

1. 我在整理什么具体问题，写给谁看？
2. 目前有哪些可用材料，哪些内容尚未读到？
3. 这段或这一章准备帮助读者理解什么？

例如：“我要为设计课程论文写一段，介绍图示说明书的评价方式。目前有三篇文章的完整结果段。读者需要分清耗时、错误和使用偏好分别提供什么信息。”

这个任务可以立即开始。“综述全世界关于设计的所有研究”则需要先缩小范围。既有文献已经回答的问题可以如实交代，不必强造空白。写作动机也可以来自更新资料、澄清术语或整理分散材料，但价值必须结合具体任务说明。

独立综述需要更详细的来源计划；引言短段只保留必要记录。设计、获取材料、整理分析和写作之间可以往返，变更范围时保留理由。[流程来源](review-source-assessment.md#r01)

<a id="read"></a>

## 3. 分层阅读，给每条信息留位置

参考 [Keshav 的分遍阅读](review-source-assessment.md#r08)，按用途决定读到哪一层：

| 这一遍的任务 | 看什么 | 可以记录什么 |
|---|---|---|
| 判断相关性 | 题名、摘要、结构、开头与结尾 | 与当前任务的关系，尚待核实的问题 |
| 理解相关内容 | 所需正文、图表、定义及上下文 | 原文报告了什么，适用于哪些对象或条件 |
| 核查关键依据 | 支撑重要句子的完整论证、方法、图表及必要补充材料 | 当前句子是否得到支持，有哪些条件不可省略 |

不规定每遍几分钟。陌生术语可以先查一个，不把整篇都看不懂归为能力不足。只读摘要可以做初筛，不能据此宣布全文论证正确、全文没有讨论某事，或已经核实其方法缺陷。

记录准确题名、作者、年份、版本，以及 PDF 页码和章节。页码含封面时注明“PDF 第几页”，不要与印刷页码混用。原文摘录与自己的概括分开；转述后仍需引文。只看过综述的转述，就保留转引身份；关键主张应尽量核对原始来源，未读到时明说。

书目信息正确与句子得到支持分开记录。尤其检查一句话合并多个判断、引用只放段末，以及自译内容被当成原文直引的情况。具体见 [引用支持核对](author-literature.md#claim-check)。

预印本与正式版、同一研究的多篇报告可能共享数据。可以分别记录版本与内容差别，不能自动计为多项独立证据。一个 DOI 对应多个下载文件，也不会增加研究数量。

<a id="matrix"></a>

## 4. 先做一个够用的小表

每篇先填五项：来源位置、研究问题、与当前段落相关的内容、适用范围、准备放在哪个比较组。看不见的信息写进工作记录的缺项栏，不猜数值。

“综合”在这里指：让几篇材料共同回答一个明确问题，同时保留各自的范围。它需要能回到原文核对的比较，不等于把摘要依次缩短。

比较维度可以由作者给出；作者授权整理时，助手也可根据已读材料提出候选，并说明为何这样分。例如按研究对象、定义、评价指标、材料类型或时期组织。分类是一种当前写作选择，不冒充领域公认体系。专业原因尚未确定时，先呈现观察到的区别。

遇到“结果冲突”先核对它们是否谈同一对象、同一含义、同一时间范围。同名词语可能对应不同指标。这里允许指出文本中可核查的不一致，不提供跨学科通用的机制推论。[来源选择与分类反思](review-source-assessment.md#r03)

几篇持相近观点的论文不自动构成领域共识；可能互相转引或使用同一数据。论文篇数也不能代替依据比较。需要统计合并时，交由合适的方法流程处理，本教程不教按显著性结果投票。

<a id="paragraph"></a>

## 5. 从表里写出一个段落

先试一种可调整的安排：

1. **本段问题**：告诉读者正在比较什么。
2. **必要材料**：选能回答该问题的来源，交代对应内容和条件。
3. **材料之间的关系**：说明共同点、补充关系或有依据的分歧。
4. **本段落点**：说明这些材料对当前论文任务的意义与适用范围。

不是每段都需要四句话；关系清楚的短段可以合并。引文紧跟它支持的内容，不能在段尾放一串引用让读者猜每篇支持哪一句。单篇资料特别重要时可以单独讨论，避免机械禁止“某作者发现”。

把自己的概括标清楚。例如“在本段所比较的三篇材料中……”限定资料范围；“这些研究已经证明所有场景……”需要远超三篇材料的支持。英文示范及逐句说明见 [完整练习](review-worked-example.md#draft)。

引言可以围绕已有工作、具体问题和本文任务组织。[Barney](review-source-assessment.md#r04) 的三段安排适合观察这些功能，但不要求所有学科用三段、固定页数或以 However 开头。[Locke 与 Golden-Biddle](review-source-assessment.md#r05) 可供进阶读者观察文献之间的连接方式，不用它们替作者生产“缺口”。

<a id="critical"></a>

## 6. 怎样写有依据的评价

初学者常把 critical 理解为“找错误”。本教程采用一个工作要求：每项评价说清对象、依据、范围及对当前段落的影响。评价可以肯定已有工作，也可以说明它尚未覆盖的问题。[Wright 与 Michailova 的启发及边界](review-source-assessment.md#r02)

| 暂时不够的评价 | 继续核对什么 |
|---|---|
| “这些研究都很肤浅。” | 具体哪一项主张，原文提供了什么，依据为何不足？ |
| “没有研究过另一地区，所以结论错误。” | 作者原本声称适用于哪里？未研究该地区能支持多大范围的评价？ |
| “第二段语气强，所以更批判。” | 它使用了哪些材料，是否把条件不同的结果混在一起？ |
| “本文突破了旧理论。” | 原稿和资料是否确实给出这一专业判断及支持？没有就不用该表述。 |

作者自述的限制应注明其身份。证据适合所提出的问题时，不为了凑评价句制造缺陷。需要专业知识才能判断的环节，列为具体待核实问题，先继续完成有依据的表达。

Wright 与 Michailova 的框架来自特定管理学语境，有其批判性定义，不能用作全学科统一评分表，也不能据此禁止系统综述开展有依据的批判评价。其“九项特征”不直接变成本教程的九项强制动作。

## 7. 段落扩展成章节

先给每一节写一句功能说明，再检查顺序。可以按问题分组、按历史发展、按概念和应用分开，也可以围绕一个争论组织；选择取决于材料和读者。

例如短章可安排“评价对象与术语”“不同评价内容”“适用范围与本文任务”。这是练习提纲，不能预设真实材料一定有三部分。某节没有材料时，可以删去提纲中的空项或标为后续阅读任务；不能写出虚构正文。

[四份学位论文目录范例](review-source-assessment.md#r06) 用于理解章节功能的差异。其中有论文把文献综述与理论框架分章；这只提供一个可参考的安排。数学、人文、质性研究等仍按实际论证材料组织，不强套实验论文的章节。

<a id="audit"></a>

## 8. 交稿前做一次短检查

- 每条主要内容能定位到已读来源；引文身份、版本和阅读范围准确。
- 小标题确实对应本节材料；分类理由可说明，跨组材料没有被硬塞。
- “多数”“一致”“从未”“首次”等词有相应资料范围支持。
- 结论与原文提供的对象、指标、时段一致；未把差异自动解释为矛盾。
- 实际如何找到与筛选文献写清楚。没有做过的双人筛选、注册、质量评价及流程数字，不写成已完成。
- 来源选择有哪些边界，例如只用某语种、某数据库或某类刊物；说明其对本稿范围的影响，不声称已消除所有偏差。

需要系统综述报告规范时另查当前适用文件。PRISMA 2020 提供报告要求，不能代替研究实施或方法质量评价；引用追踪可以用于系统综述，PRISMA-S 第 5 项要求说明做法。不要沿用“系统综述禁止顺着参考文献找文章”的概括。[核验来源](review-source-assessment.md#standards)

## 9. 助手本轮交付

有足够材料就给：一段可用文字或已授权的章节修订，关键引用位置，少量修改理由，以及真正影响下一步的问题。若只有题名或摘要，给限定范围的阅读计划和提纲，不写成完整综述。

作者希望练习时，选“给段落命名”“比较两项指标”或“指出一句话的支持范围”之一。可以直接看答案，无需通过考试。较长任务可按 [导师流程](mentor-workflow.md) 保存作者要求的续接信息。当前稿件资料不自动进入共享包。
