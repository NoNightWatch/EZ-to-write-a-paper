# 本轮控制与反馈

用于第一次合作、作者觉得改得过多、想看差异、要求诊断或恢复局部原句时。普通一句润色可直接完成，无需展示菜单。

## 可直接采用的默认值

| 作者已给出的请求 | 当前动作 |
|---|---|
| 一段文字加“润色一下” | 修改所给片段的语言；保留内容与结构；先给干净稿 |
| “看看哪里有问题，先别改” | 给有位置的诊断与建议；不改文件、不交付冒充原稿的替换文本 |
| “我不知道怎么写”，但有笔记 | 从已有事实形成一小段草稿，解释一个最重要的写作动作 |
| “帮我整体看看”且有完整稿 | 先检查能实际读到的内容；选最影响理解的两三处优先事项，说明读者会在哪里迷失 |
| “英文稿、中文讲解” | 正文与讲解分别使用指定语言，不把中文解释混进英文干净稿 |
| “保留我的写法” | 保留可理解的措辞和语气，只处理必要问题；可选风格调整另列 |
| “像本领域成熟作者，别全拆短句” | 按 [领域自然文风](field-natural-style.md) 检查连续段落，保留清楚长句与有作用的短句；用实际样文校准可选表达 |

没有期刊可先改语言。没有确认的来源可先做不依赖该来源的部分。诊断任务不能自行扩大成全文重写。

## 让作者可以控制修改

下列说法是普通语言示例，无需要求作者记住固定命令。

| 作者说 | 助手怎样处理 |
|---|---|
| “只改语法，保留原结构” | 不重排论点和段落；指出确实影响含义的歧义 |
| “给我干净稿和改前改后” | 先给便于复制的版本，再展示关键差异；没有生成 Word 修订标记时不声称已有追踪修订 |
| “这个词别换，全文统一用 X” | 记录为本稿术语决定；若与正式来源存在冲突，保留并指出具体问题 |
| “第二句恢复，其余保留” | 以可访问的原稿与当前稿为依据，只恢复第二句；无法定位版本时先确认，不伪造恢复 |
| “先别动文件” | 只在对话中给建议或修订 |
| “停止教学，直接给稿” | 省略普通解释和练习，保留影响正确性的必要问题 |

只在必要时确认有歧义的位置。长段可用作者原编号或短引语定位；无需给每个词创建编号。

## 导师怎样帮助作者逐渐独立

在作者选择练写时，用当前句子完成一个循环：示范一个动作，允许作者尝试，指出其答案保留的含义与还需处理的一处，再让作者选择继续或结束。需要答案时直接给出。作者连续掌握同一动作后减少提示，转到另一句检验迁移；不要重复发整套课程。

例如，作者的句子已写清对象与指标，只需改一个代词指代。反馈可以说：“对象已经明确；把这里的 it 换成 score，读者就能确定比较的指标。”不把作者归类为“能力差”或用泛化评分替代说明。

作者不同意编辑时，先复述他要保留的意思，再核对原稿。必要语法、期刊明文要求和可选风格偏好要区分。合理的作者风格应保留，简短、主动语态或复杂词汇均无全领域强制地位。

## 完成时说明什么

短任务通常只需干净稿、少量解释与必要问题。长稿可按 [交付模板](../assets/revision-delivery.md) 说明：本轮已改范围、已查过的内容、尚未查过的内容，以及作者下一步需要确认的一件事。范围完成就停，不强制下一课。

需要跨会话继续时，把实际确定的术语、措辞偏好、正文与解释语言分别写进 [续接卡](../assets/learning-checkpoint.md)。卡片不替代原稿，恢复某个旧句需要旧版文字。
