# 第一篇论文：学生练习册

[English workbook](paper-workbook.en.md) · [课程入口](first-paper-course.md) · [材料包](paper-case-materials.md)

全部练习使用虚构教学材料。可用中文、要点或英文回答。建议先作答，再打开文末答案链接；希望先看示范也可以。没有固定句型答案。以下字数只帮助控制练习大小，不是期刊规定。

<a id="E01"></a>
## E01 · 先分清有与没有

读 P01/P02。写四行：研究对象、文档数与配对数、能直接记录的两项内容、没有测量的两项内容。

再判断：“新版更好理解”“later 编号数可以逐条数出”“有 Contact 就能获得帮助”各需要什么材料。判断完写出你据以判断的 P 编号。

卡住时提示：在 P01 找 `twelve documents` 和未测事项。文档、配对、读者是不同计数对象。

完成标志：读者知道手上有什么，也知道哪些结论需要额外证据。

<a id="E02"></a>
## E02 · 写一个能回答的问题

把“怎样提高学习中心效率”改成现有材料能够回答的一个问题。随后给引言、方法、结果、讨论各写一句用途说明。先解释用途，无需写四章正文。

提示：问题里放进对象、两个版本和实际记录指标。不要添加读者效果。

完成标志：问题中的每个主要名词都能回到 P01/P02；四节任务能对上该问题。

<a id="E03"></a>
## E03 · 让别人能够复查方法

用 C01-B 示范计数，解释第 2 项为何只算一项。然后写一个约 100 至 160 英文词的方法段，或对应中文段落，包括材料选择、单位、两项定义和总结方式。不要添加从未执行的编码或检验步骤。

提示：先用日常语言说“我拿到什么，怎样数，怎样汇总”，再转为论文用语。

完成标志：另一位读者能依你的规则数出同样的 C01-B 结果。

| C01 | | | | | |
| C02 | | | | | |
| C03 | | | | | |
| C04 | | | | | |
| C05 | | | | | |
| C06 | | | | | |

计算两版总数、每卡均值、以 earlier 为分母的相对变化。写 3 至 5 句结果，包括一个逐对特征和 Contact 计数。再检查下面句子哪里超出材料，并改写：

> The new cards significantly reduced tasks and improved support by 50%.

提示：先区分编号条目与实际动作，再检查 `significantly` 的依据。不要把百分点差当相对百分比。

完成标志：数值可复算，比较方向和单位明确，正文没有未测量的表现主张。

<a id="E05"></a>
## E05 · 给结果写一个合适的开头

读 L1/L2 全文。各写一句“它支持什么、没有说明什么”，随后写 2 至 3 段短引言，约 150 至 220 英文词或对应中文长度。至少包含两张卡的关系、本文问题与范围。

删除或改写无依据的 `Many studies prove...`、`Nobody has studied...`。每处引用紧跟它支持的内容。不要给教学卡编造期刊、年份或 DOI。

提示：先说明可以观察哪些文档特征，再说明本文比较什么。相关背景应帮助读者理解当前问题。

完成标志：引言最后提出的问题，能由你已写的结果回答。

<a id="E06"></a>
## E06 · 从结果到讨论与结论

读 P04，比较 C01/C06 的两版原句。写讨论的三个短段：回答问题；解释原文能支持的分组变化；说明哪些读者或服务结论仍无法得出。再写 1 至 2 句结论。

将每个解释标为：计数结果、材料支持的解释、尚缺证据。标记放在工作稿边注，定稿可移去。

提示：`fewer numbered items` 能直接支持；`fewer actions required` 需要另行核对，单靠编号数不够。

完成标志：讨论有内容上的推进，每项解释有材料位置，结论没有扩展到更大的总体。

<a id="E07"></a>
## E07 · 标题与摘要

为已写内容拟一个准确标题和 3 至 5 个关键词，再写约 120 至 180 英文词的摘要，或对应中文摘要。包含问题、材料方法、关键结果、结论范围。把每个数字连回结果表。摘要中保留虚构教学说明。

提示：先把各节最必要的一句取出来，再组织成连贯段落。避免把全文开头原样充当摘要。

完成标志：只读摘要也能知道对象、方法、主要结果和边界；没有正文从未出现的新主张。

<a id="E08"></a>
## E08 · 合成一篇完整练习稿

将之前各节放在一起：标题、摘要、关键词、引言、方法、结果及表注、讨论、结论、参考资料。保留练习的虚构说明。检查六对/十二文档、计数单位、总数/均值、Contact、L1/L2 的引用、各节结论范围。

请助手提出两处最值得修的地方。先自己修一轮，再比较修前修后。若检查未发现实质问题，可以完成，不必强行改写。

最后写一条版本说明：“本版改了什么、还有什么没核查”。你可以查看完整范文，但要分清照着修改与自己判断。

完成标志：交付连贯整稿、可回查的材料对应，以及尚未完成的核对事项。完整教学稿仍不可用作真实投稿。

<a id="T01"></a>
## T01 · 换材料独立写

以下为另一组虚构数据，涉及四对活动通知，共八份文档。你拿到的是已经完成的计数记录，**没有通知原文**。P02 的计数定义适用于这张表；没有读者或活动效果数据。只能描述记录并注明无法复核原文，不能声称亲自重数了文本。两版只表示顺序。没有抽样、推断检验或编码信度记录。

| Notice | Earlier items | Later items | Earlier contact | Later contact |
|---|---|---|---|---|
| N01 | 2 | 3 | 1 | 1 |
| N02 | 4 | 4 | 1 | 0 |
| N03 | 3 | 2 | 0 | 0 |
| N04 | 5 | 3 | 1 | 1 |

不翻看案例范文，完成：

1. 写研究问题与两句材料方法，明确实际访问了什么。
2. 计算总数、均值及逐对变化；写结果段，同时报告 Contact。
3. 写一段与数据对应的讨论，以及四句短摘要。
4. 写一句解释：哪项结论与原案例不同？哪项解释因缺少原文而无法确认？

先提交无提示版本，然后可请求提示或参考答案。助手记录实际帮助，不因看过答案而宣称你已能独立完成。

### 可选：换到其他文章体裁

仅为组织表达练习，不要求创造专业理论。

- 历史文本：两份虚构前言记录。1910 年版写“供工坊学徒使用”；1920 年版写“供课堂讲授使用”。写一个比较句和一个边界句。没有学生使用记录或作者动机材料。
- 数学：已给出的命题只适用于“有限图，最大度不超过 4”，没有提供证明。写一句准确的结果概述，再列出组织证明章节还需拿到的材料。不要扩大条件或补造证明。
- 综述：只用 L1/L2 做一个限定范围的综合段。没有数据库检索记录，不能称为系统综述。
