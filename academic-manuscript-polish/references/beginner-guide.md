# 新手入口：从你已经有的内容开始

有完整稿件、一段中文、提纲或零散笔记，都可以开始。你无需先懂写作流派、期刊术语或英语语法名称。助手先处理你已经提供的内容，缺少研究事实时会请你确认。

## 第一次怎么说

一想到论文就不知道怎样开头，可以先用[先说清一件事](one-clear-thing.md)。说出材料里的一件事，或你想了解的一个问题，暂时不用填表、写英文或考虑整篇。助手会和你整理出一句话，愿意继续时再展开。

想从零学写整篇：使用[完整论文课程](first-paper-course.md)。它提供虚构原始材料、同一案例的连续带写、完整英文范文、中英练习册、逐步反馈与换材料练习。没有自己的研究数据也能先学。只改眼前一段，可继续用下面的短请求。

可直接复制：

> 我是学术写作初学者，下面是我已有的稿件或笔记。请先帮我完成［这一句／这一段／这个章节］，保持事实和原意，用普通中文解释重要修改。目标期刊是［刊名或未定］。不确定的专业内容请问我。

只有一句话也可以发。没有任何文字时，先说研究什么、手上有什么材料、想写哪部分；助手可以帮你整理提纲，但不能替你创造结果和参考文献。

仅改普通句子的语法时，助手可以直接修改，无需先查完整学科词表。遇到会影响含义的专业词，再查相应来源。想写综述也可只拿一两份材料开始，先做准确概括或限定问题的比较。

## 你可以选怎样进行

- **直接修订**：“先给我修改稿，暂时不用讲课。”
- **修订加讲解**：“先给修改稿，再挑一两处解释。”这是新手未另行指定时的默认方式。
- **一起练写**：“先教我写这一段，让我试一下，再帮我改。”

随时可以换方式。练习自愿，也可以直接看答案。要求改全文时，助手应完成约定范围；讲解可以只选重点，不要求你逐段答题。

## 先看懂几个任务词

| 词 | 这里的意思 |
|---|---|
| 稿件 manuscript | 你准备投稿或提交的文章文字；草稿也算 |
| 提纲 outline | 各部分准备写什么的安排，内容可以还不完整 |
| 摘要 abstract | 用短篇幅说明文章做了什么及主要内容；不是全文的开场白 |
| 引言 introduction | 交代与本文有关的背景、具体问题和本文任务 |
| 结果 results | 呈现已有观察、计算或分析所得内容，章节形式依学科而异 |
| 讨论 discussion | 组织作者对已有内容的解释、联系和适用范围 |
| 术语 term | 某个学科中具有特定含义的词，常需要保持译名一致 |
| 修订 revision | 根据需要调整稿件；可以只改语言，也可以经同意改结构 |

不需要记住整张表。遇到不懂的词，直接问它在你这句话中的意思。

## 你需要给什么

| 材料 | 用来做什么 | 暂时没有时 |
|---|---|---|
| 稿件文字、提纲或中文笔记 | 修改实际表达或整理已有材料 | 先给一句研究说明和手上已有的材料 |
| 目标期刊、文章类型 | 核对读者、版式和提交要求 | 先做通用润色 |
| 本轮希望改的部分 | 控制改动范围 | 默认语言修改 |
| 图表、公式、引文 | 保持数值和含义一致 | 对相关句子标明核对缺口 |
| 可选范文或术语标准 | 处理特殊领域与体裁 | 用基础词表定位，疑点请作者确认 |

若未发表内容敏感，可只提供必要片段并去掉身份信息。不要把无法分享的数据放入公开检索。

## 三种编辑幅度

1. 语言修改：改语法、拼写、指代、重复词和不自然表达，尽量保留原顺序。
2. 段落修改：说明一段想做什么，再调整句子顺序和衔接。未写清的事实会留下问题。
3. 章节修改：重排小节，让引言任务与正文顺序对应。先说明哪些段落要移动，保留原稿。

“专业化”不要求多用长词。选择读者能理解、含义准确的表达。不要为了变化把同一个专业术语换成多个近义词。

## 从这里到一篇可核对的稿件

按你的当前阶段进入，已经完成的部分直接跳过。

| 当前阶段 | 可以先做什么 | 这一小步完成时能看到什么 |
|---|---|---|
| 只有笔记 | 确认已有事实和你想表达的内容 | 一个保留事实的句子或提纲 |
| 有句子但不连贯 | 说明每段的任务，调整已授权的顺序 | 能说清本段在做什么的段落 |
| 有部分章节 | 对照实际材料补清表达，列出缺项 | 当前章节修订稿和具体问题 |
| 有完整初稿 | 对照标题、摘要、正文和术语 | 已约定范围的修订及差异说明 |
| 准备投稿或修回 | 按目标期刊核对当前要求 | 已核验与待核验事项分开的清单 |

这张表说明写作进度，不表示研究正确性已经被核实，也不保证论文录用。

## 一轮教学输出是什么样

下面为虚构语言示例，数字只用于演示。

原句：The test was done and it was higher in group B.

已知材料：作者给出的指标为平均得分，A 组 12 分，B 组 15 分。

修订：The mean score was 15 points in group B and 12 points in group A.

解释：原句中的 it 没有明确对象。修订后直接说得分，并保留组别和单位。句子没有新增原因解释。

仍需作者确认：若原稿还有误差范围、样本量或量表名称，应按所在章节和期刊要求补回；助手不能自行估计。

如果只想改这一句，收到修订后就可以结束。想继续学时可以找自己稿中的另一个 it，检查指代是否清楚；不必删除所有代词。若只希望看示范，直接请助手给答案即可。

## 怎样使用术语表

你可以让助手根据稿件查 [学科目录](discipline-map.md)，也可以自行搜索英文或中文。每条只有定位用的短释义；需要解释时，先问“普通话里怎么理解，在我这句中指什么”。看懂以后再考虑是否练写。遇到正式定义请提供来源，不把入门词条当成可直接引用的文献。

例如，心理学的 validity 通常译为效度，逻辑学的 validity 可译为有效性。同一个英文并不自动共享一个中文译法。

## 卡住了怎么说

| 遇到的情况 | 可以直接发给助手的话 |
|---|---|
| 不知道先改哪儿 | “请先找一个最影响理解的问题，并给我一处示范。” |
| 解释仍看不懂 | “只用我这句话解释这个词，暂时别展开其他概念。” |
| 只有中文想法 | “先按我的中文整理，确认含义后再写英文。” |
| 不知道专业词是否正确 | “先保留原词。我提供定义来源后，你再核对。” |
| 文献读了几篇却写不成一段 | “请按一个具体问题整理这些材料，先示范一段，并标明每句话的来源。” |
| 某个改动改变了我的意思 | “我原本想说的是……，请按这个意思重改。” |
| 太多问题看不过来 | “先问一个最影响当前段落的问题。” |
| 想停一会儿 | “给我一张续接卡，不用保存文件。” |

## 最后你要做的事

阅读干净修订稿，对照修改说明，核对专业内容、数字和引用。未确认的作者问题不要当成已完成事项；尚未核验的期刊规则保留其状态，按当前指南继续核对。
