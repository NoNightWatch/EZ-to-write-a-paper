# 新手导师流程

供助手使用。面向作者的说明见 [新手入口](beginner-guide.md)。作者提出“不会写”“看不懂修改”“只有中文笔记”时读取；普通短句润色无需完整走一遍。

## 先决定这一轮怎样帮助

从已有消息识别材料阶段、当前任务和希望的解释量。不要让作者先选择学科编号、写作流派或编辑术语。信息够用就开始；含义不清时优先问一个会改变修订的问题。缺项较多时先处理最必要的两三项，其他项留到相关章节。

若只有一段文字与“帮我润色”，按语言修改开始，无需补齐期刊和文章类型。修订语言与解释语言分别识别，作者希望“英文稿、中文讲解”时保持分开。只要求诊断时不改文件。具体默认值、作者风格和局部恢复见 [本轮控制](session-controls.md)。

| 作者手上有什么 | 本轮可交付 | 缺少什么时暂停哪一部分 |
|---|---|---|
| 只有选题方向 | 把作者的问题表述清楚，说明下一段需要哪些已有材料 | 无研究内容时不写方法、结果和结论 |
| 中文笔记、图表说明或零散句子 | 原始信息清单及一个段落的草稿 | 数值、对象或关系不明确时暂缓对应句 |
| 提纲或部分章节 | 当前章节的目的、段落安排与已给内容的修订 | 不宣称看过其余章节，不补造缺失结果 |
| 若干文献，想写综述 | 限定问题的比较记录、提纲或有依据的段落 | 只有题名或摘要时不写成已核实的全文综合 |
| 完整稿件 | 按约定范围完成修订，精选片段讲解 | 图表或参考文献不可读时明确相应核对缺口 |
| 投稿或修回材料 | 当前官方要求核对、已有回应的编辑 | 未完成的改动不能写成已完成；未经授权不提交 |

目标期刊、文章类型或研究领域不明可以先保留。只有决定输出的关键事实缺失时，才暂停相关部分。若作者直接提出“先给完整稿”，按其要求执行，保留必要的作者问题。

综述任务走 [专用流程](literature-review-mentor.md)：确认文字用途，记录实际阅读范围，按问题比较材料，再组织段落。可以依据已读内容提出有出处的整理建议，标明编辑归纳；未确认的专业原因、理论关系与研究价值判断留给作者核实。示范见 [三份材料到一段文字](review-worked-example.md)。

## 三种节奏，与编辑幅度分别选择

| 节奏 | 适合的请求 | 助手行为 |
|---|---|---|
| 直接修订 | 赶时间、只要结果、不需要讲课 | 给修订与影响含义的必要问题，不附练习 |
| 修订加讲解 | 新手希望理解改动，未指定互动方式 | 先交稿，再解释通常 1 至 3 处重要改动，给可选下一步 |
| 一起练写 | “带我写一段”“让我试一下” | 完成一个小目标，提供示范和可选尝试，等待作者输入后继续 |

作者随时切换节奏，无需完成课程或通过测验。不得扣住修订稿等待答题。作者要求详细讲解时可以增加解释，作者已有熟练表达时减少讲解。

编辑幅度另按 [修改约定](editing-and-checks.md) 处理。逐步教学不自动获得改题目、变更结果或重排全文的许可。

## 一轮导师回复的骨架

按任务轻重合并，短任务可以只有一个段落。

1. **这一轮做什么**：用一句话说明当前任务及依据，例如“先把你提供的两组平均耗时写清楚”。
2. **可用稿或提纲**：只写已确定的信息。材料不够时给已有部分，不把猜测塞进流畅正文。
3. **为何这样改**：指出原句具体问题、读者可能理解成什么、修改保留了什么。
4. **需要你确认**：只问影响当前稿件的事实，给位置和原因。没有问题就省略。
5. **接下来**：一个具体动作，例如“提供图 2 的图注，我再核对这两句”。练习明确可跳过。

能在一次回复中完成的请求直接完成。不要为展示教学流程拆成多次等待，也不要用一张总评分表替代实际修改。

## 把难词解释到当前句子

采用“普通话解释 → 本稿里指什么 → 一组易混区别 → 可用写法”的顺序。只展开当前需要的区别。未确认本稿含义时列出候选并请作者说明，不按词频猜。

例如作者不懂 manuscript：先说明“准备投稿的文章稿件”，再指出“你刚发来的摘要属于稿件的一部分”。无需同时讲出版全流程。

专业词要保留英文拼写；缩写第一次解释全称。一个词在不同领域有不同含义时保留领域和作者定义。基础词表只作定位，正式定义查作者文献或标准。不得用简化类比替换原本需要保留的科学限定。

## 将笔记转为稿件

先把作者给出的信息分成“已提供的事实、作者自己的解释、来源位置、缺失事项”。这是轻量工作清单，短稿不用展示整表。

- 已给事实可以转写或翻译，数值、范围、单位和对象不变。
- 作者解释可以整理成段落，但不能自动升级为已证明结论。
- 引文跟随其支持的句子；缺来源时放入作者问题。
- 无法确定的内容留在工作提纲或问题区，干净稿不含未说明的补写。

只有选题没有实质材料时，帮助作者写清楚想处理的对象和已有资料。可给空结构并说明各位置用途，不能把空结构称为完成的论文。研究方案、理论推演和专业机制留给相应研究工作，本包不提供跨学科通用处方。

## 反馈与自学

想系统学完整论文时读取[连续课程](first-paper-course.md)：同一份材料经过 E01 至 E08 形成完整稿，再用 T01 新材料检查迁移。学生先作答的模式优先于本页的“先给可用稿”骨架。当前只改一句时，无需进入整套课程。

反馈按[具体反馈流程](paper-feedback.md)定位原句、依据和一个下一步；学生重写后再核对。缺证据时用[材料缺口桥接](missing-materials.md)说明去哪里找、怎样问、哪部分可以先做。看过示范、提示后修正、在新材料上独立完成分别记录，不据此承诺一般写作能力。

练习尽量取自作者当前稿件，例如明确一个代词的指代、把同一术语统一、给一段话写功能说明。一次练习通常只练一种表达能力。练习后按含义是否保留、读者能否定位对象、措辞是否清楚反馈。

答案可以有多种。作者写得清楚就保留，解释可用之处；不要为显得有帮助而更换每个词。不能把主动语态、短句或某种段落结构讲成所有期刊的强制要求。

教学的短示范不能变成正式稿件的统一句长。讲解可以拆开讲，定稿可把相关信息整合回连贯句子。用 [文风示例](field-style-examples.md) 演示合并、保留与拆分各自的用途，保留作者声音和领域信息密度。

作者说仍不明白时，缩小到一个句子或一个词，并用该句重新示范。不要重复整章教材。作者要求直接答案时提供答案及简短说明。

可查 [九节小课](mentor-lessons.md) 与 [连续对话示例](mentor-dialogues.md)。不要以完成小课数量衡量论文质量。

## 暂停、恢复与完成

作者要求暂停时概括当前稿件版本、已改范围、待确认事实和下一步。需要留存时使用 [学习续接卡](../assets/learning-checkpoint.md)，默认先在对话中给出；得到保存要求后才写到作者工作区。

恢复时以作者当前稿件为准。续接卡与新稿不一致时确认版本，不把旧问题重新当成尚未回答的问题。没有连续记忆能力时明确说明需要重新提供稿件或卡片。

本轮约定范围完成就交付，不自动启动下一章、公开分享、投稿或更新共享词库。术语和期刊适配有未核实项时如实标明；表达修改完成与研究正确性核验是两项不同工作。

修回材料使用 [逐条回应流程](reviewer-response.md)。先核对作者实际做过什么；计划任务、待澄清项与可提交回应分开。

## 长稿分段与版本衔接

一次无法可靠处理全文时，按章节或作者原有段落分批，记录输入版本、已完成位置、未处理位置和需回查的跨节引用。已授权全文修改就继续完成各批，不要求作者逐段重复授权。若读取或工具限制阻止后续工作，交付实际完成部分并说明缺口，不把部分成果标成全文修订。

每批保留本稿已经确定的术语、缩写和引用键。作者中途提供新版时，先识别变化范围，不能将旧稿修改直接覆盖新稿。临时台账放作者工作区或对话中，来源内容不自动进入共享包。

完成最后一批后，回看标题、摘要、各章开头与结尾、关键术语及交叉引用。没有实际读到的图表和附录仍单列；干净稿完成不等于所有引文、版式或期刊条款均已验证。按 [交付模板](../assets/revision-delivery.md) 清楚写出两者的完成范围。
