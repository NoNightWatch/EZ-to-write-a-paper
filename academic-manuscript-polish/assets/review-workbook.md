# 文献综述工作表

可选模板。只复制当前用得上的部分到作者工作区；无需填满，也不自动保存。用法见 [综述导师](../references/literature-review-mentor.md)。缺项只留在工作记录，完成稿不得隐藏未核实信息。

## B. 来源身份卡

为每份来源复制一张；篇数少时在对话中记一行即可。

- 来源编号：L01。
- 原题名、作者、年份、期刊或版本：
- 已确认标识或链接（没有就省略）：
- 实际读过的位置：PDF 页码、印刷页码及章节分别记录。
- 书目身份核对与内容核对分别记录：确认的是哪份材料，以及哪条主张受到已读段落支持。
- 角色：原始研究 / 综述 / 规范 / 评论 / 教学材料。
- 版本或共享研究关系：是否与其他来源为同一研究、同一数据或不同版本；无法确定时明确记录。

|---|---|---|---|---|
| L01，具体章节或页码 | | | | |

按任务增减列。必要时增加对象、术语定义、材料类型、指标或时间窗；不要把不适用的实验字段塞给历史或哲学文献。短引文加引号；自己的概括不伪装成原话。

史料可加版本、时期及材料体裁；概念论述可加作者定义与所读论证范围；数学可加命题条件及结论编号；计算机或工程记录可加基准、软件版本及评价划分。只取当前任务需要的字段。[跨学科示范](../references/review-transfer-cases.md)

|---|---|---|---|---|
| | | | | |

只填写实际发生的操作。引用追踪还记录起始文献与方向；从参考文献找被引文章和查谁引用它，要能区分。完整检索式保留执行时原样，不用事后生成的示范检索式替代记录。

筛选数量保留计数口径：检索记录、去重后记录、报告文件与独立研究可能是不同数量。筛选理由、实际参与者、流程变更与自动工具的使用如实记录，无法还原的数字不得估计后装入流程图。[报告规范说明](../references/review-source-assessment.md#standards)

## F. 交付前自查

- 引用支持相邻句子，重要主张的来源与版本可定位。
- 分类与范围已说明，未凭几篇材料声称领域共识。
- 提纲、试写、修订稿的完成状态准确。
- 专业判断缺口已列出，未用流畅文字掩盖。
- 未复制第三方全文，未把作者材料写入共享 skill。
