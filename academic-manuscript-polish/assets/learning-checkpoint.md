# 学习续接卡

可选。作者要求暂停、跨会话继续或保存进度时使用。默认在对话中提供；只有作者要求保存时才写入其工作区，不收进共享 skill。

- 当前稿件版本或本轮片段：
- 研究领域和文章类型（仅记录已经知道的）：
- 目标期刊及核验状态：
- 本轮任务与允许的修改幅度：
- 正文语言、讲解语言与需保留的表达偏好：
- 文风校准涉及的样文与已读范围、已确认的句段偏好（仅需要时）：
- 已完成的具体位置：
- 尚未处理的具体位置，及无法读取的文件或章节：
- 源文献阅读范围、当前引用键或文献管理字段状态（涉及引用时）：
- 当前有效的作者决定或术语译名：
- 未解决的问题及对应位置：
- 修回任务涉及的意见编号、实际动作与完成状态（仅需要时）：
- 下一步最小动作：
- 希望继续的节奏：直接修订／修订加讲解／一起练写

只记录续接所需的信息，不保存学习者评价、能力标签、成绩、账号或未授权的全文。已解决的问题可以注明已解决，避免重复询问。续接卡不能代替原稿与修订稿，也不保证助手会自动记住这些内容。作者提供新版后先识别变化范围，不将旧批次直接覆盖到新版本。
