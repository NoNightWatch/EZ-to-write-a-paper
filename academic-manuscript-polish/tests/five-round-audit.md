# 五轮自审与修补记录

版本：3.2.0；日期：2026-10-18。五轮自审与修补已完成，更新范围为库外指南包，原知识库、原 PDF 与旧版 ZIP 保持不变。每轮记录发现、修补和实际验证；文字走查不等于独立模型行为测试。

## 第 1 轮：新手可用性

- 发现：入口虽强调按需加载，编号第 1、2 项仍要求先读领域路由和词表；普通语法任务可能被带入不必要的完整流程。综述页缺少可以立即开始的一段式入口，六个基础任务词未集中解释。
- 修补：路由改为按需分支，语法任务可直接处理；教材示例按需读取。综述页增加小任务入口与六个普通释义，允许单篇准确概括，不强制填写工作表。
- 走查：仅改普通句子、只给一篇材料、给两篇材料但不懂“综合”三种输入分别有可开始的动作，均不需要期刊或完整稿件。
- 验证：包结构检查通过，错误数 0；111 个文件，106 个 Markdown 文件。

## 第 2 轮：来源与引用支持

- 发现：旧流程同时要求核对来源和引用，却未清楚分开“书目身份已核实”与“这句话已获支持”；模板也缺少复合主张的逐项对应位置。
- 回查：重新读取 Snyder 的 PDF 第 3、5 页相关文字，Wright 与 Michailova 第 16 页的结论与注释，以及 Keshav 第 1 页。上轮保留的方法边界和 Keshav 身份信息与这些原文一致；未扩大两份长文的全文阅读声明。
- 修补：补充四种阅读状态及允许使用范围、复合主张的引用归属、自译与直引区分、书目块错配及出版状态的按需检查；工作表加入可选逐句定位。
- 走查：只有 DOI、只读摘要、综述转引、两份资料各支持半句四种情形均有明确动作。不能把搜索命中或链接可打开报告为内容核实。
- 验证：包结构检查通过，错误数 0；111 个文件，106 个 Markdown 文件。

## 第 3 轮：流程衔接与交付状态

- 发现：长稿只讲了暂停恢复，缺少跨批位置记录与末尾复核；交付表未把语言修改完成和引文核实区分开。期刊表只有三种状态，对实际不适用项目表达不足；引用管理字段的保留也未说明。
- 修补：加入长稿分批与输入版本记录、最后一批的跨节回查、引用键保留及动态字段检查边界。交付和续接模板记录未处理位置，期刊流程与模板统一增加有依据的不适用状态。
- 走查：已授权全文但分批处理、中途收到新版、无法读附录、只修改引文所在句而未检查文献管理器四种情形均能记录实际完成范围。已授权范围无需逐段再确认，资料不足只影响依赖该资料的部分。
- 验证：包结构检查通过，错误数 0；111 个文件，106 个 Markdown 文件。

## 第 4 轮：跨学科教学迁移

- 发现：综述模块主例围绕时间、错误数和偏好，虽提醒适配其他学科，未给非实验材料的完整改写。新手可能仍把所有资料塞入样本量与指标表。
- 拓展：新增历史、哲学、数学、计算机与工程四个虚构练习。分别练习材料体裁与范围、同词不同定义、命题条件、基准版本记录；每例给出输入、可用改写、理由和参考答案。
- 修补：主教程、原练习和工作表接入这些案例，并给出按需字段。没有新增专业理论、因果推演或实验设计教程。
- 走查：逐句对照虚构输入，保留日期、港口、定义、命题条件与版本号；未把来源未提供的内容补写为事实。情景 51–60 补入前三轮和本轮的关键边界。
- 验证：包结构检查通过，错误数 0；112 个文件，107 个 Markdown 文件。

## 第 5 轮：工具、边界与分发

- 复现：精确检索 `SOC` 命中 2 项，输入全角 `ＳＯＣ` 命中 0 项；`life-cycle assessment` 命中 1 项，换成不换行连字符命中 0 项。设置子进程输出编码为 ASCII 后，中文 JSON 输出失败，退出码为 2。
- 修补：只归一常见输入变体，使用 NFC 保留上下标与数学减号，避免把科学记号并成不同词头；命令行输出统一 UTF-8。原词表内容未改变，结果仍保留原有拼写与多义条目。
- 拓展：新增 12 项确定性回归测试，包括字符变体、科学符号区分、词头优先、字面搜索、截断数量、编码、空白输入、缺失目录、稳定排序及不修改输入记录。未新增网络查询或外部服务。
- 验证：38 项自动测试通过，包结构检查错误数 0；随后再次执行入口检查、全包检查和最终打包逐文件核对。具体结果见 [分发检查](release-checks.md)。
