# v3.3 使用体验检查

日期：2026-10-18。范围：首次进入、修改控制、修回任务、查词输出和分发资料。本轮采用维护者走查与确定性脚本检查，未招募真实用户，也未开展独立模型行为试验。

## 发现与处理

| 使用障碍 | 本轮处理 | 可检查的结果 |
|---|---|---|
| 安装前缺少现成的试用材料 | 加入原创虚构试用稿和参考输出 | 可用同一材料检查数值、范围和局部恢复 |
| 正文语言与解释语言混在一个设置中 | 分开设定；未指定时分别沿用原稿与对话语言 | 英文稿可以配中文说明 |
| 修改范围与反馈控制分散 | 新增本轮控制页，接入执行入口 | 诊断、轻改、保留措辞、比较和恢复各有处理方式 |
| ZIP 中缺少英文启动入口 | 内置中英启动页 | 解压即可阅读英文启动说明及相对链接 |
| 修回只有零散提示 | 新增逐条回应流程和工作表 | 完成、计划、澄清与作者不采纳决定分开 |
| 查词只输出 JSON | 增加可读文本格式，保留 JSON 默认 | 两种格式使用同一结果与计数 |
| 首页先展示大量目录，试用靠后 | 公开首页提前放试用与直接下载入口 | 中英首页内容对应，完整教程仍可继续阅读 |

## 维护者情景走查

以下核对输入与已写指令及示例是否一致。表中的结果属于维护者检查，不能称为模型实际执行成绩。

| 输入情景 | 检查的要求 | 走查结果 |
|---|---|---|
| 18 人访谈、12 人称反馈迟到 | 保留人数与陈述归属，不添成绩影响 | 虚构示例对应，参考输出满足这些条件 |
| 中文请求修改英文段落 | 正文与解释语言分开 | 启动页、入口和导师流程已一致 |
| “只点评，别改文件” | 不把诊断扩大为写入 | 控制页与入口明确此边界 |
| “第一句恢复，第二句保留” | 依据可访问原稿局部恢复 | 示例给出恢复目标；原稿不可读时须确认 |
| 审稿人问访谈时间，作者计划补充 | 不提前使用已完成时态 | 修回流程将计划与正式回应分开 |
| 作者已给新增句，但未给行号 | 采用真实章节与段落定位 | 不编页码或行号 |
| 稿件覆盖未收录学科 | 用作者参考文献界定术语 | 沿用原补充文献流程，不按现有词表强行归类 |
| 作者只想拿稿，不想练习 | 省略练习与普通讲解 | 入口及控制页可直接切换 |

## 验证方法

运行 `python -B tests/test_bundle.py` 和 `python -B scripts/validate_bundle.py`。新增 8 项测试核对文本输出的记录、目录、限制数量、空结果、非法格式、JSON 兼容、UTF-8 与只读性；完整套件共 46 项。

检查 [中文启动页](../START-HERE.zh-CN.md)、[English start](../START-HERE.en.md)、[控制流程](../references/session-controls.md)、[修回流程](../references/reviewer-response.md) 从执行入口可达。原有 52 个学科、2,080 条基础记录、2,043 个英文词头和九册 308 条详细词条未扩大，未把新增体验页计作术语或课程数量。

本轮结果：46 项测试全部通过；119 个包内文件、3,467 个内部链接通过结构检查；四份公开首页与指南的 148 个本地链接通过路径与锚点检查。中英公开文档的章节、图片、导航锚点和代码块数量对应，正文也经过维护者核对。原有术语、详细词表与写作路径文件和 v3.2 的文件哈希一致。

已查看本地首页和指南的浅色、深色与 390 像素内容宽度预览，并实际点击指南的修回导航。修正了重排后遗留的图片替代文字编号。窄屏预览没有模拟真实手机或所有 GitHub 客户端。

发布包须再逐文件核对 ZIP 内容和解压后检查，并验证公开下载；最终文件哈希随 Release 提供。静态文件和工具检查不能证明所有专业定义正确、模型始终遵循流程或教学效果提升。

## 保留的限制

大部分教材仍为中文。未新增原生 Word 修订引擎、模型服务、自动安装器或自动投稿功能。未重新核验全部期刊规则和术语定义。医学条目仍限于安全的阅读与学术表达，不补全高风险操作。使用者的资料不进入共享包。

先前版本的 [五轮记录](five-round-audit.md) 和 [v3.2 检查](release-checks.md) 保留历史语境。
