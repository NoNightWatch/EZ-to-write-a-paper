# v3.7 一句话入口：自审记录

范围：[中文入口](../references/one-clear-thing.md)、[英文入口](../references/one-clear-thing.en.md)、[助手流程](../references/gentle-start-mentor.md)，及其与导师流程、完整课程、公开页面的衔接。检查日期：2026-10-18。

## 三轮内容检查与修补

| 轮次 | 发现 | 修补与检查 |
|---|---|---|
| 1 路由 | 旧入口先推荐完整课程；畏难表达可能与“只改这一段”并存 | 只在需要起步支持时使用短路径；明确改稿、示范或完整课程请求优先；仅新手身份不触发感受推断 |
| 2 反馈与事实 | 为展示已有成果可能过度肯定，或替不完整数字补上指标和单位 | 保留学生原话，区分已表达与已核验；缺含义先问一个关键问题；材料冲突先指出，只有选题时承认得到的是问题 |
| 3 负担与续接 | 新入口若展开所有教材，会重现原来的起步困难 | 双语短页只呈现当前动作，例子折叠；完成一句可停；课程留在可选出口，已有内容沿用；不主动保存感受或能力标签 |

这些是维护助手的内容自审和下述文字情景走查，未调用独立模型或真实学生，不构成教学效果证据。

末次复查修正了短例子的上下文歧义：“8 和 11 表示什么”只在没有表格等上下文时追问；已有均值和单位就沿用，避免新手重复回答。反馈示例也明确仅在学生原句确实包含比较方向时指出这一点。

## 具体情景的文字走查

以下学生输入和输出片段均为编写示例。它们用于人工检查指令之间是否冲突，不声称模型实际自动执行过这些对话。

| 输入情景 | 符合流程的本轮处理 | 排除的处理 |
|---|---|---|
| “一想到论文就不知道从哪开始。” | “你手上的材料里，有哪一件事是你已经知道的？”只给当前问题 | 先显示八阶段、四十期刊或学习量表 |
| “A 是 8，B 是 11。”无其他材料 | 先问数字表示什么，保留当前记录 | 自行加入均值、分钟或显著性 |
| 给定虚构表 1：A 平均 8 分钟、B 平均 11 分钟，学生准确复述 | 指出组别、指标和数字已交代，可保留原句；继续时补来源位置 | 把助手生成的整段记作学生独立完成 |
| 材料记录 A 为 8，学生写成 18 | 指明记录与句子的数值冲突，先确认正确值 | 为鼓励而称句子已准确 |
| “我只有选题，没有数据。” | 整理想了解的问题，或在学生想练时提供明确虚构例子 | 生成已经完成的结果 |
| “我的材料是两份历史前言。” | 从前言已有表述起步，保留出处与范围 | 要求必须交实验组和数值 |
| “我是新手。直接润色这句，别讲课。” | 直接修订指定句，不进入互动练习 | 因学生身份强制一句话课程 |
| “我很紧张，但今晚需要改完这一节。” | 完成已授权范围，解释简短、必要问题明确 | 以起步支持为由截断整节任务 |
| “先给完整路线和答案。” | 提供所求，保留资料虚构与真实的区别 | 要求先体验一个成功才准看答案 |
| “这句写完了，先停。” | 简述已有句子和必要未核实项后结束，不自动写文件 | 主动发下一组练习或成绩 |
| “继续课程，我刚才已经给过这份材料。” | 沿用已确认内容，按实际缺口进入相应步骤 | 要求重新填写所有信息 |
