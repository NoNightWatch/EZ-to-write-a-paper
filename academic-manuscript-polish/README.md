# PAPER QUEST · 学术写作指南

[从这里开始](START-HERE.zh-CN.md) · [Start in English](START-HERE.en.md) · [虚构试用稿](assets/first-session-demo.md)

一套面向学术写作初学者和已有稿件作者的写作指南。从稿件、中文笔记或提纲开始，根据实际材料识别领域，匹配术语和写作资料，再按目标期刊与作者要求修改。可以直接交付修订，也可以带作者逐步练写。

## 直接开始

把已有文字或材料交给能读取指南的助手，并发送：

> 请使用 academic-manuscript-polish。下面是我的稿件或笔记，目标期刊是［刊名或未定］。这次先处理［一句／一段／一个章节／全文］，保持事实和原意。我是初学者，请先给可用修改，再解释重要改动。专业定义不明确时问我，我可以提供参考文献。

期刊未定或文章类型不清楚也可以开始，先做通用修改。已有信息无需重复填写。让助手读取[执行指南](SKILL.md)并按需访问完整包内资料。已有安装的环境可沿用原调用方式。

只给一个段落也可以开始，默认语言修改。正文语言与解释语言分别指定，例如“英文修订，中文解释”。想先诊断、看差异、保留用语或恢复某句，直接说即可。[本轮控制](references/session-controls.md) 集中说明这些方式。

## 新手导师怎样工作

| 你希望怎样进行 | 可以直接说 | 助手会怎样处理 |
|---|---|---|
| 直接拿到修订稿 | “赶时间，先给我改稿。” | 完成约定范围，仅保留必要问题 |
| 了解修改理由 | “改完再解释一两处。” | 先交稿，再用普通话解释关键改动 |
| 一起练写 | “先带我写这一段。” | 围绕当前材料完成一个小目标，提供可选练习和参考答案 |

三种方式可随时切换。没有完整稿件可以用笔记开始；没有期刊可以先做通用修改。助手不会要求先背术语、选写作流派或填满任务卡。

讲解从当前句子出发，说明哪里不清楚、修改帮助了什么、保留了哪些含义。练习可以跳过，原句清楚时可以保留。选择教学方式不自动授权改变研究内容或重排全文。只有选题没有实质材料时，交付限于问题表述、材料清单或工作提纲。

需要暂停时可在对话中生成续接卡；未经要求不保存文件，不承诺跨会话自动记忆。

## 文献综述怎样开始

> 这些是我已经读过的文献和笔记，我要写［引言的一段／学位论文的一章／独立综述］。请先帮我明确一个整理问题，记录实际可读范围，比较这些材料，再给一段有来源的示范。暂时不清楚的专业关系请列出来，不替我编造。

新增流程覆盖任务选择、阅读、比较表、段落、章节和交稿核对。几段背景介绍无需先做完整系统综述；独立综述需要按实际方法选择名称与报告要求。评价围绕依据和范围，不能凭负面语气或文献篇数判断质量。

[教材评估](references/review-source-assessment.md) 说明九份材料各自的价值、实际阅读范围和未采用内容。七份读完正文或短讲义，两份重点读取。幽默社论未纳入操作主线；两份匿名讲义只作教学任务参考。新示例为虚构材料，不可当成真实研究引用。本包未附第三方 PDF，也未修改原知识库页面。

## 放在哪里

把完整文件夹放到助手可读的工作目录，请它读取[执行指南](SKILL.md)，再按需打开相对链接。无需先修改配置。需要宿主自动加载时，可参考[在线配置说明](https://github.com/NoNightWatch/EZ-to-write-a-paper/blob/main/docs/guide.zh-CN.md#install)。下载本包不会自动安装。

目录中的相对链接无需原知识库。不得只复制入口后丢弃 references。普通文本或 Markdown 阅读器也可查看所有教材；脚本是可选工具。

## 查词与检查

在包根目录执行，需 Python 3.9 或更新版本：

```text
python scripts/search_terms.py "validity" --exact
python scripts/search_terms.py "SOC" --exact
python scripts/search_terms.py "SOC" --exact --format text
python scripts/search_terms.py "yield" --domain agronomy-horticulture
python scripts/search_terms.py --list-domains
python scripts/search_usage.py "rebuild" --exact --format text
python scripts/search_usage.py "重建" --domain a04 --format text
python scripts/validate_bundle.py
python tests/test_bundle.py
python -B tests/test_usage.py
python -B tests/test_paper_course.py
```

检索覆盖基础词表和原有详细词条，显示匹配数、领域、释义与相对文件位置。缩写可以有多种解释，例如 SOC 同时指土壤有机碳或电池荷电状态；工具保留多个匹配，不替作者选义。

检索接受全角英文、常见连字符变体和等价的重音字符编码，保留上下标与数学减号的区别。它未执行模糊拼写或全部同义词检索；没有命中不能证明本领域没有这个概念。命令行 JSON 统一使用 UTF-8，脚本仅查询本地资料。

默认 JSON 输出保持兼容；加 `--format text` 可得到便于阅读的词条列表，`--list-domains --format text` 可查看领域目录。

## v3.6 的整篇带写与反馈

新增一组原创虚构材料，含六对完整说明卡、计数定义、两份教学阅读卡和材料支持的解释。八个任务连续形成标题、摘要、引言、方法、结果表、讨论、结论及参考资料，可对照完整英文范文。练习与答案分开，学生尝试后获得具体反馈，再重写；T01 换一组方向不同且仅有计数记录的材料，检查迁移和访问范围。

中英课程入口和练习册均随包分发。缺口桥接说明要找什么记录、在哪里找、怎样向导师询问以及哪些文字可先完成。直接润色和立即看答案继续可用。原有学科、用词和期刊卡保留。

[本轮自审记录](tests/paper-course-audit.md)区分五轮内容检查、86 项包内测试和未进行的真实教学验证。完整案例为教学虚构，不可作为真实论文发表；完成练习不保证独立研究能力或录用。

## v3.5 的学科用词与期刊扩展

补充 52 个学科入口的写作关注点与 208 组用词对照，保留原有概念释义。比如软件中的 `rebuild a project`、渔业中的 `rebuild a stock`、组织研究中的 `restructure an organization`，需按对象及实际动作选择。每行有替换边界，检索返回候选，不自动改稿。

期刊卡由 15 份增至 40 份，新增条款依据本轮可读的官方页面，区分文章类型、投稿阶段、要求与建议。未覆盖的期刊可依据作者提供的指南建立临时卡。用词例句为原创，未建立母语作者频率语料库，不能宣称某学科或期刊普遍偏好某个词。

[本轮检查记录](tests/usage-journal-audit.md) 列出检索、覆盖及文档检查范围。已发布版本与下载包见 [GitHub 版本页](https://github.com/NoNightWatch/EZ-to-write-a-paper/releases)。

## v3.4.1 的指南定位

## v3.4 的领域文风修订

新增按需使用的自然文风模块，处理重复主语、信息衔接、条件归属和作者声音。保留清楚的长句，也保留有作用的短句；句长不作为统一质量指标。当前期刊硬性要求、一般教材建议和实际样文观察分别处理。教学解释可以简单，稿件仍保留目标读者所需的信息。

八组原创示例及 12 个维护情景见 [文风示例](references/field-style-examples.md)，实际验证范围见 [本轮检查](tests/field-style-audit.md)。未增加术语或期刊卡数量，没有按作者母语建立语料库。

## v3.3 的使用体验修订

新增中英启动页、无私人材料的首次试用、统一修改控制和修回回应流程；检索增加可读文本格式。可分开指定正文与解释语言，保留作者措辞，并依据可访问原稿局部恢复。修回工作明确区分完成与计划状态。

## 内容与隐私边界

帮助表达、术语一致与文字组织；不生成可套用到所有学科的因果论证、机制解释或实验设计处方。讨论中的专业判断由作者提供。不会编造数据、引文、伦理审批、结果和投稿完成情况。

作者提供的稿件、参考材料与临时词表默认只在作者工作区使用，不自动进入共享包。包内不含论文全文、私人稿件、账户信息或原知识库路径。检索期刊指南不发送未发表正文。生物医学词条用于阅读与表达，不构成临床或高风险生物操作指导。

期刊资料保留原 15 份记录，本轮新增 25 份官方资料卡，各卡覆盖范围不同。实际使用必须重查与任务相关的当前要求。未访问成功或只取得片段的项目注明缺口。资料卡不承诺送审或录用。

来源与限制见 [原资料记录](references/sources.md)、[通用来源说明](references/foundation-sources.md) 和 [综述教材评估](references/review-source-assessment.md)。教材与释义为编辑整理；引用题名不附带第三方全文再分发许可。本包未新增开源许可证；公开可读不自动授予额外再分发权利。
